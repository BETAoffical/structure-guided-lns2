# 冻结新模型的新随机流重复结果

## 结论

冻结 `uncapped_condition` 在第二批随机流上仍为11/16成功；Dual16+SA和未训练探索也为11/16，
旧条件模型10/16，Official+SA 8/16。新模型相对旧条件模型净增1个的方向重复，但相对Dual16和探索的净成功增量没有重复。
预设判定为 `net_gain_not_repeated_do_not_promote`，不是全面失败，也不能把新旧两批合并后改判本轮通过。

本轮不要求每个案例都赢，也没有新增更严门槛。新模型与Dual16、探索在本轮完成的是完全相同的11个位置，
因此没有因统计显著性或“必须全胜”而隐藏成功率优势。计算量和路径长度另有局部正信号，不能忽略，亦不能代替真实TTF。
