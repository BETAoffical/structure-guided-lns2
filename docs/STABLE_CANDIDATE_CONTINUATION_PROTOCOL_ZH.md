# 固定稳定候选的有界延续诊断

## 目的与停止范围

只检查既有Dual16失败状态中的稳定4车候选能否产生持续收益，不测试其他候选、不训练、不修改正式控制器、不运行串行TTF。

状态固定为`case-3723c8bd272e`，40对冲突；候选固定为`neighborhood-0d3103de10e25097`，历史8/8将冲突降至39。候选在看过全部历史结果后指定，因此这是单状态事后诊断，不是独立确认或置信度充分的总体推断。

## 协议

- 两分支：原冻结Dual16；首步强制指定4车候选，此后恢复完全相同的Dual16选择器。
- 八组新的配对随机流，命名空间`stable-candidate-continuation-v1`、根20260911；与旧延续及候选动作种子核查隔离。后续流允许因路径、候选变化而分化，不冒称始终相同实际PP顺序。
- 两分支首步相同PP seed；不同agent集合不要求字面顺序一致。
- 每项完整重放44个历史动作，核对每步完整fingerprint与实际PP顺序；源候选池、成员、分数及原选择必须复现。
- 16个正式诊断作业，最多16进程；不另造作业凑20 workers。每进程单线程数值库。
- 保留旧延续器的64步、60秒延续、单次PP最多10秒，外部fuse300秒含启动/前缀缓冲；不是增加优化预算。
- 复用旧延续器，不修改其文件。新入口只登记一个状态、固定候选、新种子和两分支调度。
- 支持`STOP_AFTER_EPISODE`、原子结果、运行锁、SHA封存及resume。错误停止新派发，已启动分支有界结束；超时不自动重试。

## 预先固定的解释标准

全部16项身份及路径合法性通过，无墙钟/原生超时删失。主比较按trial配对，报告可行数、最终冲突、64步补齐AUC、完整冲突序列、PP工作量和回滚。

以下任一且不损害原本可行的配对，才记为`bounded_signal_only`：

1. 可行数至少比原策略多2/8；或
2. 最终冲突改善的配对中位数至少2对，且至少6/8组AUC更低。

其他为`no_go_or_inconclusive`，并区分没有持续效果与预算未知。此门槛只用于决定是否保留进一步研究的线索，不构成统计显著性、晋级、TTF收益或泛化结论；不追加trial、改候选或放宽门槛。

即使通过也不自动运行下一阶段。并发运行时间仅作开销记录，不能称为单worker加速。单步下降且AUC略低，不足以证明解决了长尾。

## 验证和运行

入口为`scripts/diagnose_stable_candidate_continuation.py prepare|collect|analyze`。准备和分析不调用求解；collect单独运行。

准备登记旧计划255个文件以及新入口、协议、测试及输入SHA。定向测试覆盖固定动作、seed/排程、门槛边界和删失。复用已验证旧延续器，不额外重跑六状态或正式TTF；不重编译native。

结果在忽略目录`build/initlns-stable-candidate-continuation-v1`，运行前提交推送协议及计划登记。结束核对首步候选、seed配对、之后确为冻结模型最大分数选择、完整trace链、最终路径/冲突、补齐AUC和结果SHA。
