# 候选价值是否依赖续跑策略

## 不再重复什么

上一轮同模型单次干预18/32，连续接管15/32，原策略20/32；首次动作相同后，续跑策略会改变结局。
但它没有测量同一根状态的全部候选在不同续跑策略下的价值，不能判断候选优劣是否翻转。
本轮只补这个缺口，不搜索干预次数、置信度或停滞阈值，不重训模型，不改正式控制器。
历史反馈、H1/H4/H32、容量和时空表示负面结果保留，不把更换标签名称当作创新。

## 固定状态和模型

- 来源：已查看的 `sa-unbalanced-coverage-v1` 31状态，均未进入旧16状态模型拟合；不是新地图确认。
- 同一模型：`sa-paired-closed-loop-v1` 的冻结H32配对GBDT，不使用新网络或新增状态重训。
- 8张图各取1状态，地图排序后交替选early/continuing，各4个；候选状态按固定seed哈希选最小者。
- 仅使用decision 4到128、agent 223到484、当前冲突1到200的状态，复核它们确实是旧16状态的三个范围。
  范围相交不等于联合分布内或所有特征受支持，不称为已经消除分布偏移。
- 不读取完成率筛选，不排除难例，不改阈值补齐。某图无合格状态即停止。
- 每根保留历史登记的全部4候选、8个trial及H32窗口，原候选来源和首动作不变。

## 配对和预算

旧策略续跑256条结果直接复用；新增新模型续跑256条，另做8条旧续跑完整重放对照。
每根先从reset精确重放真实prefix，检查完整state/history fingerprint与原候选池。
旧续跑对照固定原anchor/trial0，完整轨迹必须逐步复现；对照不通过则不启动该根新分支。
每条新分支的首动作、PP顺序和完整后继状态必须与同候选同trial旧分支完全一致。
随后使用原Dual16池，保留原赢家及三个哈希盲采样候选，再由同一冻结H32模型选择。
采样沿用闭环的task-seed/decision/state key及candidate seed；trial只改变共享PP/SA流，不含候选或续跑臂名。
根状态第一步强制给定候选，与后续模型选择严格分开。proposal不得改变状态。

维持来源H32采集预算：每branch 120秒安全上限、PP 5秒、2500万generated；外部180秒保险。
prefix PP为原登记30秒，独立root进程900秒保险。时间只作资源保护，不是TTF比较。
最多20个fork分支；每根串行准备后并行子进程，父进程必须单线程，且各子进程不能修改父状态。
最多264条实际分支、8448次修复，另加8根prefix；prepare给出准确prefix数和理想并行保险上界。
完整分支原子落盘，允许逐分支resume；异常停组、不自动重试，安全超时记未知而非失败。

## 分析，不用小样本宣称泛化

每候选先聚合8trial，再比较两种续跑策略：完成率、候选对差值、严格反向对、最佳集合Jaccard。
平局不是翻转。严格翻转还必须在trial0到3、4到7中分别保持相同反向，才记“半样本重复翻转”。
至少2图出现这一描述性信号，记 `repeatable_candidate_order_shift`；不足则记弱/噪声或未见翻转。
它不是多重比较校正后的显著性门槛，不是晋级条件。8trial不足以对48候选对做有力的严格确认。

另做双向交叉半样本：前4trial分别按旧/新标签选候选，只在后4trial的新续跑结果评价，再交换。
半样本内平局优先原anchor、再候选ID。先在每状态内平均两个方向，再做5000次地图bootstrap。
这样不把同一批trial选出来的经验oracle当真实可实现上界。
同时报告固定原anchor、冻结模型首选和四候选随机的完成率，在两种续跑下分别评价。
所有根和全部trial均保留；任一删失则总体结论降为证据不完整，不用删掉未知后的成功率决定下一轮。

## 决策边界

- 重复翻转且交叉半样本有收益：支持后续单独考虑续跑策略条件化标签；不是已证明重训一定有效。
- 新续跑普遍更差但候选顺序近似不变：优先处理后续控制质量，不把重贴标签当修复方案。
- 翻转不稳定：不自动扩trial、拉长H或调模型；保留不确定结论。
- 无论何种结果，均不启动RL、正式TTF、重训或修改生产控制器。
