# 终局控制变量审计：发现局部降噪信号，尚不支持直接更新A

2026-10-01。[冻结协议](SA_TERMINAL_CONTROL_VARIATE_PROTOCOL_ZH.md)，
承接[独立随机流复测](SA_COMPLETION_REPLICABILITY_RESULT_ZH.md)。

本轮只读现有四个Train条件的原16条及新64条完整轨迹。
没有新增求解、训练、TTF或模型修改。当前A、Dual16锚点、候选、PP+SIPPS及SA不变。

## 1. 本轮为什么有必要，和旧失败尝试有何不同

旧Ridge基线拟合的是状态终局完成率，已有Brier和梯度离散度变差的结果；本轮没有再调Ridge。
新随机流复测又表明，旧773步失败没有持续重现，原小样本梯度方向不稳定。
下一步需要检查信用估计本身，而不是直接再训A3或回到一步冲突下降标签。

本轮检查的是完整轨迹梯度强度与回报的关系。
保留终局回报0/1、每条件等权和完整score，比较两种另一半基线：

- `mean`：另一半轨迹的平均完成率。
- `score_squared`：另一半的`sum(R ||S||^2) / sum(||S||^2)`。

S是4193个参数的完整轨迹log-policy导数向量，不是步数、时间或节点数。
这不是删除失败、除以轨迹长度或引入更便宜动作奖励，而是改变动作无关的控制变量。
只有在完整轨迹、期望score为0及矩存在等条件下，独立基线不改变期望终局梯度。

[Greensmith等，JMLR 2004](https://www.jmlr.org/papers/v5/greensmith04a.html)
提供平均回报基线不一定最小方差的控制变量依据；
本文是该思想在完整终局score上的诊断，不复现原文GPOMDP，也不继承其求解性能保证。

## 2. 怎么防止“同批拟合看起来很好”的假象

每个新条件16条轨迹，穷举全部6435种不重复的8/8划分。
一半拟合基线，只在另一半评价，两半互换；原4条仅有3种2/2划分。
评价轨迹的回报和score不能拟合自身基线。

报告二阶矩`mean ||(R-b) S||^2`、中心离散度和分组方向变化。
同批拟合的最佳单常数只作为诊断oracle，明确不可部署，不能决定是否有信号。
6435个划分共用同16条轨迹，不是6435个独立样本，也不产生新的邻域标签。

平均交叉拟合的合成梯度复现LORO参考；Gram算法与直接参数空间计算交叉核验。
二阶矩和分组敏感性只是当前数据的描述性诊断，不是无偏真实梯度方差或闭环收益。

## 3. 有降噪信号，但不是每个条件都更好

下面三列均在相同新16条上计算；LORO使用其他15条，另两列使用另一半8条。

| 条件 | 终局成功 | 原LORO二阶矩 | 8/8 mean二阶矩 | 8/8 score_squared二阶矩 | 相对同样8/8 mean |
|---|---:|---:|---:|---:|---:|
| M01/d20/solver233 | 16/16 | 0 | 0 | 0 | 无区分信用 |
| M00/d25/solver239 | 3/16 | 155.5780 | 180.7279 | 97.1997 | -46.22% |
| M02/d25/solver233 | 16/16 | 0 | 0 | 0 | 无区分信用 |
| M04/d20/solver233 | 13/16 | 123.2680 | 127.0206 | 129.7715 | +2.17% |
| 四条件等权均值 | 48/64 | 69.7115 | 76.9371 | 56.7428 | -26.25% |

与实际原LORO相比，四条件等权二阶矩下降18.60%。
M00下降约37.52%，M04增加约5.28%，不是只比较较差的8/8 mean来隐藏实际参考结果。

满足预先固定的描述性标准：总体至少下降10%，任一混合终局条件不增加超过10%。
这允许条件间取舍，不要求每条轨迹或每个条件全胜。
机器判定为`descriptive_signal_needs_fresh_confirmation`，不会自动训练或晋级。

## 4. 改善来自哪里，风险在哪里

### M00：普通完成率不是当前数据最合适的控制变量

M00的16条完成率18.75%，同批单常数二阶矩最优值却约为0.0300。
这表明当前样本中回报与score强度并非近似独立，普通完成率不能被默认视为最合适基线。
这个0.0300读取了全部评价样本，所以只作解释，不能拿它的同批表现推广。

真正8/8交叉拟合下，二阶矩下降46.22%，中心离散度下降48.25%，
划分间的合成梯度离散度从1.58774降至0.51531。
这些是当前困难条件上的降噪信号，不证明它会新增成功或提高TTF。

### M04：同样公式仍可能增加不稳定性

M04的交叉拟合二阶矩增加2.17%，中心离散度增加5.93%。
更值得警惕的是划分间梯度离散度从0.21348变为0.80055，增加约275%。
因此不能只看总体下降，就宣布新基线已比旧基线稳定。
另一半的score强度估计仍受小样本影响，本轮没有根据条件选择或混合不同基线。

### 两个全成功条件仍没有动作区分信用

M01和M02都为16/16成功，两种交叉拟合基线均为1、优势均为0。
没有强行给这些成功动作制造更好/更坏标签；单常数oracle的极小浮点残差也不解释为信用。
因此新基线只可能改善部分已有信用的估计，不能解决全成/全败条件的信用稀疏。

## 5. 原四次重复不能直接照搬新方案

| 原4条条件 | score_squared相对2/2 mean的二阶矩变化 |
|---|---:|
| M01 | +0.29% |
| M00 | -5.61% |
| M02 | +17.64% |
| M04 | +23.67% |

原4条并没有复现新16条的总体降噪模式，尤其M02和M04变差。
不能把4变16直接当作已隔离的样本量因果实验，因为随机轨迹和终局结果也变了。
但这足以反对“不改变采样支持，直接给原训练器换公式就会改善”的做法。
本轮没有修改原训练器，也没有事后删除773步失败。

## 6. 下一步应怎样推进

1. 当前A和所有旧结果保持冻结；不直接导出或计时A3。
2. 将mean与score_squared的拟合规则及已有Train基线冻结，
   在未参与拟合的新同父Train随机轨迹上做一次有界检查。
   评价时不再用新轨迹重调基线，也不把现有6435个划分写成独立确认。
3. 仍使用终局完成、既有节点预算、完整轨迹和无决策次数上限。
   不自动添加成本奖励、温度扫描或旧Ridge模型。
4. 独立检查必须完整报告M04这类退化和全成功的零信用；
   若信号不复现，停止这一控制变量改法，不继续追加样本直到出现正结果。
5. 只有该检查支持具体估计器设计后，才另立一个有界参数更新及A对照闭环；
   最终仍要验证成功数、长尾、工作量和真实TTF，而不是凭二阶矩晋级。

当前发现的是一个尚值得确认的训练估计环节，不是新邻域模型已经成功。
它也不能解释或修复全部SA长尾，更不恢复静态上下文迁移主张。
