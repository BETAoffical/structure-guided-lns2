# 原始logit修正策略：表达合同与零更新校验

2026-09-24。本轮实现隔离原型，不训练参数、不调用MAPF、不解封评价集、不改正式控制器。
前一轮说明有界残差不能让单个候选超过Dual16锚点，但当前权重未触及上界，仍不能将长尾归因为此。

## 固定模型与边界

冻结已登记actor-1为base，候选与129维特征均保持。新策略为：

```text
pi_new(a|s) proportional to pi_base(a|s) * exp(delta_theta(s,a))
delta_theta = Linear(32 -> 1)(tanh(Linear(129 -> 32)(normalized_features)))
```

不在最后一层再用有界tanh。第一层复制base，末层全零，归一化继承base，不增加网络宽度。
base权重永远冻结；delta可以累积更新，不为每轮嵌套新的网络。使用独立schema，旧控制器加载器必须拒绝。
没有显式候选ID输入；相同特征不可能凭空区分两个候选。表达见证需要输入可区分，不是任意真实状态都能识别正确动作的证明。

NumPy零修正与任意公共常量修正返回原概率，保持同环境逐位一致和所有CDF边界选择。
Torch训练接口使用可微log-softmax，不使用会切断零初始化梯度的快捷返回；概率容差1e-12。
非有限数或概率下溢明确拒绝，不裁剪成另一个策略，不回退Dual16。

## 更新约束不是永久锁定

只实现候选更新的检查器，不调用优化器。
复用原概率统计与固定门槛：平均KL<=0.002、轨迹KL均值<=0.1、最大状态KL<=0.02。
参考必须是**直接前一行为策略**，不是每一步永远与初始base比较；base本身仍固定。
单元测试用人为构造的连续小改动说明局部约束不永久禁止改选，但这些不是训练迭代或MAPF收益。
统计保留episode权重和零动作可行任务，不将关联决策当独立样本。
有限样本KL不是全状态安全保证，不允许据此自动晋级。

## 本轮固定核验

1. 复用第二批96条actor-1 Train轨迹、六张图及13,423次决策；全部校验零初始化与base逐位概率一致、原随机抽样一致。
2. 每图固定字典序第一条轨迹，取第一、中间、最后状态，共18个真实输入。
3. 构造20个可区分候选的输入，分别指定每一个为目标，提供20个手工权重表达见证；不是拟合、不是修复标签。
4. 这些大幅改选见证都必须被单次KL检查拒绝；不能为演示表达而放松实际更新门槛。
5. 18+20组输入在Windows NumPy、已有Windows Torch环境及WSL NumPy核对概率、选择和构造目标。
6. 有限差分验证梯度，特别检查零初始化梯度、导出、候选置换、冻结base、缺失/泄漏特征、非法概率及旧加载器拒绝。

既有轨迹不重新赋值，也不作为本轮训练集。只读回放最多20进程；其余数学/导出测试不需人为拆分大量worker。
输出在`build/sa-raw-residual-contract-v1`，绑定原始输入/代码/模型SHA，支持逐episode原子保存和resume。
只提供prepare/replay/portable-check/report/verify，没有collect/train入口。

## 通过后的研究边界

通过只表示新表达合同可用，不表示参数已经学习、不增加任何任务成功数，也不说明TTF改善。
下一次训练必须单独登记数据、一次更新预算和父策略对照，仍使用完整终局目标而非一步下降/H32代理。
本轮不能授权重复拟合旧批次、扫探索比例、增加网络容量或正式计时。
旧SA、PP、Dual16、actor-1与此前失败结果全部保留。
