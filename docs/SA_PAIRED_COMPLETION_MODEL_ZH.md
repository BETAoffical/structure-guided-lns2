# 新选择器：同状态配对完成差原型

2026-09-17。实现阶段：训练原型与数据合同，尚无新的项目训练权重。

## 研究边界

继续研究新邻域选择模型，不转向初始化、重启或更换PP。不修改正式Dual16、候选生成、SA接受、冻结模型和native。
这不是已获验证的新算法，也不撤销旧长期标签稳定性FAIL。

上一轮三表示、两目标实验提示完成目标比持续下降更值得研究，但训练用的204个观察点只记录旧策略实际选择的动作。
候选特征存在，不代表已获得同状态替代动作的结果。已有8根、24候选、192分支来自模型选中的候选，只能做诊断。
不能通过修改数据角色字段，把它们变成独立的新训练集。

## 模型到底预测什么

同一访问状态s、候选a与b、配对trial r，记：

```text
Y(s,a,r) = 该候选执行后，冻结Dual16+SA续跑，在登记的32步内完成则为1，否则为0
D(s,a,b) = mean_r [Y(s,a,r) - Y(s,b,r)]
```

这估计固定续跑策略及预算下的完成概率差，不是剩余修复轮数、Cost-to-Go、一步冲突下降或真实TTF。
两候选共享trial编号及随机化方案，不意味着不同集合的PP顺序相同，也不意味着两条分支访问相同后续路径。
提前可行是已观察完成；完整32步未完成只代表窗口内未完成。节点/时间上限或不完整PP造成的截断是未知，不能补零。

使用固定参数HistGradientBoostingRegressor：100轮、7叶、叶最少10样本、learning rate 0.05、L2 0.1、seed 20260916。
输入复用决策前dynamic特征，包括当前冲突、实际候选、当前温度/阶段及冻结旧分数；不增加静态上下文或修复后信息。
每对输入为特征差与特征均值，使两个候选相同的温度、状态难度和绝对规模不会被纯差分消去。
127列变为254列只是配对编码，不代表新增127个独立观测特征。尚未证明这种编码优于旧编码。

训练保存win/loss/tie计数，回归完成率差，不挑稳定赢家、不删除平局、不按较大的样本均值生成确定胜者。
每个状态全部候选对及正反方向的总权重为1。trial用于估计目标，不作为独立状态；地图仍是验证分组单位。
预测用正反方向差的一半保证反对称，再汇总对其余候选的预测差。完全平局保留冻结动作，其余平局按candidate ID。
模型分数不是校准置信度，也没有因此获得永久禁用候选或自动覆盖旧策略的权限。

## 与旧实验的区别及没有解决的部分

| 旧实验 | 本原型的变化 | 仍然没有证明 |
|---|---|---|
| 观察性历史分类器 | 数据合同要求同根候选干预结果，训练配对完成差 | 仅改变损失不能消除坏的数据覆盖 |
| H1/Pareto成对排序 | 目标为冻结续跑下完成事件，不是局部冲突下降 | H32仍可能稀疏、噪声大，不能声称已解决长期信用 |
| H4/H32经验赢家 | 保留平局和概率差，不要求有限trial产生确定赢家 | 软目标仍有采样误差，不会自动使标签稳定 |
| 历史特征堆叠 | 先实现无显式历史对照，同目标下才允许历史消融 | 历史增量尚未证明，也没有被永久否定 |

这是训练问题定义和工程接口的整改，不宣称方法首次提出或已有性能收益。
没有把原有FAIL改为PASS，没有延长H、增加trial、换训练地图或解除旧采集门槛。
部署新排序器后续策略本身会改变，因此固定旧策略续跑标签的离线优势也不能代替新策略闭环验证。

## 数据与运行准入

- 数据身份包含state occurrence、地图、episode、decision、状态/历史指纹、候选成员、trial及continuation binding。
- 候选和trial不完整、未知agent、重复物理集合、特征列变化、随机流不配对或无解释错误必须拒绝。
- 训练地图和留出地图完整隔离；训练权重与是否具有完成差异只从训练折计算，不能读取留出标签作筛选。
- 本轮只提供历史数据检查CLI，故意不提供正式采集、运行时加载或模型导出命令。
- 后续前瞻数据必须在看结果前登记状态/候选选择，不能只采新模型首选；保留冻结动作，并预登记大小/来源覆盖。
- 新采集需单独固定预算和用途。工程数据校验通过不等于科学准入通过，更不能自动解除历史方法家族停止决定。
- 在证明怎样获得有信息且可复核的完成对照前，不通过增加树、trial或H来自动推动训练。
