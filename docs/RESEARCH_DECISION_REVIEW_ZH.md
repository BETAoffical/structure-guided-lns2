# 研究决策复盘：先确定值得解决的损失，停止相邻机制无限扩展

日期：2026-09-10。本轮仅读取已有结果，不调用求解器、不训练、不改变正式控制器，不新增计时或晋级门槛。

## 1. 本轮没有重复哪些工作

2026-09-09已经完成第一批高压力实验的快慢分组和全部120秒第一阶段轨迹分类。本轮直接复用该审计，不重跑109,900步，不再开发一套轨迹解析器。

范围仍是8张已查看仓库地图、48个静态OD任务、两个solver seed、三种方法。60/120秒共576个episode；以下成本分解仅用120秒的288个episode，每方法96个。不能与旧native首次可行实验或延迟扰动恢复实验混算。

已有细节分别见忽略目录中的 `build/path-quality-pressure-deadline-recovery-v1/review-20260909/REVIEW_ZH.md` 和 `transition-audit/REPORT_ZH.md`。本轮新增内容是损失优先级、计算账本和方法级停止规则，不是新的性能发现。

## 4. 当前优先级与不能跨越的推论

1. **可靠性优先。** 先面对Official独有成功11/24例，不再用少数局部改善掩盖未解任务。即便工程加速有价值，也不能自动声称它消除了算法长尾。
2. **修复质量与总开销同时约束。** 快例减少PP工作足以覆盖更贵的决策；慢例经常少做了一些PP却仍更慢。需要的是实际可兑现的计算收益，不是更多观测或更强单次搜索。
3. **共同PP局限不是V2劣势的充分原因。** Official也使用PP。仅证明某个PP顺序失败，尚未解释控制器为什么进入该状态、为什么选择该集合，以及Official是否会访问同样困难状态。
4. **不要否认自然恢复。** 旧审计记录V2的380段至少9轮冲突不降平台中，364段后来发生下降；Dual16为176/206。这里包含改变路径的等冲突步骤，并受预算删失，不是可部署阈值的误报率。不能据此短阈值切换、永久禁用曾失败邻域或无限重试。
5. **不能把失败案例代表性夸大。** 近期3状态枚举、单状态235见证及24状态机制研究均来自已查看开发数据。几千个分支不等于几千份独立证据，也不提供自然发生率估计。

## 5. 方法级停止清单

停止的是这些已测试实现的无新证据重启，不是永久否定整个研究领域。

| 路线 | 当前证据 | 本轮决策与重启所需差别 |
|---|---|---|
| 单外车软CAT忽略及频率选择 | 三失败状态2708分支全部回滚；两类观测排名也未通过 | 关闭当前分支。更多频率权重/同动作更多seed不构成新机制 |
| 同集合末次、前缀、整对路径反馈 | 目标局部冲突可移除，但原完整邻域没有稳定失败长尾恢复 | 不再只加约束或换反馈排序；先证明新限制放松能产生整体可接受机会 |
| 从单套Official完整路径作局部拼接 | 仅固定二选一路径库内牵动413/471/472辆车 | 结束存在性审计；不能以此上线大闭包或推导最小修复规模 |
| stable4、compact/blocker、重复救援 | 部分一步或短期正信号，持续性/代价未达到部署要求 | 保留正负边界，不凭一次逃逸重启；须先解释为何新方法不会重复进入困难状态 |
| 简单tabu、固定stall阈值、下一名 | 历史存在过早干预、候选轮换循环和整体退化 | 不从本批事后回滚率或快慢分组直接制定阈值 |
| 全量路径闭包、统一GCBS | 紧凑性、覆盖或成本门槛未过 | 不把预算/车辆数扩大作为默认补救 |
| GBDT容量、历史图模型、旧长期标签、直接RL | 原协议未通过或未形成端到端收益 | 不因低层诊断失败自动转入重训；需全新且有标签机会支持的问题 |
| 纯排名推理加速 | 记录循环时间占比约1% | 不是当前长尾主攻方向；不把代理微基准当作可靠性改善 |

## 6. 后续实验的准入，而不是新一串自动任务

当前决策为 `pause_new_mechanism_collection`。没有自动批准下一种联合搜索、更多trials、训练或正式TTF。

任何新提议先在一页中写清：目标损失与适用任务；与最近失败方法的实质差别；能改变决策的正负结果；机会验证的范围；实现成本及停止预算。仅指出“还有一种可能没排除”不够。

未来顺序固定为：有界动作机会 → 输入可见的低成本选择/实现 → 持续性与代价 → 独立端到端。不能再次先开发大规模观察器，后检查动作空间是否有收益。若复用已经充分审计的机制，不为了凑齐步骤重复运行。

停止规则必须覆盖方法家族：机会不足就停止该动作家族；机会存在而实现失败，只允许有明确失败定位支持的一次针对性修正，预算在执行前固定；不得通过连续改名、换观测范围延长同一分支。独立确认前冻结规则，开发集预登记不冒充独立验证。不修改任何旧门槛以迁就结果。

工程使用层面，本批高压力自然从头规划以Official为更可靠的已测参照；旧仓库延迟扰动恢复中的V2/Dual16正结果单独保留。本轮不修改实际默认配置，也不从这批已查看地图事后学习路由。
