# Raw选择器首轮终局更新：出现开发正信号，尚未晋级

协议见[固定范围与终局信用定义](SA_RAW_RESIDUAL_RUNTIME_PROTOCOL_ZH.md)。

**本轮完成了真实连续采样、一次终局策略梯度更新和新随机流配对比较，不再只是表达能力演示。**
父策略成功37/48，更新策略39/48；新增成功3个、丢失1个，净增加2个。

## 1. 实际改变的层

冻结旧actor-1作为base，使用`pi_new proportional to pi_base * exp(raw_correction)`。
raw分支129→32(tanh)→1，不再给末层施加[-2,2]永久上界；base、归一化和输入列全部冻结。
两个不同地图的原生完整对照共40次修复，零修正的路径、候选、特征、概率、动作和节点均复现父策略。

新模型只改变已有候选池上的概率选择。候选生成、Dual16/GBDT锚点、PP、SIPPS、SA温度及接受逻辑均未改。
模型仅通过独立进程的显式适配器运行，不进入默认控制器；退出或异常后恢复历史加载器。
旧加载器仍拒绝raw schema。原生文件固定为`sa-wall-clock-v1`，SHA仍为
`5b1b2af1a8a388e76567c3f1e874674ef8c2701775c3706d0a1e4d9678d1925d`。

此处“父策略”是零修正raw封装后的旧actor-1，**不是单独Official，也不是正式Dual16+SA**。
本轮不能据此声称已经超过这两种正式基线。

## 3. 训练确实用了终局信号

完整可行回报1，节点预算耗尽回报0；不使用一步下降、剩余冲突、runtime或未选动作伪标签。
采用同条件leave-one-replica-out baseline，地图/条件/episode等权，信用乘整段`sum(log pi)`。
零动作可行episode的权重保留；没有按长短轨迹改为逐步等权。

实际有非零信用的是20条轨迹，来自M00、M02、M03、M04、M05的五个条件。
其余条件的四个结果完全相同，不能强行产生正负选择标签。M04的500-agent条件仍没有成功信用。

## 5. 结论与不能归因的部分

机器决定为`positive_development_signal_needs_independent_confirmation`，`no_promotion=true`。

- 已做到：新schema接入真实连续运行；新完整终局批次产生非零梯度；一次固定更新后，新随机流下有净成功收益，并有共同成功节点下降。
- 未证明：稳定成功率提升、解决全部长尾、跨地图泛化、真实TTF加速、超过正式Dual16+SA或Official+SA。
- 尚未隔离：同一批数据上的旧有界模型更新没有作为本轮对照，因此不能把收益专门归因于取消永久残差上界。
- 尚未解决：只有五个条件提供差异化终局信用，M04高负载仍无成功样本；单次小步和已有手工特征均有限。

本轮不是回到一步最优，也不是重做温度扫描或重复拟合旧批次。
下一步应冻结这个模型，先预注册独立任务/随机流确认并补正式Dual16+SA同机制对照，必要时包含Official+SA。
暂不继续拟合本批次、不追加参数扫描、不启动正式TTF，也不恢复静态地图/OD迁移主张。
若确认失败，保留本轮正负案例与区间，而不是挑出获胜地图改写结论。
