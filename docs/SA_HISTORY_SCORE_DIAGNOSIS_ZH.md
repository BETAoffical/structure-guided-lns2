# SA历史选择器：评分与预测误差诊断协议

2026-09-16。来源为已经看过结果的采样修正开发集，因此这是事后解释性审计，不是独立确认实验。
不改变旧模型、特征、标签、评分参数或正式控制器；不补采、不训练、不执行TTF或RL。

## 输入和比较

固定29状态、174候选、696次trial的索引、折外预测和正式报告SHA。
完整验证原计划、所有receipt、四trial聚合、模型文件SHA和既有折外选择复现后才能分析。
每个状态等权，5000次地图级bootstrap，另按原有三个stratum报告。

1. 原历史/动态模型的评分与仅冲突消融。
2. 用四trial经验均值替代全部预测，分别执行原评分和仅冲突规则。
3. 对冲突、旧边持续性、可行性三个预测头枚举全部8种经验值替换，保留其他头不变。
4. 将预测评分相对经验最优冲突规则的差分拆为：
   - 经验评分相对经验最优冲突规则的代价；
   - 预测评分相对经验评分的剩余差。
   两者是有符号算术分解，不是因果归因，也不保证每项为正。
5. 对8种替换计算各头的Shapley平均冲突损失变化，检查加和等于全头替换收益。
   这只消除替换顺序的任意性，不表示可部署的信息增益或真实世界因果贡献。
6. 用trial 0/1选择、2/3核验，再交换方向；两方向先在状态内平均。
   报告原经验评分相对仅冲突规则的独立半样本冲突差、可行率差和旧边保留差。

经验规则使用原来的1对冲突容差、0.25可行率量化和候选ID平局规则；不扫描或优化参数。
“经验oracle”只知道本次有限trial，既不是无噪声期望，也不知道后续能否完成。
一步总冲突较多不能证明SA暂时恶化有害；本轮不推断长期TTF。

## 解释边界与下一步

- 若完全替换预测后仍牺牲一步质量，说明评分目标确实有代价，不是单纯模型预测错误。
- 若经验评分损失小而模型损失大，预测误差值得优先检查。
- 若分半结果不稳定，只能报告数据分辨率不足，不把经验最优当作稳定标签。
- 若多个因素并存，分别报告，不把所有差异归结为一个组件。
- 无论结果如何，不自动采用oracle、改阈值、重训或上线；新的评分方案需要独立协议。
