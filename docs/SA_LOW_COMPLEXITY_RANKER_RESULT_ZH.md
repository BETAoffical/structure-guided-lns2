# H32 低复杂度排序器结果与下一步

## 结论

不要求一个方法所有地图都赢，也不把5个百分点当作探索的硬门槛。
本轮两个固定模型相对冻结Dual16+SA都有正平均点估计，允许保留为探索方向。
其中线性差值模型的信号更清楚：8图5胜、1负、2平，H32完成率增加2.604个百分点。
但两个模型均未超过同数据、同地图划分的GBDT，不能称为新模型已经优于现有学习方法。
本轮没有求解新任务，没有正式TTF，也没有修改生产控制器。

## 实际做了什么

遵循[训练前协议](SA_LOW_COMPLEXITY_RANKER_PROTOCOL_ZH.md)，新增两个隔离原型：

- `linear_difference`：有L2正则的线性标量效用，学习候选之间的H32完成率差。
- `coarse_rank_svm`：按同状态H32完成率的50/75百分位分组，只学习组间优劣，不要求拟合精确差值。

两者排序均可传递，不会产生A胜B、B胜C、C胜A；这不等于它们一定预测正确。
复用47状态、8地图、188候选和1504个已有trial，候选结果先聚合再训练。
每折完整留出一张地图，训练标准化与标签不读取该地图；8折乘2模型，共16个正式拟合。
最多16进程实际并行，每进程数值库线程数为1。不安装依赖，不新增反事实采集。
旧GBDT预测由登记的逐折模型结果提供，不重新训练或改变其参数。

这8图都是已查看的station-centric开发地图，没有新的独立验证图，也不是8种地图结构。
旧16状态与新31状态合并后总计47，不能将1504trial或训练候选对解释为独立状态数。

## 找出了什么，仍没找出什么

1. **降低自由度不是万能修复。** 线性差值的训练折oracle命中率91.19%，低于GBDT的97.26%；
   SVM则达到99.70%，却在留出地图更差。127维表示面对47状态，即使线性模型也能过拟合。
   训练折329条预测有重复，仅作拟合诊断，不能当成329个独立样本。
2. **消除成对循环没有自动带来更好泛化。** 两个新模型都可传递，却都低于GBDT。
   本轮同时改变了表达和估计器，不能单独证明非传递性完全无害或一定是主因。
3. **共享状态特征的作用有限。** 温度等对同一候选池恒定的特征在线性差分里抵消；
   这只是刻意简单的对照，不是完备的历史条件化SA模型，不自动加入交互项重新搜索参数。
4. **旧策略续跑标签仍不等于新策略连续接管。** 之前连续新模型15/32低于冻结20/32，
   固定同首动作而换续跑策略也出现退化。这些实际负面结果不能靠降低门槛改写。
5. **规模和目标都不轻松。** 有效地图与状态少，终止事件稀疏，同一候选还受到PP顺序和后续SA影响。
   当前H32标签不是任意策略下的固有动作质量，更不是精确TTF。

所选实际size分布：GBDT为4:3、8:7、14:1、16:36；线性差值为4:3、8:8、14:1、15:1、16:34；
SVM为4:10、8:12、14:1、16:24。不是只靠选择同一size产生全部差异。

## 别人的论文对我们有什么帮助

[MAPF-ML-LNS](https://taoanhuang.github.io/files/aaai22.pdf)使用轻量线性排序和分组监督，
并通过策略访问状态聚合缓解分布偏移；它主要优化已有可行解的SOC。
本轮借鉴前两点，但没有复现原算法，也没有把一步SOC目标用于我们的H32任务。

[统一复评](https://ojs.aaai.org/index.php/SOCS/article/download/35996/38151/40068)发现，
在其统一设置下学习方法并没有明确的效率和改进能力优势。
所以不能把“有论文提出改进”理解成“任何数据、阶段、低层规划器及时间预算都可以直接复现增益”。
反过来，我们也不需要证明处处最优才能形成成果，应明确适用范围、总体收益和成本。

## 下一步只做什么

优先保留线性差值模型作为低开销挑战者，而不是直接替换生产模型。
它相对冻结策略有跨多数开发地图的正信号，足以申请一次小规模独立闭环验证，无需再堆离线门槛。
但GBDT在相同离线协议更高，不能为了推广线性模型把它从对照中删除。

下一次先冻结最终训练产物、独立任务清单和有界计算预算，再比较冻结Dual16+SA、已有H32学习对照和线性模型。
主要看净完成数、完成曲线、长尾及计算开销，完整列出得失；不要求每地图都赢。
不重新运行已经失败的anchor门控、单次介入、树容量扫描，不根据试验结果追加阈值或地图。
这是对新估计器连续控制能力的验证，不是把旧GBDT相同配置再跑一遍找正结果。
若有正闭环信号再进行独立单worker TTF；若仍负面，保留原策略，不宣称长尾已修好。
本轮尚未启动这一步，也没有形成新的正式性能结论。
