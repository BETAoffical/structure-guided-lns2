# 时空模型训练结果：能够拟合，未证明新增表示收益

2026-09-17。预注册本地提交 `f98de59`，见 [冻结协议](SA_SPATIOTEMPORAL_MODEL_PROTOCOL_ZH.md)。
本轮完成了真实训练，不只是数据准备：8折配对GBDT，以及三种神经设计各3个seed、8折，共72次神经拟合。
另对固定的第一个path_time折完整重训一次，用于确定性核验，不参与方法选择。
没有调用求解器、重新采集标签、修改正式控制器或运行TTF。

## 模型及结论

- `gbdt`：旧H32配对完成差GBDT，在本轮相同训练折上重新拟合；不是生产Dual16排序器。
- `flat`：仅原127维特征的小MLP，4,129参数。
- `time_bag`：旧特征加时间聚合路径输入，9,569参数。
- `path_time`：旧特征加保留物理时序及候选内外占用的小CNN，9,569参数。
- 冻结原动作：当前Dual16+SA在该状态的选择；均匀随机只在本批四候选之间平均，不是官方Random。

固定结论为 **`no_stable_incremental_representation_signal`**。
时序模型略好于只用旧特征的MLP，但没有超过旧GBDT，也没有超过同容量的时间聚合对照。
因此不晋级、不导出生产模型、不启动TTF，不把这次结果解释为已经解决长尾。

## 主结果

47个已查看开发状态来自8张同族仓库地图，每状态4候选、每候选8个trial，合计1504个既有H32结果。
每折完整留出一张地图的新旧状态。主口径为状态在图内平均、神经模型3seed平均、8地图等权。
下表是一次动作干预后旧策略续跑的H32完成率，不是从reset开始运行新模型的成功率。

| 方法 | 留图H32完成率 | 与同样本经验最优的regret |
|---|---:|---:|
| 冻结Dual16+SA原动作 | 50.10% | 8.07个百分点 |
| 四候选均匀随机期望 | 50.89% | 7.29个百分点 |
| 旧H32配对GBDT | **54.53%** | **3.65个百分点** |
| Flat MLP | 52.50% | 5.68个百分点 |
| 时间聚合网络 | 53.33% | 4.84个百分点 |
| 路径时序网络 | 53.11% | 5.07个百分点 |
| 同样本经验最优 | 58.18% | 0 |

经验最优使用同批8trial选择赢家，存在选优乐观偏差，不能称为模型可达到的真实上限。
模型在同一地图的多个状态及多个训练seed不是独立地图样本。

## 路径时序网络的差异

5000次地图级paired bootstrap，单位为百分点。

| 对照 | 平均差异 | 95%区间 | 严格改善地图数 |
|---|---:|---:|---:|
| 旧H32配对GBDT | -1.424 | [-5.399,+1.649] | 3/8 |
| Flat MLP | +0.608 | [-1.302,+2.691] | 3/8 |
| 时间聚合网络 | -0.226 | [-1.198,+0.730] | 3/8 |
| 冻结原动作 | +3.003 | [+0.417,+5.558] | 5/8 |
| 均匀随机 | +2.222 | [-1.320,+5.577] | 6/8 |

对GBDT三个训练seed的差异分别为-0.990、-1.927、-1.354个百分点，并非只输在某一个训练seed。
相对原动作的开发性正信号保留，但旧GBDT本来就有类似信号；它不能证明新增精确时序有效，也不能替代闭环确认。
相对随机的点估计高2.22个百分点，区间仍含负值，不写成稳定优于随机。

## 为什么与之前的59.9%不一样

旧报告的59.8958%只评价新增31状态；本轮主结果评价全部47状态。
将本轮GBDT严格限制回同一新增31状态、使用同一地图等权口径，得到 **59.8958333333%**，精确复现旧结果。
因此不能用54.53%与59.90%直接相减，声称底层算法变慢或旧模型退化。

## 失败原因：证据与假设

**已观察到：** 三种神经模型在各自训练状态上的经验最优候选命中率均为100%，GBDT约97.26%。
这里的100%不是训练任务全部成功，而是选中了该训练状态四候选中最高的经验H32标签；很多状态存在并列或全相同结果。
神经训练状态的被选候选完成率约57.72%，绝不是100%的求解成功率。

网络有足够能力拟合这批标签，但没有把拟合优势带到留出地图，支持过拟合/泛化不足的解释。
它不支持“模型太小所以完全学不动”，但也不能唯一排除表示不足或标签噪声。

仍然存在的限制：

1. 仅47状态、8地图；1504trial只增加同状态动作结果的重复观察，不增加独立情境。
2. H32标签自身有随机波动，前轮已经发现split-half最优集合不稳定。本轮没有制造更可靠的监督信息。
3. 9,569参数的小CNN不是完整NNS；只读取候选旧路径及一格邻域的占用场，不能描述所有潜在绕行关系。
4. 此处时序是当前小车路径中的物理时刻，不是搜索过程中失败/接受等修复历史记忆。
5. 训练标签的续跑仍是旧Dual16+SA，不是新模型每步接管。即使离线超过GBDT，也仍需处理这一部署区别。

不能把失败归结为一个已经确定可修的推理bug；也不能据此宣布所有时空神经模型都没有价值。

## 下一步边界

不追加更深网络、更多epoch、更多历史窗口或事后门槛；不把本次模型上线。
若继续研究，应先解决“独立训练情境太少/标签不稳”和“训练续跑与部署不一致”中的一个明确问题，再决定新采集合同。
不能继续仅在同一批47状态上轮换更复杂模型，并期待复杂度本身带来长尾改善。
生产Dual16+SA、此前失败模型及报告全部保留。本次是一个完成的、未晋级的表示实验，而不是算法长尾已经修复的结论。
