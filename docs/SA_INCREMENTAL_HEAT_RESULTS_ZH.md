# SA 增量路径热度：等价性通过，当前版本不晋级

## 结论

8 个案例、792 次配对选择及历史修复全部完成。新旧 heat、拓扑、特征、候选、分数、动作、PP 顺序及完整路径/计数 fingerprint 一致，无错误或安全超时。

但包含所有校验后，选择阶段累计由 **26.1633 秒增加到 29.1810 秒，慢 11.53%**，只有 3/8 案例更快。不满足预设门槛，**本版不晋级，不替换单次完整检查运行时**。

这不是增量热度完全无收益：普通更新减少约 9.06% 选择时间，周期性 shadow 校验却增加了更多开销。已经定位到 shadow 中一处未使用的 Python 索引构造，下一轮可单独验证其等价消除，不降低校验频率。

## 修改与实验范围

- 独立 `ExactChangedTopology` 将缓存实际保存的路径与当前路径比较，再调用已有增量热度接口，不相信上一次邻域或外部 changed-agent 提示。
- 独立 `IncrementalHeatPool` 复用原 selector 的同一 code object，仅私有绑定拓扑缓存类。未修改 native、模型、PP、候选、评分或退火。
- 保留每 20 次增量更新一次完整 shadow，包括热度重算与冲突分析比较。
- 使用原 4 张仓库地图的 8 个案例，solver seed103，每个历史决策只做一次新旧配对选择。总计 792 次配对，单 worker，交替调用顺序。
- 输入 deepcopy、特征/拓扑一致性比较、历史重放与写出在组件计时外；变化检测、shadow、fingerprint 及全部选择器逻辑在组件计时内。
- 这是冻结轨迹上的组件实验，不是两种控制器各自自由运行的 TTF；不能直接换算为整批任务速度。

## 为什么多数调用更快，总体却慢

|分组|调用次数|原版秒|增量版秒|差异|
|---|---:|---:|---:|---|
|普通非初始化更新|749|24.6407|22.4085|节省 2.2322 秒，改善 9.06%|
|触发完整 shadow 的更新|35|1.1972|6.4193|增加 5.2221 秒|
|初始化|8|0.3254|0.3532|增加 0.0278 秒|
|合计|792|26.1633|29.1810|增加 3.0177 秒|

35 次 shadow 中增量版全部更慢。周期性开销超过普通更新的节省，足以解释本轮的累计退化。不能删除这 35 次记录，也不能降低 shadow 频率后覆盖本轮报告。

本轮发现 5 次路径完全不变的选择，其累计时间也有增有减，样本太少，不用于建立“回滚后特殊跳过”规则。

## 失败分析：发现了具体代码冗余

当前 `TopologyAnalysisCache._shadow_analysis` 先无条件执行：

```python
index = TemporalConflictIndex(paths)
```

随后 `_full_events` 在 native 模式下选择 `self._native_events(state)`，并不读取 `index.all_events()`。因此：

- Python 时空占用、交换边和冲突事件索引已经完整构造，却没有参与该次 native shadow 的比较结果。
- 真正用于对比的仍是一次新的 native 冲突提取及 `_analysis_from_events` 的全量热度计算。
- Python fallback 模式确实需要这个索引，不能全局删除。
- 补充调用链测试验证了 native 模式构造但不读取索引，以及 Python 模式必须读取索引。

这是工程冗余，不是模型选错邻域，也不是因为这轮更换了原始 PP 或接受语义。**尚未单独测量该构造占 shadow 时间的比例，不能把全部 5.2221 秒都直接记为可回收收益。**

## 下一步的唯一候选改动

在另一个独立版本中，native shadow 直接进行原本实际使用的全量 native 提取和热度重算，省去没有被读取的 Python 索引；Python fallback 继续原实现。

验证必须保留：

1. 原来的非空路径、身份和地图检查，以及每 20 次更新的相同校验频率。
2. 独立重新提取冲突和全量重算热度，不使用待验证的增量 heat 作为参考答案。
3. 故意注入 heat 错误仍被发现；native 与 Python fallback 的结果一致。
4. 同一历史前缀的路径、计数、特征、候选与动作一致。
5. 变化识别和新 shadow 的实际成本全部计入；另存新版本报告，不修改本轮失败判定。

只有这个具体等价改动产生净收益，才考虑新的端到端确认。本轮不自动改 shadow 周期、关校验、重训模型、增加邻域或修改 native。
