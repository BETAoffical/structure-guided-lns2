# 完成目标与历史表示：交叉对照结果

2026-09-17。本轮完成，状态`diagnostic_only_no_model_selection`。
协议与实现登记于`6c4fb46`。这是观察上轮结果后固定的解释性分析，不是预先封存的确认实验。

## 1. 做了什么，为什么不是重复一步排序

上轮ordered预测“32步持续改进”，temporal_bag预测“32步完成”，两个因素同时改变。
本轮补齐三种表示乘两种目标，分离目标和表示的作用；不是重新训练一步冲突下降模型。

- 训练仍为原204个观察点，8折留图，原固定GBDT参数及episode权重，48次小型拟合，最多20进程。
- 192个已有分支只用于分析，不进入拟合。没有新求解、路径采集、TTF、RL或模型导出。
- 原四种模型组合在全部48个候选上的概率精确复现，最大差为0。
- 所有比较共用每根三个已测候选，避免替未观测动作编造结果。
- 模型本身仍是观察性预测器，本轮没有解决动作选择偏差或把它自动转为因果模型。

## 2. 目标变化的信号比增加历史更明确

下表均为三个已测候选内选一个后的32步完成率。分母64来自8状态各8次trial，不是64个独立地图。

| 表示 | 预测持续改进后选择 | 预测完成后选择 | 完成率差 |
|---|---:|---:|---:|
| 动态状态与候选，无显式历史 | 17/64 = 26.56% | 21/64 = 32.81% | +6.25个百分点 |
| 分段历史ordered | 18/64 = 28.13% | 20/64 = 31.25% | +3.13个百分点 |
| 历史汇总temporal_bag | 17/64 = 26.56% | 20/64 = 31.25% | +4.69个百分点 |

原冻结选择为17/64，三个候选的均匀随机期望为28.65%。
动态完成模型相对自身持续改进模型为3图提高、0图下降、5图相同，探索性地图bootstrap区间[1.56,12.50]个百分点。
ordered换目标为2图提高、1图下降、5图相同，区间[-3.13,10.94]；temporal_bag为2图提高、6图相同，区间[0,10.94]。
这些区间未经多重比较校正，数据已经多次查看，不能据此宣布确认性成功。

固定完成目标后，两个历史模型均比无历史动态模型少1/64，差异只来自一个状态；没有证明历史增量。
动态完成模型相对原冻结选择则是3图提高、1图下降、4图相同，差+6.25个百分点但区间[-9.38,20.31]。
所以“目标对齐值得优先考虑”不等于“新模型已优于原选择器”。

## 4. 不能忽略的候选池边界

有三层不同的池：原在线池每根19或20个候选；旧采样先取6个；上轮桥接只评估其中3个。
本轮程序的`full_pool_*`字段指中间的六候选诊断池，不是全部19/20个在线候选。

| 组合 | 六候选诊断池首选有真实标签的根数 |
|---|---:|
| dynamic / 持续改进 | 4/8 |
| dynamic / 完成 | 5/8 |
| ordered / 持续改进 | 8/8 |
| ordered / 完成 | 4/8 |
| temporal_bag / 持续改进 | 2/8 |
| temporal_bag / 完成 | 8/8 |

缺失首选的结果明确为null。表2只能比较共同三个候选，不能当作六候选或正式在线策略表现。
原来的三个候选又是由原选择和两个历史模型首选组成，不是模型无关的均匀候选抽样。
限制为共同池提高了可比性，但不能消除池构成偏差；它不是可部署的候选筛选规则。

## 5. 标签噪声还没有消失

用trial0–3的经验完成率选候选、在4–7评价，再交换，两方向按地图平均：

- 完成目标经验参考为18/64 = 28.13%，相对原选择+1.56个百分点，区间[-4.69,9.38]。
- 持续改进目标经验参考完成20/64 = 31.25%，相对原选择+4.69个百分点，区间[-3.13,12.50]。
- 若同一批8个trial同时选经验完成最优并评价，会得到24/64 = 37.50%，明显更乐观。

这说明少量重复下的候选均值和赢家本身仍不稳定。半样本经验参考不是理论上界，可能比模型更差；
不能因为持续改进参考在这8根上更高，就倒推它是更好的最终目标。
本轮不改变上轮稳定性FAIL，不自动扩trial、延长H，也不在这24个候选上拟合排序器。

## 6. 下一版训练需要先满足的数据合同

目前没有一个可直接晋级的新模型。下一轮应先设计同状态动作数据，不能仅把观察性分类器改名为选择器。

| 环节 | 必须改正的条件 | 不允许的替代办法 |
|---|---|---|
| 数据单位 | state occurrence、候选集合、trial、continuation、预算和输入身份分别登记 | 将192个trial算作192个独立训练状态 |
| 候选选择 | 在看结果前、独立于待测模型确定；覆盖可用大小、来源以及原冻结选择 | 只采某个新模型已经偏好的候选，再声明该模型最好 |
| 动作比较 | 同根、同外部路径和历史、配对随机流，得到各候选的实际完成结果 | 用旧轨迹中一个已选动作的后续结果推断全部未选动作 |
| 目标 | 完成事件直接报告；持续下降只作诊断；预算和删失语义固定 | 临时调大H直到显著，或把窗口未完成写成整个问题无解 |
| 覆盖 | 分开盘点末期、普通推进和停滞状态中的大小/来源支持 | 小集合只在接近完成时出现，却外推到高冲突场景 |
| 表示对照 | 无显式历史作为基线，同一完成目标再检验历史增量 | 目标和表示同时改变后把总差归功于历史 |
| 不确定性 | 不强迫给全平局或方向翻转的候选生成确定赢家 | 把样本均值当真实动作价值，永久禁止一次失败的集合 |
| 验证 | 地图隔离；原8图全部属于开发；未来闭环单独授权并计入推理开销 | 用共同三候选结果替代全池策略成功率或TTF |

这是一份后续实验的准入合同，不是已经批准的新collector预算。
在解决“怎样取得可区分的完成标签而不重复旧H扩展”之前，新增采集和正式替换仍暂停。
现有证据支持优先研究目标/动作数据对齐，不支持继续堆历史特征、增加模型容量或启动RL。
