# 单冲突候选失败的只读资源审计

本轮只读取已完成的三个根、228个候选分支及历史证书，不调用求解器、不训练、不改正式控制器。
这是查看结果后的解释性审计，不是新的预注册性能实验。此前报告的0/228与66次冲突转移保持原样。

## 固定范围

- 以完整报告SHA `0174a93e33f4787fea6cc48f01bb00462a6890699d5a5bdeac3197ca37f6f702` 绑定输入。
- 228个分支全部重建，不只挑出66个转移分支；后者单独分层报告。
- 复用现有顶点/交换冲突重建函数，核对完整冲突边集合、实际PP顺序、集合外路径不变。
- 按事件时刻严格区分经过/等待、最后路径时刻到达、最后路径时刻之后持续终点占位。
  到过目标后又离开的中途访问不能叫最终停车。
- 分开统计事件数、agent对数和具有某现象的分支数；一个分支可有多种现象，分类不强行互斥。
- 回滚后的路径是旧路径，原PP尝试路径没有保存，不猜测未保存的冲突位置。
- 报告根状态的冲突时间、格子、原冲突车辆目标周围自由格和最终目标占用者。
  静态目标邻接占位只是描述，不作为不可解或必须补车的证明。
- 对照旧强迫早期出口、目标唯一时隙证书的完整地图、任务、路径身份；不能只因时间或格子相似就复用证书。
- 最多20个进程仅并行读取与重建事件，不报告为求解TTF或新修复成功率。
- 新输出位于 `build/sa-terminal-resource-audit-v1`。源结果不改写，输入/输出SHA保持可追溯。

## 解释约束

目标占位或冲突转移若与旧机制相似，不宣称新算法或因果根因；必须区分观测与必要性证明。
若没有新的可证伪机制，就停止新增实验，不自动加随机seed、预算、CBS/PBS或训练。
本轮没有验收晋级门槛，也不改变已有模型晋级结论。

```powershell
python scripts/audit_sa_terminal_resources.py prepare
python scripts/audit_sa_terminal_resources.py analyze
python scripts/audit_sa_terminal_resources.py verify
```

完整输出可验证重用；中断输出保留供检查，不自动覆盖。小图测试覆盖时间语义、交换冲突、
非连续agent ID、输入篡改和统计分母。本轮不要求重新运行任何TTF或重编译冻结native。
