# H32 选择器一致性只读审计

本轮固定旧模型，只读现有数据，不新增求解、标签、训练或 TTF。
它是已看过结果后的诊断，不是独立确认，不声称为新的模型贡献。

历史 SafeSlot 已发现混合候选会改变 Borda 总分和原候选的排名，见
[首次分歧诊断](STRIDE_SAFESLOT_FIRST_DIVERGENCE_V1_REPORT.md)。本轮不是重新发明 anchor 门控，
只检查同类问题在目前失败的 H32 配对模型上是否真实存在，以及规模是否足以支持进一步修复。
旧[排序目标审计](INITLNS_RESEARCH_REPORT_ZH.md)的双头回归负面结果继续有效。

## 固定范围

- 上轮 8 状态、256 条新模型续跑中的 5,910 次后续决策，纯重算已保存特征和分数。
- 未进入旧16状态训练的全部31状态，每状态4候选、8 trial的旧策略H32标签。
- 其中8状态额外有新策略H32标签，单独报告，不混成更多独立样本。
- 地图与训练地图重合，不能声称未见地图验证。
- 原生/portable 分数已由上轮逐项复核；本轮复核 sklearn 原模型精确重现保存的分数和选择。
- 无未选后续候选的真值，不把访问轨迹最终是否完成当成每个后续动作的反事实标签。

## 分数和统计

保持原公式 m(a,b)=clip((f(a,b)-f(b,a))/2,-1,1)，总分是所有对手差值的平均。
检查总分赢家是否直接输给/打平 anchor、三角偏好循环、删除一个非赢家且非anchor候选后的排名变化。
特征不变的删候选只是聚合性质检查，不模拟真实候选生成。

另有一个重要代数边界：完整、等权成对图的最小二乘标量效用投影正比于原总分，
所以推理时把它投影成标量并不会自动得到新的、更好的排序。

对有标签的根状态只做两个预先固定的离线反事实选择：
1. 直接选择预测上最胜过anchor的候选，平局优先anchor再ID。
2. 原总分赢家直接差值不大于0时改选anchor，否则保留。
没有置信度阈值搜索、模型拟合或实际部署。用同一根、同trial的H32结果读取这两个选择的结果。
这不是连续使用新规则的闭环证据，也不是TTF；不得据此修改正式控制器。

报告全部根状态，31状态按地图内平均后进行5,000次地图bootstrap；不得按trial当独立样本。
8状态新续跑单独分析，不用该组挑最优规则。不存在真值的后续决策只统计一致性，不填充标签。
检查选择对anchor的真实差值是否在两个4-trial半样本中同向；无稳定信号时不自动追加trial。

## 停止和完整性

输入和源报告 SHA 全部固定；任何分数、选择、候选或结果文件不一致立即报错。
结果原子写入独立build目录，已有同名结果只能完全相同，不能覆盖改变的数据。
最多20个只读进程，每个进程单线程预测；并行时间不参与科学指标。
无论结果如何，本轮只得出聚合/预测缺陷的诊断结论，不训练、不扫阈值、不运行求解器。
只有有标签的同一根状态显示修复有实际收益，才另行考虑新的有界闭环验证；不得用无标签的循环计数替代收益。
