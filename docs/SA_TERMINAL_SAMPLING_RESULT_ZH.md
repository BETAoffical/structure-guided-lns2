# 困难Train终局采样：结果与下一步

2026-09-23；协议见[采样协议](SA_TERMINAL_SAMPLING_PROTOCOL_ZH.md)。

## 1. 结论

48条新增轨迹及12,081次决策全部完成并通过逐状态审计，0错误、0安全截断。
混合采样成功28/48，原actor-1为32/48；4新增、8损失、净少4，未知对数0。
原先缺乏成功方向的M04/d25两个条件仍各0/4，没有补齐困难训练条件的成功见证。

预设判定为 `no_new_hard_terminal_support_stop_this_sampler`。
停止这一档采样扩展，不追加比例或随机流搜索，不直接训练actor-3，不修改正式控制器。
这不是否定所有模型训练，也不是因要求每张地图都赢而拒绝：本轮允许损失，实际净完成和困难覆盖均无改善。

保留局部正结果：4个新增完成；24个共同成功位置的平均makespan缩短4.35%。
它们没有抵消8个成功损失，也不能替代TTF。本轮没有测量串行TTF或整批机器人实际完成时间。

## 2. 数据与干预

沿用6张已查看Train地图，完整ID前缀为 `sa_linear_v1_m00` 至 `sa_linear_v1_m05`。
这些M00--M05编号不与其他历史数据集的同号地图混用。
只取六张图各自的bottleneck_d25静态任务，两个初始化seed233/239、四个replica，12条件、48配对位置。
没有只取原失败案例，也没有重抽任务、生成新地图、读取M06/M07评价标签。

对照48条来自已审计的 `build/sa-second-onpolicy-batch-v1`，原样复用，没有重新求解。
新臂为固定概率 `0.5*p_actor1 + 0.5/|pool|`，不是新训练模型，也不是纯均匀随机。
保持原候选池、原actor-1、PP、SA、native和配对随机流，只改变候选采样分布。
新采样器独立schema/身份，不能直接用其轨迹更新原actor而声称on-policy。

每条25,000,000修复generated节点；没有决策次数上限，native次数上限也是0。
最后一步完整执行后检查节点预算，新臂最大25,156,868，对照最大25,154,368，末步越界按原协议保留。
全部未完成轨迹都因节点预算停止，不是超时，更不是完整无解证明。
20个进程仅用于非计时工作；模型、求解器、旧报告没有改动。

新增的三个混合组来自原全成功条件受到损伤：M02/s233、M03/s239、M05/s239。

本轮在采集前已明确区分这两类现象，没有根据结果临时增加门槛。

## 5. 干预确实生效，但探索不是越多越好

| 行为量 | actor-1 | 新采样 |
|---|---:|---:|
| 全部决策数 | 9,660 | 12,081 |
| 实际选择非锚点候选占比 | 9.79% | 52.56% |
| 按决策加权的平均锚点概率 | 90.11% | 47.65% |
| 超过256次修复的episode | 16 | 26 |
| 最大实际修复次数 | 357 | 396 |

48/48条均产生动作分歧。首次分歧前路径状态一致，首次分歧时候选、特征及抽样数一致；
逐步审计重算了模型锚点评分、采样概率、选择、PP/SA随机流、接受、最终路径和质量指标。
不是采样器没有加载、仍执行同一个动作，或低层逻辑偷偷变了。

但更强探索没有在原全失败条件形成成功。本预算下它同时打断了若干原来能完成的轨迹。
这支持停止“仅把固定随机探索比例调高”的当前方案，不能由一个比例推断所有状态条件化探索无效。

## 7. 下一步与不重复的边界

当前暂停同配方actor-3、探索比例搜索、H1/H32替代标签以及已有停滞救援链。
不是停止所有新模型研究，而是当前采样未提供足够新的困难成功信息，继续同配方更新没有新依据。

对94份顶层SA登记/报告按完整任务ID检索，在本次两个M04初始化上只找到actor-0、actor-1和本采样器，
未发现相同起点、25M节点预算下的Official+SA记录。该检索范围不等于声称所有历史Official实验都没有做过。

下一项有区分力的问题是：**相同初始化与资源下，官方候选选择是否能提供这些Train条件的完整成功轨迹？**
应先核对历史完整fingerprint，已有严格匹配就复用；没有才单独登记小规模同机制参考，并保留能解对照。
这一步不是再比较一个随机采样比例，也不直接用于宣布方法优劣。

- 若参考能完成，再沿成功轨迹检查其邻域能否由当前候选池表示，区分候选支持不足与选择/信用问题。
- 若参考也未完成，结果仍是预算下未知；不能靠这批全失败数据假造成功排序标签，应重新评估工作预算或训练任务覆盖。
- 参考方法数据不能直接作为旧actor的on-policy梯度；任何模仿、离策略或新候选空间训练都需要独立协议。

本轮没有执行这个下一步，没有替换默认控制器，也没有启动TTF。
