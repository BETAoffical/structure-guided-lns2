# 冻结A/A2：第二批独立仓库TTF确认

## 结论

本轮完成72/72初始准入、288/288串行计时、288/288计时外轨迹审计，零实验错误。
另外完成11个含失败条件的44条配对轨迹只读诊断，没有追加求解、训练或修改正式控制器。

**A相对同SA机制Official+SA的首次可行规划优势得到重复支持；A2有增量信号，但还不能确认优于A。**

- Official成功63/72，Official+SA成功66/72，A+SA成功66/72，A2+SA成功67/72。
- 主对照A/Official+SA：63个共同成功条件的平均TTF从29.3147降至21.6263秒，下降26.23%；
  45个更快、18个更慢，地图级差值95%区间[-11.5812,-4.3695]秒。达到预登记的主门槛。
- A2/A：新增2个成功、损失1个；65个共同成功条件平均TTF下降3.79%，但差值区间跨零，29快、36慢。
  不把A2判为没有价值，也不据此自动替换A。
- TTF改善不等于整批机器人完成更快。A和A2的makespan均有增加；每步1秒的完成时间模型未显示明确改善。
- 剩余失败并未消失，也不是都来自重复选择同一个邻域。冻结A继续作为主比较版本，A2作为候选完整保留。

这是新的同族受压仓库地图证据，不是跨布局、静态上下文迁移或真实机器人执行实验。
成功数相同不构成总体成功率等效证明；主门槛通过不意味着每个任务都优于基线。

## 后续决定

本轮已经完成独立计时及针对性失败诊断。A保持主版本，A2保留为值得继续检验的候选，**没有在本批结果上做第三次更新**。
现在也不新增基于M04/M06身份或密度的事后路由，不做温度网格、通用新奇性惩罚或再次扩大树/网络容量。

下一项有区分度的学习实验是扩大独立训练地图覆盖，而非在原六图上反复追加更新：

1. 先冻结本批数据为评估证据，不能从这些成功/失败生成训练梯度或挑选训练任务。
2. 新训练数据保留同样动态表示、候选、PP、SA、终局成功目标和更新约束，只改变训练地图覆盖。
   同时保留容易成功、中等混合、全部失败条件；按地图汇总有相对成功信用的条件数，不能用决策总数假装独立标签数。
3. 如果新数据仍几乎全成或全败，先报告信用不足，不盲目增加优化轮数；只有覆盖改善才做一次冻结更新。
   这检验的是数据覆盖假设，不预设“样本少”已经被证明为根因。
4. 用新的开发地图检查成功增损和工作量，然后在另一批未见任务做串行TTF。评价平均收益及置信区间，
   不要求每例全胜；同时保护原成功案例，并继续单列SOC/makespan。
5. 若主要目标转为机器人实际完成时间，应另立路径质量/第二阶段协议；不能临时改本轮目标或只挑有利每步秒数。

以上是下一轮边界，不是已执行的新训练结果；本轮没有因A2的不确定性抹掉A的已复现正向成果。
