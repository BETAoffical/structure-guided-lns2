# H32训练标签审计：排除错误解释，修正稳定性判断

2026-09-17。协议提交`e9e1e3b`，对应[只读审计协议](SA_COMPLETION_CONTRACT_PROTOCOL_ZH.md)。
本轮复用512条分支，不采集、不改变模型、不运行求解器或真实训练/TTF。

## 结论

1. 没有发现本批PP/SA随机化、完成标签、分支身份或最终指纹不符合采集合同的错误。
2. “完整指纹含低层计数，从而影响proposal种子”是历史已知的设计依赖，不是新发现的官方bug。
   在本批首步后的768个同trial候选对中，没有仅低层计数不同而其余状态相同的配对，不能用它解释本轮失败。
3. 上轮28.13%的最佳集合重合率只对应前4/后4分法。全部35种分法平均为40.33%，原解释需要收窄。
4. 交叉选优平均完成率40.16%，高于旧动作38.28%，但低于随机期望40.82%。这是有限、较弱的样本信号，不是可靠新模型收益。
5. 旧模型评估结果、门槛和不晋级决定不变。不能因为审计排除了一种错误解释，就跳过标签/样本问题重新训练。

## 数据合同检查

输入为`build/sa-paired-completion-pilot-v1`：16状态、8地图、64候选、512条H32分支。
全部root和branch receipt、原登记输入及训练receipt通过SHA核验；逐事件检查PP seed、接受draw、温度、绝对步数和动作成员。
重新解码11,665次状态转换，核对每分支最终完整指纹及完成标签。
原轮已经从路径验证过合法性，本轮没有重跑低层搜索，也没有把省略重复求解等同于省略文件完整性检查。

最多20个进程、16个根并行处理。没有新增真实模型拟合、采集分支、native构建或依赖安装。

## 是否存在“相同路径，记账变化导致续跑分化”

审计保留三种独立身份：正式完整fingerprint；只屏蔽low_level的审计签名；另外屏蔽iteration的物理状态审计签名。
后两者绝不进入正式候选生成或替换旧fingerprint。

| 检查 | 数量 |
|---|---:|
| 同根、同trial、不同首候选配对 | 768 |
| 首步后非计数状态完全相同 | 0 |
| 首步后完整状态相同 | 0 |
| 后续同一步出现非终止、非计数状态合并 | 0 |
| 首步后路径不变的分支 | 2/512，均未接受 |
| 分支内部出现非终止物理状态重复 | 15/512 |
| 两候选最终H32完成标签不同 | 67/768，8.72% |

不同候选的首步确实产生了不同路径状态。不能说“动作没有任何作用”，也没有观察到整个路径状态合并后忘掉首动作。
但这不排除关键局部资源差异消退或后续决策削弱首动作效果；整个状态不合并并不能证明首步具有重要长期价值。
物理重复不是完整策略状态自环，温度、步数及计数可能仍在变化。
15/512也不是所有平台的发生率：重复选择同一邻域、冲突图不变等情况并不要求完整路径逐位相同，旧长尾证据没有因此被推翻。

同完整状态的后续一致性断言在本批没有实际配对可检查；只有对应单元测试覆盖，不能把零异常伪称为实证确定性证明。
计数与proposal随机流耦合已由`NONMONOTONIC_REPAIR_RESULT_ZH.md`及`SA_SELECTOR_FACTORIAL_RESULTS_ZH.md`记载。
本批没有同路径反例，并不证明耦合永远无影响；它只是不能被当成此次失败的已证实原因。
PP/SA配对也不等于后续proposal或不同成员的实际规划顺序相同，后续根据自身状态决策本就是冻结策略的一部分。

## 单一对半分法的局限

8个trial共有35种无序4/4划分。本轮枚举所有划分，每种都执行两个方向的“前半选优、另一半评价”，平局优先旧动作。
不挑对模型有利的划分，不训练新的选择器；35种划分仍来自原8个trial，不是35组新样本。

| 指标 | 原固定前4/后4 | 全部划分平均 |
|---|---:|---:|
| 有完成率差异的8状态：最佳集合Jaccard | 28.125% | 40.3274% |
| 全部16状态：最佳集合Jaccard | 64.0625% | 70.1637% |
| 交叉选优H32完成率 | 38.28125% | 40.15625% |

全部状态的重合率包含8个完全平局状态，它们均为1，不能只用70.16%宣称标签稳定。
各分法的总体交叉完成率范围为37.50%至42.1875%；范围不是置信区间。
在全部划分中，两半均有严格差异的候选对比较共366次，其中208次方向一致，56.83%。
这些比较高度重复、相关，不能把366当作独立样本做显著性检验。
原13对中4对一致的数字没有算错，但它不是全部分法下的总体比例；今后不能只拿该数字作普遍性结论。

原动作38.28125%、新配对模型37.50%、直接模型39.84375%、随机期望40.8203125%均保持不变。
经验oracle46.09375%使用同一批结果挑赢家，较交叉选优40.15625%高5.9375个百分点，具有明显样本内乐观成分。
这不是模型已经学到40.16%，而是使用部分真实结果选候选的描述性检查。

## 配对随机化是否已经降噪

按状态及候选对平均，配对差的样本方差为0.0842634，两边边际样本方差之和为0.0831473，比值1.01342。
共同PP/SA随机种子没有在这个小样本中产生明显的配对方差下降。
边际方差和只作未相关噪声的数学参考，本轮并没有额外执行独立随机流实验，也不能据此声称独立种子更好。
此统计不证明随机化实现错误；不同动作对同一随机输入的反应不一定正相关。

## 对新模型设计的实际含义

- 本轮没有发现需要回退或修复冻结PP/native的错误，也没有证据支持修改默认fingerprint来“修好”这批结果。
- 首步路径影响存在，H32二元终点标签却只在8.72%的配对trial中分出不同结果。要区分“动作响应”和“可稳定学习的排序”。
- 不能仅换GBDT参数、删掉平局或把经验oracle赢家当作确定标签；也不能把稀疏的全0/全1样本说成已证明等价。
- 下一轮设计应先规定独立状态覆盖、未知/难区分标签如何保留，以及候选价值能否在未参与选优的trial上复现。
  这涉及数据与目标的可识别性，不是直接训练更大的模型；候选采样不能按确认结果挑容易出正信号的状态。
- 若要改续跑策略或随机流定义，必须承认目标策略已变，单独登记并保留原机制对照，不能复用旧标签冒充同一实验。
- 当前512分支到此冻结，不再追加这批数据的划分、窗口、参数或训练试探；本轮不自动扩采，也不转去重启/PP救援。

这仍是新选择器的训练数据审计。它缩小了可疑原因，没有解决长尾，也没有否定所有新模型设计。
