## 训练信息与未解决的问题

当前模型产生13,423步、96条完整轨迹。按照冻结的完整终局目标、同条件其他三个replica基线、
地图/条件/episode等权，对整条轨迹log概率求和：

| 条件 | 四次成功数 | 是否提供非零训练系数 |
|---|---:|---|
| M00/d25/s233 | 2/4 | 是 |
| M00/d25/s239 | 1/4 | 是 |
| M02/d25/s239 | 2/4 | 是 |
| M03/d25/s233 | 3/4 | 是 |
| M04/d25/s233 | 0/4 | 否 |
| M04/d25/s239 | 0/4 | 否 |
| 其余18条件 | 各4/4 | 否 |

非零系数只覆盖16条轨迹、4,099步。它们是新策略自己采出的新数据，不是旧actor-0轨迹的反复拟合；
但有效条件数与有效地图数仍为4和3，不能宣称采样已经解决信息稀疏。
另外一半探索轨迹仅用于配对诊断，未进入梯度。

最明显的盲区是M04/d25：两种策略在两个初始seed、各四次重复上均0/8。
当前零一终局加条件内相对基线，在四次全失败时系数为零，所以本批不能直接教会模型如何逃出这些状态。
这说明当前采样没有提供成功方向，不证明这些实例无解，也不能单凭本批归因于PP、候选池或模型容量。

已有学习残差确实改变了成功位置，但仍有损失，且共同成功工作量增加。
它不推翻[上一轮新随机流](SA_FRESH_STREAM_RESULT_ZH.md)中模型与Dual16/探索完成同一组11个位置的结论。
也不应仅因未在所有位置获胜就宣布训练不可行。

## 下一步边界

本轮登记结果是`fresh_terminal_credit_available_not_trained`：允许继续一次训练原型更新，不代表晋级。

1. 先新增支持非零父策略的更新器，保持历史actor-0更新器不动。旧更新器明确拒绝非零残差，未被本轮错误调用。
2. 从固定锚点探索先验重建概率，不能把actor-1行为概率作为先验后再叠加完整残差；检查未更新时概率、梯度和导出parent/iteration。
3. 只用本批当前模型的96条完整轨迹，按既有终局信用做一次预先登记、受概率变化约束的更新；不混入探索或旧actor-0轨迹。
4. 检查Torch/NumPy/WSL概率和选择一致后，再登记父模型、新模型、探索及Dual16的开发配对比较。

不自动扩成第三批，不扫容量或步长，不恢复H1/H32代理或正式TTF。若更新后仍无法重复净完成增量，
应重新评估“稀疏零一终局、每条件四次采样”的信息来源，不把不断增加同类采集当作进展。
正式控制器及历史结论保持不变。
