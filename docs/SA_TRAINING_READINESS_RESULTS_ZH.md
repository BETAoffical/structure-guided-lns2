# 退火数据重训准备度审计结果

## 结论

SA确实打破了旧单调流程中“成功之前的修复条件不能再次出现”的限制，但现有成功经验很稀疏，并且几乎都已被原排序器选中。它主要帮助返回已有冲突水平，尚未提供突破历史最低冲突的证据。

现有数据不足以直接训练并验证一个更好的SA候选排序器。这里不是认为机器学习无用，而是区分：已执行动作的轨迹、可复用的历史反馈、同一状态下多个动作的监督标签。

本轮没有运行求解器、采集修复标签、训练模型或计时。保留原Dual16+SA。

## 样本与验收

- 107/107条已有SA轨迹完成只读审计，22581次已记录transition；20个分析进程。
- 96条120秒来源与11条300秒失败并集来源有重叠，以下分开报告，不能合成107个独立任务。
- 输入文件SHA、初始/终态fingerprint、动作对应与接受公式通过；逐步delta重建一致。没有重复执行先前已完成的物理路径搜索验收。
- 审计0错误；原轨迹分别有7次和6次不完整PP尝试，保留为censored，不作为失败标签，两组数量不可直接当作独立超时总数。
- 40项相关测试通过，覆盖前置历史、截断处理、外部路径失效、非连续ID、四trial聚合及缓存文件防篡改。
- 新模型0，新求解器调用0，新TTF episode 0。没有重跑CTest或修改native。

## 1. 退火后能复用多少正反馈？

“同条件”要求所选agent与起终点、全部外部路径、地图、旧受影响冲突对数和动作协议相同。正反馈仅指此前完整尝试曾降低冲突，不等于完成整场任务。
下表所有历史统计都在当前动作执行之前计算，未把当前结果或未来完成情况用作输入。

| 观测 | 120秒全组 | 300秒困难并集 |
|---|---:|---:|
| episode / 地图 | 96 / 8 | 11 / 3 |
| 决策次数 | 11562 | 11019 |
| 同一agent集合已有下降记录的被选动作 | 2211 | 4327 |
| 同一可见修复条件已有下降记录的被选动作 | 202 | 90 |
| 候选池中存在任何同条件正反馈的决策 | 206 | 93 |
| 上述决策比例 | 1.782% | 0.844% |
| 有正反馈但未被选中的候选槽位 | 4 | 3 |
| 选中有正反馈条件后再次下降 | 133 | 58 |
| 其中刷新本episode历史最低冲突 | 0 | 0 |

在存在正反馈的决策中，原模型已分别202/206、90/93次选中那个条件。故“让模型记住成功集合”不是当前遗漏的大量机会。仅按集合累积2211/4327次历史会混合已改变的外部路径条件。

这不是证明该键之外不能泛化：监督模型可能从相似但不完全相同的条件学习。也不是同键PP结果同分布的证明：随机顺序、截止时间及隐藏native历史仍可能影响结果。问题键只描述可见条件，不能直接做结果缓存或无校准成功概率。

增加精确温度与预算后，两组重复数均为0。温度本来就逐轮变化，这个零由键定义影响，不能作为“不存在可学习价值”的证据。

## 2. 失败历史也不能直接变成禁用标签

| 观测 | 120秒全组 | 300秒困难并集 |
|---|---:|---:|
| 同条件有过不下降记录、当前PP完整的尝试 | 2923 | 6589 |
| 其中当前仍然严格下降 | 194 | 127 |

因此“曾经不下降就屏蔽”会排除实际仍有下降能力的尝试。是否排除后影响整场完成尚无反事实验证，不能把194/127称作确定会损失的成功任务。

连续32步未刷新历史最佳的区域也存在这种情况：两组分别有134、94次下降发生在同条件已有不下降记录之后。重复既可能是无效循环，也可能是有用的随机重试，单个失败次数不够区分。

本结果支持历史Feedback Exploration/HistoryRank的边界：不能重新引入永久禁忌、固定新颖度惩罚或按重复次数强制换候选。

这些候选没有完整的SA后续反事实标签。旧H4数据和本轮回温数据不能直接拼接：状态、动作及后续策略不同。轨迹中的未选动作也没有真值，不能通过读取它们的模型分数补成训练标签。

## 4. 对“是否重训”的实际决定

1. **不做只换数据量的重训。** 已选轨迹可以作为行为数据，但模仿SA接受动作会把随机放行混入标签；它不回答未选候选是否更好。
2. **不把旧失败实验改名重做。** 旧HistoryRank已测试新颖度和多个单特征；Feedback Exploration已测试反馈/随机探索及延续。本次新问题仅是非单调条件下正反馈能否复现，现已回答，不自动重开这些控制器。
3. **保留局部机会，不夸大负面结论。** 退火历史复用实际存在，原排序也存在个别遗漏；它们还没有组成稳定的、跨地图的脱困监督信号。本轮不能证明重训永远无效，也不能证明一步排序是唯一根因。
4. **如另行推进训练，先冻结新的数据问题。** 必须明确训练的是修复后接受价值还是修复前候选选择；保持PP/候选/接受机制固定，在独立地图的SA访问状态上获得同状态替代动作证据。需要区分容易成功、可恢复平台和残余困难条件，不能只采失败案例。
5. **先有标签证据，再批准新采集。** 旧H4稳定性失败仍有效，不直接复制H4扩采或用剩余修复轮数回归替代。只有稳定的、有界后续收益及跨地图验证安排明确后，才值得小规模候选排序重训；本轮不自动启动这一阶段。
