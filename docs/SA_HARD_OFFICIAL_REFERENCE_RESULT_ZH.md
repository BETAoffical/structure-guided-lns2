# 同起点 Official+SA 参考：困难终局仍未补齐

## 本轮做了什么

按[冻结协议](SA_HARD_OFFICIAL_REFERENCE_PROTOCOL_ZH.md)，只增加16条Official+SA诊断。
Train M01和M04的d25任务、solver 233/239、replica 0--3，与既有actor-1、actor-0探索和半均匀采样严格配对。
旧控制轨迹48条直接引用，没有重跑、重训、修改正式控制器或读取M06/M07。
20个配置worker对应16个实际作业；非计时，不以并行运行秒数报告TTF。

每条预算为25,000,000个修复generated nodes，允许最后一次完整修复越界。
没有决策次数上限；native的`max_repair_iterations=0`，256仅是冻结输入尺度。
16/16正常终止，7,884步完整审计通过，0身份错误、0非法动作、0时间保护未知。

Official的8个M04失败都用完节点预算，修复456--611次；整组最高688次。

当前登记结论为`hard_failure_shared_at_fixed_budget_no_success_labels_for_retraining`。
含义是同预算的参考同样失败，不是MAPF无解证明，也不是所有学习方法都不可行。

actor-0也有相近的节点优势，因此更不能把全部优势归因于actor-1的那次新训练。

## 解释边界与下一步

1. 没有发现换回官方选择即可补齐M04成功终局的证据。增加探索与改成官方参考，都没有提供这两个困难条件的正样本。
2. 当前actor已经使用完整终局目标，本轮也没有次数上限。不能继续把失败归因于“一步标签”或旧256步截断。
3. Official保留8-agent邻域和原始native随机流，Dual16保留显式候选与单步PP随机seed。
   相同初始路径、节点预算和SA接受流不等于相同动作空间、PP顺序或温度在节点轴上的进程；本轮不是纯评分器因果消融。
4. 因为没有Official成功见证，原计划有条件的“复现成功轨迹并检查候选覆盖”分支本轮不启动。
5. 不自动追加actor-3、探索比例、H1/H32标签、重温参数或更多树参数；历史已有失败或不稳定记录。
6. 不再重复已经完成的信用数量审计：上一批actor-1只有4条件/3地图提供非零终局系数，这一点已知。
   若继续新模型路线，优先另行预注册小规模的训练难度过渡方案，而非第三次同配方更新：在Train范围补充
   有机会产生完整成败差异的过渡任务；保留原困难d25任务，后续仍检验是否真正改善它们，不删除来抬高成功率。
   已核对旧第二批M04/d20，actor-1成功8/8、actor-0为7/8；说明不是这张地图的所有已测任务都失败。
   但d20/d25是不同完整OD任务，不能仅凭该对比证明agent密度是唯一原因，过渡采集尚需独立设计与固定预算。
   本轮没有执行额外扩采、预算上调、底层替换或正式计时，也没有宣称共享瓶颈的具体原因已经查清。
