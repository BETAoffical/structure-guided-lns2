# 固定双seed重启：只读预算核算

2026-09-21。本协议在本轮核算前登记，但源结果已经查看过；不是新数据预注册，也不是正式TTF确认。

## 要回答的唯一问题

旧高压力首解记录中，同一方法的两次初始化是否具有足够互补性，值得再实现一次有预算重启？
不回答新选择器是否更好，不训练，不采集，不改变正式控制器。

此前CPLNS重启消融在SA臂未触发重启，非SA仅一例触发；不能据此否定一般重启。
此前独立双轨和节点分配比较的是不同搜索策略，不能代替同方法换初始化seed。
这也不是重新尝试停滞阈值、回温、后失败CBS或邻域闭包。

## 固定设计

- 复用8张仓库地图、48个静态任务、seed 61/62的120秒首解记录。
- 三臂主批次：Official、Dual16、Dual16+SA；补充批次只取Official+SA。
- 不重复计入补充报告中复制的96条Dual16+SA。
- 每个方法分别做两种固定顺序：61先62后，以及62先61后。不得看结果后选择有利顺序。
- 单段60秒，总预算120秒。首段60秒内完成即停止；否则计入完整60秒，再给另一个seed最多60秒。
- 第二段使用源TTF，包含该次reset和初始PP；不使用min(两次TTF)，不免费合并两次成功。
- 对照是同一个首seed连续运行120秒。48个任务各有两种相关顺序，不称为96个独立任务。
- 两顺序等权汇总；同时报告分顺序、分地图结果、新增成功、成功损失、被截去的60秒后成功。
- 失败的原始TTF仍为null；120秒封顶时间只用作全组预算账本，不伪称实际失败TTF。
- 5,000次地图级配对bootstrap仅作开发性描述，两顺序和同图任务一起重采样。
- 不搜索30/40/80等截止点、不换seed、不拟合重启触发器，不根据结果补更多trial。

## 必须保留的限制

这是“保持历史前缀行为、切换额外开销为零”条件下的日志核算，**不是真实重启性能，也不是无条件理论上界**。
真实短时预算可能改变PP最后一次搜索；中止、清理、环境重建及切换开销尚未实测。
源TTF从reset前开始，不包括冷启动、模型加载和最终路径交付开销；本轮不推断机器人整批完成时间。
跨批次机器环境差异仍存在，不能从四方法核算表推出同期因果速度排名。

## 核验与停止规则

核对源报告、登记、manifest固定SHA；检查每项binding/result/initial/supervisor摘要文件SHA、排程身份、native身份和TTF一致性。
检查48个相同任务、各两seed、四方法同任务同seed初始fingerprint一致。地图、scenario及任务文件与登记SHA一致。
本轮不重新解析所有轨迹或重做路径合法性验证，原完整验证保留；报告明确这个验证范围。

每方法均保留两顺序，不通过选择顺序或方法形成新控制器。只有等权新增成功多于损失，且封顶时间降低，才记为“值得考虑一次运行时等价性验证”。
这个筛查不要求每张图胜或5%提升，也不能自动晋级。无净机会则停止本固定60+60方案，不继续扫参数。
任意正信号只能进入独立的短预算前缀/安全停止验证，不能直接安排完整计时、重训或RL。
