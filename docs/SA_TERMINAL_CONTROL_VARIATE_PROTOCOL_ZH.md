# 完整终局梯度的交叉拟合基线审计

2026-10-01。承接[新随机流复测](SA_COMPLETION_REPLICABILITY_RESULT_ZH.md)。
只读既有四个Train条件的原4及新16条轨迹，不采集、不训练、不做TTF、不自动晋级。
本轮是已查看任务上的开发性诊断；穷举分组不是新增独立样本。

## 历史排除与文献边界

旧Ridge状态基线已显示Brier和梯度离散度代理变差，不能再次换参数重复。
本轮不拟合状态成功率模型，而是检查完整轨迹score与终局回报的关系，
并比较“平均回报基线”与“梯度强度加权基线”。

[Greensmith、Bartlett、Baxter，JMLR 2004](https://www.jmlr.org/papers/v5/greensmith04a.html)
讨论控制变量及最小方差基线，指出平均回报基线不总是最优。
原文主要研究GPOMDP与相应假设；本轮不是其算法复现或保证的移植。

本项目的完整终局score为`S=sum_t grad log pi(a_t|s_t)`，回报R仅为终局成功0/1。
在完整轨迹、期望score为0及矩存在的条件下，常数b不改变期望梯度；
最小化`E[(R-b)^2 ||S||^2]`的常数为`E[R||S||^2]/E[||S||^2]`。
这是对本项目完整轨迹向量的控制变量推导，不继承原文平均回报过程的定理。
有限样本估计它未必能降方差，必须在没有参与拟合的轨迹上检查。

## 固定比较

1. 原LORO：每条使用其他replica平均终局回报，复现参考梯度。
2. 等分交叉拟合mean：另一半轨迹的平均回报作为基线。
3. 等分交叉拟合score_squared：另一半轨迹的`sum(R||S||^2)/sum(||S||^2)`作为基线。
4. 同批拟合的最小二阶矩常数只作“单个常数基线类”中的oracle诊断下界；
   它不是所有状态/交叉拟合基线的下界。读取评价回报，不能用于训练或晋级。

对新16条穷举全部6435种不重复的8/8划分，旧4条为3种2/2划分。
每次两半互作拟合集和评价集；评价轨迹的任何回报或score不能拟合自身基线。
固定四条件各等权，全部保留，全成/全败与零梯度不伪造成方向。
只减动作无关的另一半基线，不按长度缩放score，不裁剪失败，不加入单步、成本或静态上下文奖励。
零score能量的拟合半回退为该半平均回报并计数，不调平滑参数。

## 输出及解释

- 报告每条件的LORO、交叉拟合二阶矩、中心离散度、分组方向敏感性和基线范围。
- 使用replica Gram矩阵计算，避免生成“6435分组×参数”的巨大张量。
- 分组共用原16条，不是6435次独立实验；中心离散度和分组敏感性都不是无偏真实梯度方差。
- 二阶矩下降只证明当前数据的描述性降噪信号，不证明更新有益、成功率更高或TTF更快。
- 固定描述性信号：新四条件等权的交叉拟合二阶矩至少下降10%，
  且任一有正负终局的条件不能增加超过10%。允许条件间取舍，不要求逐轨迹全胜。
- 有信号也只允许另立新数据确认；无信号保留A，不自动加trials、换阈值或做A3。
