因此不能用一个约18%的孤立数字断定此次失败由分布外特征导致；模型在这些新状态的有效性仍未验证。

## 与历史合并后的判断

- [旧300秒延长](SA_PRESSURE_300S_RESULTS_ZH.md)没有普遍解决长尾，不能再次把延长预算当新算法。
- [冷却审计](SA_COOLING_TRACE_RESULTS_ZH.md)已区分高接受率失败与低温拒绝；
  [有限回温](SA_BOUNDED_REHEAT_RESULTS_ZH.md)也未带来主要组新增完成，不再自动扫描温度。
- [课程更新](SA_CURRICULUM_UPDATE_RESULT_ZH.md)没有把450车子任务的终局信号迁回完整500车。
- [原任务支持诊断](SA_ORIGINAL_TERMINAL_SUPPORT_RESULT_ZH.md)在M00/M02产生混合终局，M04仍缺成功样本。
- 当前actor已经使用完整终局目标，不能再次把问题笼统归咎于仍只优化一步下降。

本轮结论固定为`no_recovery_with_fixed_extra_work_stop_budget_scan`。
这不是被统计显著性或要求所有任务都胜出的门槛挡住：四条续跑确实没有一个可行终局。
同时这只是一个根，既不证明模型路线不可能，也不证明任务不可解。

## 下一步边界

1. 停止25M→30M这条预算扫描，不自动改成35M/50M，不追加相同探索配方或actor-3。
2. 困难原任务缺少可供区分动作的成功信息，仍是当前训练合同的实际缺口；
   增加这四条全失败轨迹不能凭空提供该根的成功方向。
3. 继续新模型前，先解决“原任务的候选/修复中是否存在可到达终局的信息来源”，
   不能把双端覆盖、被SA接受、一次冲突下降或子任务成功当成它的替代标签。
   若另立小规模反事实，必须针对这里尚未观测的动作结果，与历史PBS、路径重选、H32案例逐项排重，
   不能再做一轮同名异义的通用回退测试。
4. 保留旧正式控制器及其正负结果；本轮没有新模型晋级，不修改任何TTF或成功率主张。
