# SA策略预算对齐单轮更新：开发结果

## 结论

本轮已完成12个control、768个标签分支、一次模型训练，以及修复加载器后的24条开发闭环。
新模型没有获得净改善，判定为`no_net_signal_do_not_repeat_parameters`，不替换Dual16+SA，不自动进行第二次更新或TTF。
这是针对高层选择器的一次有界原型，不是官方LNS2、原V2、Dual16或所有策略迭代方法的失败结论。

| 方法 | 128次修复预算内完成 | 资源截断/未知 | 修复generated nodes合计 |
|---|---:|---:|---:|
| 冻结Dual16+SA | 2/8 | 0 | 91,126,523 |
| 更新前47状态GBDT | 0/8 | 0 | 88,296,316 |
| 本轮预算对齐GBDT | 0/8 | 0 | 72,492,936 |

两个留出地图各有四个任务-seed组合，新模型在两图上均比Dual16+SA少完成一个。
新模型的节点总量少20.45%，但它没有完成任务，且8个组合的最终冲突数全部高于Dual16+SA。
这不能称为TTF加速。共同成功集合为空，不能计算共同成功时间/工作量比，更不能把失败填成零。

## 本轮改了什么

- 以前的标签是单次选候选、随后旧Dual16+SA续跑；本轮同时保留旧Dual16+SA和旧GBDT两条续跑结果。
- 使用旧GBDT实际访问的状态；按预先固定哈希选6图，每图一条episode，取decision 0和16，共12根状态。
- 每根4个候选、8个PP/SA配对trial、2种完整续跑器，共768分支。两种续跑器必须有相同首动作后继。
- 标签是两续跑器在固定工作预算下完成率的等权平均；不是一步下降、剩余轮数或Cost-to-Go标签。
- 预算继承原episode：总128次修复、2500万修复generated nodes，decision16根最多剩112步。
- 127维动态候选输入加剩余决策预算和剩余节点预算。固定参数GBDT，只训练一次，不调参。
- PP/SIPPS、SA、候选池与正式控制器未修改。20进程诊断耗时不是TTF。

节点预算在修复之间检查，并非SIPPS内部严格节点中断器；本轮所有非成功闭环实际均停于128次上限。
初始PP不计入修复节点预算。没有资源安全超时、未知标签或自动加预算。
标签实际执行73,746次修复，前缀重放另外6,144次；12个单步control另计。
长时间主要花在采集和轨迹核验，GBDT拟合命令本身只用数秒。

## 标签与拟合诊断

以下是事后描述，不参与训练参数或模型类型选择。分母为12个根状态，地图等权；不是768个独立地图样本。

| 训练状态上的选择 | 两续跑器平均完成率 |
|---|---:|
| Dual16 anchor | 36.98% |
| 更新前GBDT | 36.98% |
| 本轮模型 | 41.67% |
| 四候选均匀随机经验期望 | 35.94% |
| 同一批trial上的样本内最佳 | 41.67% |

1. 12根中4根所有候选均未完成，全平局；只有8根存在经验完成率差异。
2. 新模型12/12根选中样本内最佳；排除平局也是8/8。这说明训练拟合不差，不支持优先增加容量。
3. 样本内最佳比anchor高4.69个百分点，但它受到同样本选赢家的偏差影响，不是可信上界。
4. 将trial 0-3与4-7分半，在一半选候选、另一半评价，再交换两半，平均对anchor收益为-0.52个百分点。
5. 42个在至少一半样本存在严格差异的候选对，仅10个在两半保持同向严格差异；其余包括另一半平局和反向。
6. 固定首动作后，Dual16+SA续跑完成233/384，旧GBDT续跑43/384。总体续跑差异明显，
   但不能直接把它当成每个候选间排序都可靠的证据。

半样本每候选只有4个trial，上述结果不能证明真实动作差异不存在；它说明当前经验赢家不稳定，
不能凭训练集100%最佳命中就认为学到了可迁移规律。没有重新抽trial或挑选有利的分半。

## 闭环覆盖与逐例结果

新模型执行1,024个决策，其中：

- 888个发生在decision16之后，占86.72%；本轮训练根只覆盖0和16。
- 900个至少一个预算特征超出训练坐标范围，占87.89%。
- 870个偏离当时Dual16 anchor，占84.96%。这不是非法动作，也不直接证明降低介入频率会有效。
- 全部候选输入坐标中约10.92%超出训练各列最小/最大范围。

这只是覆盖描述，不是因果归因，也不是可直接部署的回退阈值。
新模型是在拟合后才进入连续闭环；混合旧参考/旧学习器续跑也不等于已学会更新后的自身完整价值。

## 与历史的联系及下一步

本轮确实训练了新模型，并非又转去寻找更便宜的一步修复。
但仍复现了历史的两类风险：样本内排序好并不能稳定选择新trial赢家，早期根状态也没有覆盖持续接管后的状态。
因此不能把失败简单归为树太少、SA本身有bug、一步最优，或要求每张地图全赢的门槛太高。
本轮甚至没有5%门槛；观察结果本身未超过保留策略。

当前停止这一轮原型，不增加树、不自动第二次拟合、不将失败数据清零或删除。
若继续训练，应先解决可验证的两个前提，而不是直接扩大同配方采集：

1. 用保留轨迹登记少量中后期根状态，覆盖实际剩余预算；不能继续只在0/16训练后让模型接管128步。
2. 在任何新拟合前，用独立trial评价候选选择收益及其不确定性，区别真实差异与样本内赢家噪声。
3. 只有出现可重复、规模适当的信号，再做有限策略更新，并保留Dual16+SA同预算闭环对照。
4. anchor门控、介入频率、容量、时空网络、单步成本、PP/PBS回退已存在历史负面结果，不能换名当新方案直接部署。

这些是后续方案的约束，不是本轮已经验证的修复方法。一次有界原型失败不能排除完整策略迭代，
但当前也没有依据承诺重训或增加数据就能解决长尾。静态上下文迁移、RL与正式TTF均未恢复。
