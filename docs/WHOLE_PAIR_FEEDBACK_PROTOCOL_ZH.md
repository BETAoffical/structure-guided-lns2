# 整对路径协调与对外冲突保护：独立机制预注册

## 假设与边界

前一轮单事件前缀反馈没有通过门槛：避开指定事件后仍可能存在同一车对冲突；即使目标车对消失，后缀仍可能超出冲突预算。本轮测试完整两车路径的协调，而不是追加前一轮第五次重试或重新解释其 NO_GO。

Official、V2、Dual16、模型、原生二进制、邻域成员及插入顺序保持冻结。不训练、不修改正式控制器、不执行串行 TTF，不自动启动计时。

本轮全部为已查看的开发状态，不得宣称独立确认或上线收益。

## 数据与控制

- 使用前一轮同样 24 个状态、4 张地图、两个 PP seeds，共 48 条件。
- 所有状态和条件均保留，包括快速对照、成功长尾和失败长尾。
- 复用已独立验证的 192 个旧对照结果：ordinary、random_retry、directed_resources、prefix_resources。不冒充新运行了这些对照。
- 新运行 `whole_pair` 与 `whole_pair_guarded`，各 48 个，共 **96 个新作业**。每个新作业重新运行普通 PP，科学签名必须匹配冻结普通结果。
- 配置、实现、源报告、验证证书、模型相关既有登记、native 与输入均哈希绑定；不允许旧新数据混跑。

## 两种新方法

两方法共有步骤：

1. 普通 PP 回滚，或接受但路径完全不变时才触发。
2. 使用前一轮固定累积前缀关系排序，最多两组 blocker/victim 关系。
3. 对后车计算与前一轮相同的参考路径：暂不计指定前车，外部和先前前缀路径仍进入软冲突表。此参考搜索的展开量与耗时全部计入预算。
4. 不只约束一个事件。以该后车参考路径的全部顶点占位、反向交换边以及终点等待作为前车硬约束；前车成本不得超过普通尝试中的原成本。
5. 前车和其间车辆按原顺序规划；轮到后车时，直接插入已计算的参考路径，不再次自由选择另一条路径。之后继续原顺序的整个邻域后缀。
6. 每次插入均沿用官方唯一冲突 agent 对的累积预算，超出即回滚。只有整个邻域完成且全局冲突严格下降，才选用替代结果，否则精确保留普通结果。

因此这是 **带前瞻参考路径承诺的两车协调**，不是不加说明地更换官方 PP。它保持车辆插入顺序，但改变了路径决定的时序。

`whole_pair` 仅实施上述整对路径协调。

主方法 `whole_pair_guarded` 额外保护这两辆车的对外冲突：

- 若后车参考路径新增了普通后车路径未碰撞的外部 agent，直接拒绝该选项。
- 前车硬约束再加入普通前车路径原本不碰撞的外部车辆的完整时空占位。原本允许冲突的外部车辆仍保持软冲突语义。
- 保护的是每辆选中车对外冲突 **集合不扩大**，不只是数量不增加。
- 不保护所有后缀车辆；其余车辆仍可能新增冲突，因此必须保留整轮预算检查，不能以局部通过代替整体成功。
- 不移动任何外部车辆，不扩展邻域，不变更顺序。对外保护失败不能证明必须移动外部车辆。

## 预算与资源

- 两组关系各最多两次前车重搜，按“第一组、第二组、第一组、第二组”交错顺序分配，最多四个选项；参考路径不可用的关系不生成选项。
- 每次替代 seed 为原 seed 加选项序号加一。第一次严格改善后停止，不依据输出另选更优分支。
- 每作业 30 秒、每次搜索 5 秒、外部 fuse 60 秒；不自动增加次数、关系数、成本上限或超时。
- 最多 20 个独立进程，低于 3 GiB 可用内存停止派发。支持 STOP、逐作业原子结果、锁和身份一致的 resume；错误停止新派发、保留输出并检查。
- 96 个新作业的外部 fuse 串行上限约 96 分钟，20 进程仅是理想并行预算估计，不是 TTF 或性能预测。额外包括准备、路径校验及汇总。
- 有限成本前车的约束覆盖到 `max(前车成本上限, 被避让路径结束时刻)`；到达后持续等待纳入检查。不增加或重编译 native 接口。
- 已预付的后车参考路径复用时搜索计数置零，明确标记 cached；其参考搜索时的 low-level collision 数不冒充新前缀下的碰撞数。实际冲突从完整路径重新计算。

## 门槛与报告

主方法固定为 `whole_pair_guarded`，不从两种新方法中事后选赢家。`whole_pair` 用来解释保护约束的影响。

1. 96/96 新条件完整，无错误、预算删失、普通基线差异、非法路径、整对路径约束或外部保护失效。
2. 至少 3 个“两 seed 均触发”状态在两个 seed 均新增严格改善，涉及至少 2 张地图、至少 1 个失败长尾状态。
3. 稳定恢复数不低于旧恢复对照，并至少有 2 个稳定状态为新主方法独有。
4. 每条件最终冲突不劣于普通 PP；额外计算开销必须完整报告。

分别报告新增恢复、严格下降、失败长尾、双 seed 稳定性、展开/生成数，以及前车找不到路径、后车尚未插入即回滚、整对已消除但后缀回滚、参考对外保护拒绝等类别。

若整体无收益或大量未知，停止此轮，不加 trials、不改 guard、不直接进入 CBS/RL。即使通过，也只允许进一步独立机制和原生事务验证，不自动执行正式计时。

## 运行前验证与命令

验证完整路径约束与顶点/交换/终点等待冲突一致，成本上限、参考路径计数、精确回滚、非法输出拒绝、源 SHA、暂停续跑和原生冻结语义。源码和协议须在真实 24 状态运行前推送。

```bash
python scripts/diagnose_whole_pair_feedback.py prepare
python scripts/diagnose_whole_pair_feedback.py dry-run
python scripts/diagnose_whole_pair_feedback.py collect --workers 20 --max-jobs 20
python scripts/diagnose_whole_pair_feedback.py verify --partial
python scripts/diagnose_whole_pair_feedback.py collect --workers 20 --resume
python scripts/diagnose_whole_pair_feedback.py verify
```

数据写入忽略目录 `build/initlns-whole-pair-feedback-v1`，旧报告和原生构建保持不变。
