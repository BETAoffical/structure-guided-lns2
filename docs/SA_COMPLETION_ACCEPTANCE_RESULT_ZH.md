# 冻结A的SA接受器消融结果

## 结论

48次串行运行及48条完整轨迹审计已完成。**保留冻结A的SA，不改为只接受非恶化的版本。**
在24组条件中，A+SA成功24组，complete-greedy成功15组，新增9个成功、没有丢失成功。
本批的成功率差为37.5个百分点，5000次地图级配对bootstrap区间为[16.67,58.33]个百分点。
这是当前模型、任务和预算下的接受器收益，不是SA在所有环境中的保证。

共同成功15组的TTF均值下降34.38%，但差值区间跨零，不能声称稳定的普遍加速。
本轮没有重训、修改候选生成、PP/SIPPS或native；默认控制器不变。

## 实验边界

- 来源是已查看的12张station_centric仓库地图，每张d20/d25两个任务，统一solver seed281。
- 24组配对、两个接受器、48次运行；每次120秒规划预算，240秒进程保险，无决策次数或节点上限。
- 两臂均完整执行同一PP尝试，仅最终接受谓词不同。complete-greedy拒绝冲突增加，但接受冲突相等。
- complete-greedy不是带提前退出的官方标准PP，不得写成A与Official对比。
- 模型的温度输入保留原日程作为虚拟时钟；否则会同时改变模型输入，而非只改变接受器。
- 两臂重新单worker计时，顺序均衡；准备和审计20进程，不计入TTF。
- TTF从reset前到首次可行返回；路径校验、保存后的交付时间另报；冷启动和模型加载另计。
- 数据不回流训练。这是开发消融，不是独立地图确认，也不与其他批次合并成功率。

## 机制解释与不能推出的结论

SA共3382次修复、3382次完整尝试，1087次恶化中接受1057次。
greedy共8469次修复、8461次完整尝试，5946次恶化全部拒绝；未完整的8次须与预算到期分开。
两臂访问状态不同，这些总数不能当同一组尝试的逐动作因果比较。
实验支持“当前A仍需要暂时接受恶化来提高完成率”，不证明每一次恶化必要，也不证明所有一步学习都不可行。

本轮没有包含上一批A失败的M05/d25/283、M10/d25/283、M10/d25/293。
**原来的69/72和三个未解案例完全保留，24/24不能写成长尾已经修好。**
旧预算冷却、有限回温、强均匀探索的负面结果也不被覆盖。下一轮不重复扫描温度。
