# 证书补车的一次性干预延续

准入：证书单车扩展在四trial中至少两次完整严格下降。本轮按最小平均剩余冲突、再候选ID确定一个开发候选，不隐瞒已经查看结果。

精确重放原745步前缀，原native、模型、完整fingerprint和首步候选池完全一致后分支。三臂为原冻结选择、首步加入该外车、首步用该外车替换最小ID的无冲突填充成员。
替换不删除任何当前冲突端点，但不假定无冲突成员永远无用。后续全部使用原Dual16候选、排序、PP及原绝对轮次退火；不重复强制补车。

每臂四trial，共12个独立分支，最多64步（包含首步）、5000万generated节点、120秒安全预算、单PP5秒、硬fuse180秒。首步随机流与已采四trial配对，后续各臂使用相同显式随机流；不重置退火温度。
父进程只重放一次，再fork独立native/RNG；最多20workers，此处只有12个可并行作业。多进程耗时不称TTF。

保留完整逐步候选、动作、接受随机量及路径delta，重新验收路径、回滚、全图冲突和父状态不变。报告末次冲突、目标冲突复发、完成数、节点和删失。只减少一对冲突却仍停滞不算长尾解决。
这是一个地图、一个已查看状态的后验机制验证，不晋级默认控制器，不训练，不追加延续时长或trial。
