# 最近 47 状态 GBDT 的确定性重建

本轮只补上一轮因没有保存权重而缺失的预测。不是新模型搜索，不恢复神经模型，不新增标签或求解器调用。
旧报告、索引、模型参数、特征及正式控制器保持不变。

## 固定过程

1. 固定 `sa-spatiotemporal-model-probe-v1` 的 47 状态旧索引、8 折 GBDT 分数、输入和实现 SHA。
2. 原样重建 `gbdt_job`：127 维输入，原 H32 配对完成率差，原地图等权和状态内配对权重；
   保留 `HistGradientBoostingRegressor(loss=squared_error)` 及原 `MODEL_PARAMS`、sklearn 1.5.0。
3. 每折完整排除一张地图，不使用本批 376 个新标签来训练、校准或选择版本。
4. 每折全部 47 个旧状态、每个候选的分数及选择必须与原结果完全相同，无浮点容差。
   8 折共 376 行预测、1,504 个候选分数；任一不一致即停止，不调整参数使之“看起来相似”。
5. 保存 pickle 及 SHA 后重新加载，再次核验原预测，全部通过才发布 model receipt。
6. 复用上一轮封存的动作前特征，预测完整的 16 个同来源 size16 候选对，并封存预测。
7. 最后单独读取已有标签，沿用上一轮的完整队列、pair/anchor 对照、地图等权及 5,000 次 bootstrap。

重建记录不能声称找回了原始权重字节；它仅证明固定旧流程重建后精确复现已保存预测。
不添加新特征、额外训练数据、优化目标或 runtime 集成；不按结果挑选折或候选。

## 资源与恢复

最多 20 个 worker，但仅有 8 折作业，所以实际最多 8 进程，每个进程的数值库线程固定为 1。
旧记录每折约 1 秒，预计重建是分钟内的小任务，不进行原神经网络或求解实验。
提供 `prepare/reconstruct/predict/analyze/verify` 入口。整组重建有运行锁；逐折输出原子封存。
完整折续跑前重新验证；孤立 pickle、临时文件或不完整 receipt 不自动覆盖，必须先检查。

## 解读边界

- 这是已经查看过的开发数据，不是新地图独立确认。
- H32 分支完成率不等于端到端成功率、真实 TTF 或机器人执行时间。
- 不设置新的晋级门槛。报告相对均匀选择、anchor、历史 16 状态模型的幅度和区间。
- 8/8 对 3/8 的案例只作解释，同时保留其他 15 个状态，不能据此筛选训练数据。
- 结果不触发自动调参、训练新架构、扩采或正式计时。原 Dual16、SA、PP 和 native 保持冻结。

新代码、配置、测试、协议先本地提交和备份，再进行重建；输出保存在忽略的
`build/sa-recent-model-reconstruction-v1`，不覆盖前一轮不可评估记录。
