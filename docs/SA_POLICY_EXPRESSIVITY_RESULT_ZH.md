# 新模型能否替代Dual16首选：表达范围核验

2026-09-24。结论：**当前on-policy原型确有强先验与有界残差共同造成的表达限制；但尚未证明它是当前失败的原因。**
本轮只读已有192条Train轨迹，没有新增求解、训练、改SA或正式TTF。
当前原型不是早期V2的pairwise GBDT，而是围绕冻结Dual16锚点的129维、小型残差策略网络。

## 2. 数学限制在哪里

设本状态有K个实际候选，Dual16选择的候选称为anchor：

```text
q(anchor) = 0.9 + 0.1/K
q(other)  = 0.1/K
r(a)      = 2*tanh(network(a)), in [-2, 2]
pi(a)     = q(a)*exp(r(a)) / sum_b q(b)*exp(r(b))
```

一个具体的其他候选b要超过anchor，需要：

```text
r(b) - r(anchor) > log(q(anchor)/q(b)) = log(9K+1)
```

允许的最大残差差只有4。K>=6时，右侧已经大于4。
**因此在这些候选数下，不论增加训练次数、换多少数据，保留这套输出合同就不可能让某个其他候选成为概率最高项。**
这说的是策略族的表达边界，不是说采样永远选择anchor；所有其他动作仍有正概率。

| 候选数K | 超过anchor所需差值 | 任意一个其他候选的概率上界 | 所有其他候选同时抬高时anchor概率下界 |
|---|---:|---:|---:|
| 17 | >5.0370 | 24.42% | 14.99% |
| 18 | >5.0938 | 23.37% | 14.94% |
| 19 | >5.1475 | 22.41% | 14.89% |
| 20 | >5.1985 | 21.53% | 14.86% |

两个极值对应不同残差分配，不能同时达到。它们是独立残差盒的上下界，实际共享网络未必能达到。
即使所有其他候选的总概率超过50%，每个单独候选仍可能低于anchor。
所以“更多随机探索”和“学会集中选择一个正确替代邻域”不是同一件事。

## 3. 实际轨迹核验

固定第二批Train数据：六张已见地图、192条原轨迹，actor-0/actor-1各96条。
26,041次决策全部重放概率及实际采样选择通过，最大概率误差2.22e-16。
这是Windows概率重算与已审计WSL记录的对照；不重新生成候选或调用native修复。

两个actor访问不同轨迹，表中均值不是完全同状态配对因果比较。
在actor-1自己的13,423个输入上，换回未训练先验并复用同一draw，会改变444次选择（3.31%）。
这只是一种固定输入回放，不是另跑444次MAPF，更不能直接转换成成功率。
相同输入下平均概率总变差0.005694，最大0.017402。

26,041是关联决策数，不是独立训练样本量；独立地图仍只有6张。
原80/96与78/96完成数仅从来源保留，不是本轮新测成绩。

## 4. 这是否解释了所有失败

**不能。需同时保留两条结论：**

1. 表达限制真实存在。若研究目标是一个可替代旧首选的选择器，这个保守残差设计与目标不完全相符。
2. 当前权重远未触及残差差上界：最大仅0.242，对比允许的4。因此不能说本次训练已经被边界截住，也不能承诺取消上界就能提高成功率。

原实现符合当时冻结的“保守残差”设计，不是概率计算、模型加载或随机抽样的执行bug。
必须修正的是研究描述与下一版表达合同，不能追溯改写旧结果。
当前仍受稀疏终局信用、少量独立条件、梯度方向波动和困难状态缺少成功候选见证等限制。
更强探索、课程、H32和局部补车的历史负面结果没有被这一公式推翻。
此分析也不能证明Dual16的anchor总是错误，或者一个更自由的选择器必然更好。

## 5. 下一步怎样改，才不是重试旧方案

建议先补一项**无求解、无训练的下一版策略表达合同**，而不是立即再收数百条轨迹：

- 冻结当前actor-1为父策略，零初始化的新策略必须在每个候选上完全复现父概率和原随机draw选择。
- 候选评分增加可学习的原始logit修正；偏移由单次更新相对父策略的KL约束控制，不用一个永久上界禁止超越旧首选。
- 在构造输入上验证：模型既能保留anchor，也能有针对性地让任一指定其他候选成为最高概率项；候选置换不改变对应结果。
- 不把单纯提高均匀随机比例当作该模型的实现，不在评价中突然由采样切成argmax。
- 目标仍为完整任务终局成功；不能用未选动作伪标签、剩余冲突均值或更便宜的一步来回避信用问题。

这些仅是下一版的设计条件，**本轮没有实现或训练该策略**。
合同通过后仍需另立一次受控on-policy训练与未训练同分布对照，报告新增和损失成功；
没有新数据/训练预算登记前不自动重用旧批次反复拟合，也不解封Validation/OOD。
无需要求每张图都赢，但不能用表达能力、离线loss或动作变化代替实际完成收益。
