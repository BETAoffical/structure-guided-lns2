# 首次策略更新：幅度很小，也存在方向噪声

2026-09-22。[固定诊断协议](SA_ONPOLICY_GRADIENT_PROTOCOL_ZH.md)。本轮读取已审计的96条Train轨迹，
最多20个NumPy进程；没有调用MAPF求解器、训练新权重、改变归一化、读取留出标签或运行TTF。
本次分析不是新模型成功率测试，也没有重做H32/一步排序。

## 1. 更新计算核验

只在actor-0输出层为零这一特定点，使用精确公式分解每条完整轨迹的输出层score。
地图/任务等权、同条件其余replica基线、整条轨迹求和均与原训练一致。

| 检查 | 结果 |
|---|---:|
| Train轨迹 | 96 |
| 原行为策略决策 | 12,180 |
| PyTorch autograd交叉核验输入 | 222 |
| score与autograd最大误差 | 2.4425e-15 |
| 重建梯度范数 | 0.3480195656408185 |
| 已保存更新与重建更新的最大参数差 | 1.3146e-18 |

未发现此次梯度权重、符号或SGD步长执行错误。梯度范数小于1，裁剪没有压缩这次更新。
零输出初始化使首次第一层梯度为零，这是已登记构造的行为，不是PyTorch漏更新。
这些检查只覆盖本次更新，不等于证明整个项目没有任何bug。

## 2. 不是只要调大学习率

首批仍只有3/24个条件出现重复间的成败差异，12/96条轨迹有非零系数。
3个条件梯度范数分别为0.3065、0.2496、0.2819，合成范数0.3480。
合成范数与各条件范数之和的比值为0.4153，存在抵消；这不是“损失了58.5%的成功率”。

| 有信号条件 | 该条件与其余条件合成方向的余弦 |
|---|---:|
| m02 / task_0001 / seed227 | -0.2720 |
| m03 / task_0001 / seed229 | -0.6479 |
| m04 / task_0000 / seed229 | -0.2384 |

对四个replica的全部三种2+2拆分，分别独立计算同条件基线：

| 两半replica | 梯度余弦 |
|---|---:|
| 0,1 对 2,3 | +0.6940 |
| 0,2 对 1,3 | -0.6438 |
| 0,3 对 1,2 | -0.6301 |

正值表示两半建议较相近的参数方向，负值表示相反。该批次的方向明显依赖哪些随机重复被分到一起。
三种拆分共享数据，不是三次独立统计试验，不能据此估计“训练有三分之二概率失败”。
不同任务梯度冲突在共享模型中也不必然是错误；当前只有3个有信号条件，不能将抵消直接归因于模型结构、地图或SA。

这项结果不形成新的“所有梯度必须同向”晋级门槛。它说明现阶段直接放大学习率有放大采样噪声的风险，
而非证明继续训练无效。相比从6次动作改变直接推断“模型没能力”，现在能更具体地区分更新幅度和方向不确定性。

## 3. 后期不是完全没有信息

| 决策阶段 | 决策数 | 隐藏单元饱和均值 | 输出层Fisher trace均值 | 阶段梯度范数 |
|---|---:|---:|---:|---:|
| 0-31 | 3,017 | 3.11% | 4.2858 | 0.1907 |
| 32-127 | 5,805 | 53.12% | 2.6915 | 0.2275 |
| 128-255 | 3,358 | 82.32% | 1.1293 | 0.3010 |

Fisher trace在这里是当前策略对输出权重的局部敏感程度，不是路径修复质量。
后期敏感度较低，但候选隐藏表示仍有差异，后期梯度范数并不为零。
阶段梯度是向量，范数不能直接相加；这些相关状态也不是独立样本。
不同阶段状态分布不同，表格不能证明归一化单独导致敏感度下降，更不能直接宣布修改它会提高成功率。

## 4. 现有一步更新的变化上界

利用隐藏单元在[-1,1]以及已保存输出权重，可得到actor-1相对actor-0在相同输入下的总变差距离上界：
`0.001273113`，即概率质量约0.1273个百分点。实际旧状态上的平均总变差为`0.0000608682`。

该上界是概率分布距离，不是成功率或TTF改善上界，也不是同一个累计概率采样器的动作改变率上界。
多个微小改变可以累积、导致轨迹分叉，因此不能说闭环一定没有影响。
但它确认：当前小步合同确实限制了单步干预量，不能把“两次小SGD更新”当作充分训练后否定新模型。

## 5. 下一步应改什么，不应再做什么

本轮不自动收第二批，不调大学习率，不改PP、SA、候选池或正式模型。

下一轮建议重新登记一个**有界的完整轨迹训练合同**，先解决训练估计，而不是继续堆排序器变体：

1. 保留终局完成目标。不得偷偷换回一步冲突下降、单步节点便宜或旧H32混合标签。
2. 优先考虑与动作无关的状态回报基线来降低估计方差；基线必须在独立episode/fold上拟合，
   不能用同一条轨迹的结果拟合自身基线，也不能引入未选动作的伪标签。是否真降低方差仍需检验，不预设有效。
   它只用于扣除可预期的终局回报，不直接给候选排序，也不预测剩余修复轮数；actor仍按实际完整轨迹更新。
3. 更新强度用预先冻结的概率分布偏移约束控制，并明确总采集/更新上限；不能仅把0.001放大几倍，
   也不在当前旧批次反复训练到喜欢的结果。模型更新后数据必须由新策略生成。
4. 归一化若修改，应与训练基线/更新规则分开登记及比较。现有后期饱和只是风险证据，不一次同时更换所有组件。
5. 在固定小规模预算结束后比较“训练策略”与“相同探索但未训练策略”的实际完成数、删失和工作量，
   允许公开取舍，不增加“每图、每次拆分必须都好”的门槛。最后才决定是否需要独立地图和正式TTF。

这是下一轮设计建议，不是已经实现的新critic、PPO、信任域优化器或新的性能结论。
当前actor-1作为可追溯原型保留，正式Dual16+SA继续不变。
