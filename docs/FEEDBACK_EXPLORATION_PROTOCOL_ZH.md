# 三轮有界反馈探索诊断

本协议只产生历史状态上的开发性机制证据，不改正式控制器、不训练模型、不启动 TTF。
冻结 Dual16 候选生成、模型、原生修复器及原始证据；并行耗时不作为算法速度。

## 固定比较

三个策略使用完全相同的当前候选池。frozen 始终选择原排序器首选。
uniform 与 feedback 仅在首选的当前 repair-problem-budget 条件曾发生未下降时触发。
uniform 从完整候选池均匀抽样；feedback 使用 Beta(1+严格下降次数,1+未下降次数) 抽样。
不永久禁止失败候选。预算不足不记为失败反馈。条件变化时旧反馈不迁移到新条件。
模型分数不解释成成功概率。不控制 PP 顺序；同阶段、案例、trial、决策序号共享 PP seed。
每条轨迹从空反馈开始，不读取该轨迹未来结果或旧 H1 标签进行选择。

## 三轮

1. 使用原 opportunity 的五个状态，包含两个快速对照；每策略四次 trial、最多32步，共60条轨迹。
2. 仅对仍未清零且未截断的后继状态测试新条件。按 feedback、uniform、frozen，案例、trial 排序；每个案例只检查第一个符合者，最多五次准备。最多两个案例、每候选四次 trial，最多160次单步修复。旧初始候选和本轮已选条件不重复测试。无新条件则跳过，不增加参数或预算。
3. 另外三个历史地图来源各取按编号排序、实际存在1至3冲突状态的前两个 checkpoint，在第一个符合状态重复同样三策略、四trial、32步，共72条轨迹。没有该状态的来源列入准备排除清单；每张地图不足两个则停止，不替换地图。历史数据曾被查看，不称独立确认或未见地图泛化。

准备阶段修正：初稿选择前两个编号时发现部分轨迹直接从4或更多冲突清零，未写出计划、未执行新修复。正式冻结前改为上述明确的状态供应规则，不依据新策略结果重抽来源。

最多4384次新增修复，另计原始动作 prefix 重放及最多10次 smoke 修复。
每次 PP 预算5秒，每轨迹诊断预算120秒，独立进程 fuse 180秒，20个进程。
整组累计90分钟，到期不派发下一批，当前批完成后停止。支持 STOP 文件与 episode 级续跑。
每批最多20项，所有输出原子保存；结果错误或身份不一致停止，旧结果不覆盖后重算。
第一轮资源截断达到25%时不扩展，以免把机器预算问题解释成策略失败。

## 预定解释

- 任意资源截断：主分类为证据受预算影响，仍报告完整分母，不将截断当无解证明。
- 恢复信号：第一轮相对 frozen 至少新增两次清零，且第一和第三轮均无配对清零损失。
- 反馈增量信号：满足恢复信号，两轮各自清零数不低于 uniform，合计严格更高。
- 有恢复但不满足上述增量：只能认为探索有帮助，不能称反馈优于随机。
- 不满足恢复：没有一致恢复信号。分析仍失败状态是否存在未选的一步可行邻域。

AUC、末期冲突、动作触发与选择分布用于解释，不能以少一个冲突替代清零门槛。
所有分类均禁止直接晋级或声称成功率、TTF 已提升。下一轮必须另立端到端协议。

## 历史边界与验收

已有简单停滞触发、禁忌/次优替换、单步优势延续、GCBS通用回退、整对约束反馈的负面结果。
本轮不同之处仅是已验证的修复条件键与历史反馈，且设同触发随机对照；若随机同样有效，不重复包装成新的结构贡献。
灵感来自 TACKLE/ADDRESS 的在线反馈思想，不声称复现其算法或继承 anytime SOC 的理论结论。

验证 prefix fingerprint、原始候选与分数、外部路径不变、精确回滚、最终路径合法性及冲突重建。
原生 equivalence 报告 SHA、正式结果、模型登记及实现文件 SHA 必须匹配。
备份并提交协议后运行；每轮保存独立报告，失败原因进入总结，最多三轮后停止。
