## 时钟与执行

完全复用已冻结的 timed_worker 函数体，只替换私有 Policy 绑定。主时钟从 reset 前开始，首次可行 env 返回计 TTF；校验、保存和哈希到交付时钟结束均保留，不扣除不利开销。此前迭代校验与 trace 成本进入 TTF。模型加载及环境构造另报；cold_worker 不含 OS 启动及模块导入。

单 worker、120 秒首解预算、240 秒进程 fuse。无修复次数、决策或节点上限；资源特征中的参考值仍是特征尺度，不是执行限制。失败 TTF 为 null；成功率全分母，原始 TTF 只在共同成功集合配对。不执行第二阶段。

`python scripts/run_sa_raw_fast_ttf.py stop` 请求当前 episode 完成后暂停；`resume` 校验已完成文件后续跑。部分输出或异常不自动重试。计时期间不同时运行其他实验。

## 验证与统计

计时前 36×3 步真实 native 前缀验证，最多 20 个非计时进程；启动前登记代码、输入、模型、配置和 Git 提交，备份注册文件。计时后逐条使用旧特征实现复算全轨迹，再检查同模型两运行时的重叠候选、特征、概率、动作及路径一致性。只有 PP deadline 可以导致路径分叉；快路径多完成的步骤单独解释，不能假定失败最终状态必须相同。

报告 raw_fast 对 raw_reference 与 dual16_sa 的成功数、TTF、交付、选择开销、PP、SOC、makespan 和等待。建模完成时间为交付 + makespan×0.5/1/2 秒，不是机器人实测。5,000 次地图级配对 bootstrap；六图和每图仅两个条件，区间用于表达不确定性。不要求每例都更好，也不因少量案例通过即推广所有地图。

本轮案例已用于工程诊断，是重复案例的工程确认，不是新的独立泛化实验。无论结果如何保留全部输出；不修改旧192条报告。预计计时约20–50分钟，规划预算累计上限72分钟，进程fuse累计上限144分钟，不含验证和调度。
