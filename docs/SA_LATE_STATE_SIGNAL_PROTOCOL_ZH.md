# 中后期候选差异：独立trial复核

## 问题与边界

上一轮新模型训练拟合全部经验最佳，但开发闭环0/8，保留Dual16+SA为2/8。
本轮只问：中后期、继承剩余预算后，某个候选比当前anchor更易完成的差异，能否在新trial中复现？
不训练模型，不启动TTF，不改PP/SIPPS、SA、候选池或正式控制器。

原早期768分支的零成本复核：混合续跑、哈希平局下跨半收益-0.52pp；
平局保留anchor后-1.04pp。仅Dual16+SA续跑、保留anchor平局同为-1.04pp。
因此不是简单改一个平局规则就能获得旧数据上的收益；历史正式报告不覆盖。

## 冻结设计

- 只用上轮原Train的6图及已盲选的6个旧GBDT来源episode，不读留出图候选标签。
- 按seed2026091805对地图ID哈希排序，轮转分配decision32、64、96，各两图，一图一根。
- 原episode和阶段缺失或超过工作预算则停止，不能按结果换根、换图或重抽seed。
- 每根保留原trace的四候选、全部前缀及原始状态；6个原动作control重新核验候选、路径、评分、节点。
- 候选分别运行16个trial，trial0-7为发现批、8-15为确认批，合计384分支。
- 只用冻结Dual16+SA续跑，不重复已知较差旧GBDT的续跑网格，降低采集成本。
- 完成事件以原episode总128次修复或2500万修复generated节点为工作预算；初始PP不计入节点预算。
- 32/64/96根分别最多剩96/64/32步；不在根上重置完整预算。节点上限在修复间检查，不是低层硬节点限额。
- 每次PP20秒、分支300秒；含较长prefix的外部fuse固定480秒，不为策略增加优化预算。
- 最多20个独立进程；未知不补零。理论标签修复上限24,576次，prefix另24,576次；control额外390次修复。
- 每批最多20作业，支持完整作业resume和STOP_AFTER_BATCH。半写作业必须先检查，不静默重跑。

## 防止样本内选赢家

先采发现批并全轨迹审计；仅根据其完成率选候选，平局保留anchor，其余按候选ID。
在任何确认分支启动前，将选择和发现批审计SHA写入choices.json；确认启动登记其SHA，之后禁止改选。
确认批评价该固定选择，并报告anchor、均匀随机经验期望、旧GBDT和上轮预算模型在根上的冻结选择。
模型根预测在Windows Python portable和WSL native必须完全一致；它们不参与本轮拟合。
确认批上的样本内最佳只作描述，不冒充可靠上界或可部署策略。

主要量是六根等权的确认完成率差（发现批选择减anchor），每根对应一张地图。
报告正/负/平局地图数、两批同向严格收益、候选对稳定性、地板/天花板、最佳集重合及5000次地图bootstrap。
置信区间只呈现不确定性，不设置每图全赢、5%提升或区间下界必须大于零的硬晋级条件。

- 平均确认收益大于0，且至少2根的严格收益在两批同向：仅为开发信号，另立后续训练协议。
- 平均为正但不足上述复现：弱信号，不自动训练。
- 平均不正：没有复现选择收益，不增加trial或追加同配方模型。
- 资源截断：证据不足，不将未知当失败，也不删除困难根来算成功。

本轮仍未评价“更新模型持续接管”；只评价根动作加参考续跑的一个学习前提。
所有图已查看过，不能称独立地图确认；每图只配一个阶段，阶段与地图混杂，不能作阶段因果比较。
六根很少，阴性结果不能证明候选价值不可学习；阳性也不自动证明TTF更快。
