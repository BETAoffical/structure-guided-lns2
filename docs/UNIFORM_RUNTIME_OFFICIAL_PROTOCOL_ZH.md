# 无模型均匀探索与官方对照：有限诊断协议

2026-09-12。本轮不做正式 TTF，不修改冻结控制器、native 或模型，不训练，不改变已失败双轨的比例或温度。

## 新问题与历史边界

前一轮独立双轨相对均匀贪心多用 14.83% generated nodes，成本门槛失败。均匀贪心 16/16 成功，但仍为了审计计算了模型分数，且使用完整 PP；没有同状态官方 Adaptive 对照。因此不能直接说它更快或优于官方。

本轮只填这两个缺口，不再做末态救援、反馈阈值或多轨预算搜索。复用上一轮 16 个开发状态，不把它们改称未见数据。

## 冻结流程

1. 从冻结候选生成器中抽取无模型调用路径。保留 seed 选取、Target/Collision/Random、代表候选、Dual16 结构候选、顺序和去重规则。仅跳过候选特征向量和模型加载/推理；必要的冲突拓扑分析仍保留。
2. 16 个状态各完整运行一次 uniform-complete，最多 256 步，与上一轮保存的 445 次修复逐项比较：除模型分数外的完整候选、最终选择、PP 顺序、接受判断、指纹、冲突轨迹、节点和最终路径完全一致。使用禁止模型加载/特征打分函数被调用的 guard。任何差异立即停止，不修改求解器来追求一致。
3. 只有等价验证通过才运行 32 个新对照作业：同样 16 个状态上的 Official Adaptive，以及无模型 uniform-standard。uniform-standard 使用官方原 PP 提前终止与单调接受；uniform-complete 使用既有实验完整 PP 与单调接受。二者使用相同显式动作随机流规则，Official 不额外插入 proposal 或动作级 reseed。
4. 所有方法从相同规范化初始路径、seed、计数和 fingerprint 开始。每作业最多 256 次决策、120 秒诊断资源预算、每 PP 5 秒、外部 180 秒。最多 20 workers，逐文件原子保存、resume 和 STOP 安全停止；不根据结果换任务或增加 trials。

初始化来自上一轮原始 PP 后的规范化导入，不是重新测量官方从 reset 开始的完整流程。并行期间的秒数只用于资源诊断，不能称为 TTF。

## 分析与准入

- 分别报告三方法的成功、失败/资源截断、决策数、实际调用过 PP 的次数、generated nodes、每图和共同成功结果；不只看总体修复次数。
- 每个 uniform 方法分别与 Official 比较；不得根据结果改变哪一种实现属于何种方法。
- 后续独立验证准入要求：无错误/截断、无官方成功任务退化、总 generated nodes 至少降低 5%、至少 4/8 张图节点总数不增加。该门槛只是发展性筛选，不是正式 TTF 或默认替换门槛。
- 所有方法都失败则记录共同困难；uniform-complete 优于 uniform-standard 才能支持完整 PP 的条件性价值。单个胜例不足以归因，更不能归因于模型学习。
- 若没有任何 uniform 方法通过，则停止这条廉价探索的直接计时扩展；若通过，下一轮才设计全新任务的独立配对，不能用复用的 16 状态宣称泛化。
