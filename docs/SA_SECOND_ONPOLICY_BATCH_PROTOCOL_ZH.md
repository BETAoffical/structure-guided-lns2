# 第二批真正on-policy终局数据与探索对照

## 目的

上轮冻结复测中新模型11/16，与Dual16及未训练探索完成同一组位置；相对旧条件模型净增1个。
继续重复拟合actor-0原轨迹不能解决信息支撑有限的问题。下一步先增加当前策略自身的完整终局数据，
检查能否获得新的条件内成败对照。不训练模型、不做正式TTF，不读取M06/M07标签用于训练。

## 固定设计

- 六张原Train地图M00至M05、每图两个原任务不变。不是新地图或新OD验证。
- 初始规划solver seeds固定233/239，与旧227/229隔离。共24个新名义条件。
- 新随机流phase为`train-1-new-conditions`，每条件replica 0至3。
- 冻结当前`uncapped_condition`采集96条；同条件、同随机流的未训练探索actor-0另采96条。
- 总计192条。探索对照只解释学习增量，绝不混入当前策略的梯度。这里的探索仍有Dual16锚点，不是均匀随机邻域。
- 先做24次reset准入。校验原生身份、路径、地图/任务身份，并与原Train初始路径比较物理新颖性。
- 保留零冲突、容易和困难条件，不查看结果后挑选seed。若整批没有任何新的初始路径则停止采集，不自动重新抽seed。
- 初始路径重复数和真正不同的路径数均报告，不把solver标签差异自动当作独立样本。

## 保持不变

129维输入、32单元残差actor、固定归一化、Dual16完整候选池、PP/SIPPS、SA及冻结native不改。
取消决策次数上限继续有效；256仅是输入归一化参考，原生max_repair_iterations为0。
2500万repair generated nodes预算、PP20秒、episode900秒、进程960秒安全保护不改；reset外部fuse180秒。
默认20进程，逐批安全停止、原子结果、显式resume；无自动重试、无删失补零、无难例删除。
零冲突直接成功也保留；节点耗尽不是无解证明。多进程耗时不作TTF。

## 分析与停止规则

192条必须全部正常终止且完整轨迹审计通过。异常或安全删失需先检查，不能删掉后生成训练标签。
两方法必须具有相同初始fingerprint和RNG身份，报告成功数、新增/损失、逐地图结果和共同成功节点/路径质量。
只有当前模型的96条用于重建完整终局策略梯度系数：终局可行1，否则节点预算结束0；
同条件其他三个replica作动作无关基线，地图、条件和episode等权，对整条轨迹log概率求和。

报告混合成败条件数量、有效地图数量、非零系数轨迹及其步数，和旧actor-0的4条件/3地图信息量并列。
新旧不同seed和不同采样策略的总体完成率不作配对模型改善证据；仅本批当前模型与探索是配对比较。
存在非零终局信用，才允许下一阶段登记一次更新；没有则停止训练，不换成H1/H32代理或自动追加trials。
这一许可不是模型晋级门槛，也不保证新模型能提高成功率。

## 后续训练边界

历史`sa_crossfit_update.guarded_update`明确要求零残差actor-0。其批量概率实现把行为概率当作锚点，
只对actor-0成立，不能直接套在非零actor-1上；显式检查阻止了这种误用，历史结果没有因此失效。
下一阶段若续训，必须从固定Dual16探索先验重建概率，而不是在已有行为概率上再次叠加完整残差，
并验证非零父模型的Torch/NumPy概率、autograd梯度、导出iteration/parent和动作一致性。
本轮没有调用该更新器，没有修改历史模型或训练函数。

所有正式旧数据、模型及结果保留，输出完整终局采样、逐步审计、信息量报告和下一阶段建议。
