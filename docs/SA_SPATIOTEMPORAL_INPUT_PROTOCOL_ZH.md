# SA 时空输入恢复：独立表示研究的第一步

## 目的与边界

2026-09-17。最近配对H32模型在连续闭环中未晋级；旧模型、候选生成、PP/SIPPS、SA和正式结果保持不变。
本轮只落实新的输入表示，不训练，不采集新标签，不做TTF，不自动将历史负面结论改成正面。
输入正确不等于输入有增量预测价值，更不等于新策略能更快完成。

来源固定为已查看的旧16状态和新增31状态，合计47状态、8张同族仓库地图。
两个来源不是地图独立的Train/Validation；所有数据只作为开发材料。
原H32标签仍表示首动作后由冻结Dual16+SA续跑，不能重命名为连续使用新策略的价值。
最近32个新任务的闭环轨迹不进入本轮输入索引或训练。

## 与历史方法的区别

- 旧GBDT把路径压缩成统计量；旧二层GNN主要处理二值agent冲突图和agent汇总量。
- 本轮保留完整的单车位置时间序列，用连续停留区间无损存储，末次到达目标后的占用延伸到无限远。
- 地图栅格与所有车辆路径每个状态只存一次；候选仅提供selected mask，避免重复编码整张地图。
- 所有外部路径均保留，不限于当前冲突agent，暂不作时间截断或只保留局部子图。
- 栅格是空间输入，不包含布局名称、任务类型、split名称或地图ID编码；这不是恢复静态上下文迁移主张。

设计参考 [NNS ICLR 2024](https://proceedings.iclr.cc/paper_files/paper/2024/file/d41f8403e9bb5141bc2c81fad7658185-Paper-Conference.pdf)
的方法部分：显式表示路径时空关系并共享状态编码。但这里没有复制其网络、训练目标或源码，不能称为NNS复现。
NNS优化可行解的成本，并在神经实验中重点使用PBS；本项目仍研究PP修复下的首次可行解。

## 输入合同

- `states/*.json.gz`：障碍栅格、各车起终点、路径成本、精确占用区间和时空冲突事件。
- 区间右端开区间；最后一个区间的null终点表示持续占用。保存path_cost用于完全重建原始有限路径，包括末尾等待。
- 冲突事件统计到原路径最大成本，之后所有车停在唯一目标上；不把无限占用算成无限次冲突。
- `candidate_index.jsonl`：共享状态引用和布尔成员掩码。候选ID、agent ID、地图ID仅用于连接和审计，不作为数值特征。
- `label_reference`只指向原索引。未来训练器必须明确分离标签读取与输入提取；本轮不产生新reward或新标签。
- 禁止读取修复后路径、control_event修复结果、runtime、generated nodes作为时空模型输入。
- 原127维输入只做来源一致性核验，本轮不改变或删除原特征。

先校验原plan、index、root receipt和state fingerprint，再将完整路径编码成区间。
以两种独立计算方式校验冲突：逐时刻路径扫描，以及按格子区间交集/反向移动匹配。
两种事件列表、官方已保存冲突边和冲突对数必须一致；路径必须可逐格重建。
任何输入不一致均停止，不删除难例、不自动修改历史文件。

## 输出与解释

固定配置 `configs/sa_spatiotemporal_input_audit.json`，默认20个独立进程。

```text
python scripts/audit_sa_spatiotemporal_input.py run
python scripts/audit_sa_spatiotemporal_input.py verify
```

输出到忽略的 `build/sa-spatiotemporal-input-audit-v1`。不覆盖已有输出；异常保留状态和锁供检查。
保存源码/输入SHA、运行配置、逐状态文件、候选索引、报告和完成receipt；完成后再核验全部源文件没有变化。
确定性gzip不含时间或机器路径；索引和manifest仅使用仓库相对路径。

描述性统计包括：内部/边界/外部冲突、外部终点持续占用冲突、多时刻事件、重复冲突对、附近但当前不冲突的外部车辆。
附近定义为候选旧路径及其一格可通行邻域，仅用于说明覆盖，绝不是可行性证书或必要阻挡者判定。
这些数量不能证明当前127维特征完全不知道相应信息，也不能证明其具有增量可学习价值。
同样，保留所有路径不意味着未来神经编码器能无损利用全部信息。

## 后续明确分开

1. 本轮完成输入恢复、泄漏防护和规模盘点，不以新模型胜负为验收指标。
2. 下一轮先冻结具体时空编码器、参数预算、地图分组、旧特征消融及H32标签的开发用途，再训练表示探针。
3. 训练探针必须与旧模型使用相同候选和标签，才能归因表示差异；不得自动改为一步下降标签。
4. 若出现独立预测信号，再另行设计续跑策略与实际部署一致的连续控制验证；此前不接入正式控制器。
5. 若没有信号，检查标签方差与表示不足，不能靠反复调参或重新筛选地图产生通过结论。

已有历史明确包括数据聚合、图模型、历史反馈、长期标签和容量试验。本轮新增的是精确时空输入接口，不把这些旧工作宣称为未尝试。
