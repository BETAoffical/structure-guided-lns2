主指标为实际 `native_replan_seconds`，外层 step 调用单独记录，不把嵌套时间相加。候选生成、模型分数、路径、冲突与节点计数必须等价。支持作业后安全停止、完整成功作业的 SHA 续跑校验、失败或不完整作业拒绝静默重试。

65 项针对性测试通过，覆盖新增协议、停止/续跑保护、原始枚举顺序、保留清单及独立 native Python 接口。本轮未重跑完整 Python 套件、CTest 或官方 CLI parity，不把接口测试称为全套验收。

## 为什么停下

启动前只读检查发现 Windows `deadlock`（PID 36408）的 `PercentProcessorTime=371`，约为 3.71 个逻辑核的占用。供电检查返回 BatteryStatus=2，电量100%。这是一次瞬时观测，说明存在明显的外部竞争风险，不证明它造成了某个具体数值的变慢。

这次负载检查与启动命令在同一个工具编排调用中顺序发出，尚未读到检查结果就启动了采集。发现后立即设置 `STOP_AFTER_JOB.json`，让已运行作业正常结束，没有终止或修改用户的外部程序。后续必须先单独获取并审阅负载检查结果，再决定是否发出采集命令。

最终完成 **2/32 作业**：同一案例的参考与栈邻接版本各 48 次修复。两者都与历史路径、候选和搜索计数一致；其耗时不用于任何加速判定。两份结果及其 SHA 完整保留，停止后已确认无遗留采集 worker。
