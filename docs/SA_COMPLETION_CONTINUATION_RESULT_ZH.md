# A的一次on-policy续训：省工作量，但未增加成功

## 当前决定

已完成96条A训练轨迹、一次终局成功更新、96条A/A2开发比较，以及192/192完整轨迹审计。
**保留A+SA作为当前冻结比较版本，不直接用A2替换。**

A2不是毫无信号：共同成功案例的低层节点减少6.30%，修复次数减少8.44%，五张图的条件节点均值下降。
但成功数由41/48降为40/48，没有新增成功，丢失1个成功；总体节点差的地图级区间仍跨零。
因此没有满足预登记的“成功数不降低”条件，不将省节点直接写成更快TTF。
这不是要求每例全胜，也不是判定所有进一步训练都无效，而是完整保留当前观察到的取舍。

## 本轮到底改变了什么

模型谱系为raw-1 -> A -> A2。本报告中的`parent`指A，不是raw-1，也不是Official或Dual16。
A先前从raw-1的轨迹更新一次；本轮用A自身的新轨迹再更新一次。

- 129维输入、32单元隐藏层、归一化、冻结锚点、候选生成、PP+SIPPS和SA完全不变。
- 目标仍是完整轨迹最终成功，按地图等权、leave-one-replica-out基线、相同KL限制与回溯步长。
- 没有一步冲突下降奖励，没有换成小邻域成本奖励，没有温度扫描或模型容量调参。
- 原六张训练图：12任务、solver seeds233/239、四replica，96条新A轨迹。
- 另外六张旧开发图：12任务、seeds251/257、两replica、两个模型，96条比较，48个配对位置。
- 两档为bottleneck_d20/d25，均为station_centric仓库；不是跨地图族泛化。
- 使用新的训练/比较随机流；比较两臂配对初始路径、选择draw、PP随机流和接受draw。
- 不使用接受器消融的24组或扩样计时72组结果来训练、筛选任务或调参。

20个独立进程，每episode2500万节点预算，取消决策次数上限。
节点预算在原子修复之间检查，最后一次完整修复可越过节点阈值，不能当成严格硬截断。
保护性PP/episode/process时限分别20/900/960秒，本轮没有保护中断。
本轮并行运行时间不作为TTF，CSV也不包含伪装成TTF的并行秒数。

## 丢失成功的轨迹检查

唯一丢失条件为M01/task_0001、solver251、replica0，初始531对冲突。

| 项目 | A | A2 |
|---|---:|---:|
| 结束状态 | 成功 | 节点预算内未解 |
| 总generated nodes | 24,209,696 | 25,034,894 |
| 修复次数 | 295 | 255 |
| 不同邻域数 | 293 | 255 |
| 单个邻域最多选择次数 | 2 | 1 |
| 最少 / 最后冲突对 | 0 / 0 | 24 / 34 |

它不是旧Dual16那种不断重复同一个集合的证据。A2没有接近最后一对，而是在更早的修复阶段未能完成。
不由此声称检查过全部全路径回访，也不将节点预算失败称为无解。

首次动作分歧在零起算decision108；此前状态fingerprint、候选池、特征、draw均相同。
两臂选择不同的8车集合，共用PP seed1003837556；概率总变差约0.002745。
A该步冲突101 -> 103，A2为101 -> 100，但后续只有A成功。

这说明小概率更新可能跨过抽样边界并走向不同长期轨迹，不能用该步下降判断最终结果。
但后续整条策略都不同，**不是只干预一个动作的因果实验**；不能认定这一次改选就是唯一根因。
A2本身使用终局成功目标，因此也不能把本次结果解释为“又训练了一个一步贪心模型”。

## 历史回顾与下一步

1. 接受器消融支持保留SA；本轮两模型都保留SA，不能再用删SA解释或修复A2的一个损失。
2. 这次确实完成了A自身访问分布上的更新，不是重复使用raw-1轨迹；它回答了继续同目标训练的一项新问题。
3. 当前信号是“共同成功少做一些工作，但没有增加可靠性”，不是所有指标无效，也不是全胜门槛误杀。
4. 按预登记规则保留A，A2以成本/可靠性取舍候选保留，不删除权重，不自动做第三次更新、奖励扫描或温度扫描。
5. 直接扩充TTF时，主冻结版本继续使用A+SA。若进一步考察A2，必须另行预登记独立、相同墙钟预算的配对比较，
   同时保留失败与路径质量，才能判断省节点是否转为实际收益；本轮不提供A2的TTF或建模任务完成时间结论。
6. 不能从这一轮断言训练方向不可行。独立训练地图数量、仅七个有相对信用的条件、终局信用方差和节点预算与TTF的差别，
   都是仍未被充分隔离的限制；不是已证明换某个模型结构就能修复。

原A在上批独立仓库TTF中的正向结果和三个失败继续保留。本轮旧开发图也不恢复跨布局或静态上下文迁移主张。
