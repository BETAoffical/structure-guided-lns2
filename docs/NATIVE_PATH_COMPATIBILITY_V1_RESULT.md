## 主要结果

| 方法 | 固定顺序条件 | 两车无冲突成功 | 相对普通方法新增恢复 | 累计低层展开 |
|---|---:|---:|---:|---:|
| 普通顺序规划 | 20 | 3 | 0 | 116,339 |
| 无定向同成本重选，最多四次 | 20 | 4 | 1 | 575,970 |
| 定向同成本重选，最多四个反馈约束 | 20 | 7 | 4 | 350,738 |

成功的含义：选中两车不再与彼此或任何固定外部路径碰撞；外部车辆之间原有冲突可以保留。
六个状态和每对车辆的两个顺序相关，不能把 60 个作业当作 60 个独立场景。
新增恢复均未增加首车成本，这里相对同搜索器的普通尝试，不是相对输入旧路径；
不保证整批任务的 SOC 或 makespan 更优。

按来源分开，普通 / 随机 / 定向的成功顺序条件数分别为：

| 来源状态 | 来源类型 | 普通 | 随机 | 定向 |
|---|---|---:|---:|---:|
| `case-b4c844537f19` | 最终成功但长时间停滞 | 0/2 | 0/2 | 2/2 |
| `case-7ee343a50388` | 失败长尾 | 0/2 | 0/2 | 0/2 |
| `case-7972d3318d2d` | 快速对照 | 2/4 | 3/4 | 4/4 |
| `case-6542dfb0660a` | 最终成功但长时间停滞 | 0/4 | 0/4 | 0/4 |
| `case-3723c8bd272e` | 失败长尾 | 0/4 | 0/4 | 0/4 |
| `case-505cbcf446fa` | 快速对照 | 1/4 | 1/4 | 1/4 |

**两个失败长尾来源均未恢复。** 当前正信号不足以证明可以提高正式任务成功率或解决失败长尾。

三方法包含前置普通尝试的累计诊断耗时分别约为 0.535、2.098、1.392 秒。
这些计时排除了进程启动、输入认证、探针构造和最终 native 路径校验，且来自多进程诊断，
不能作为单 worker TTF、生产控制器开销或可靠加速比。

## 等价性和路径核验

12/12 个完整历史邻域、固定顺序和 PP seed 的普通 PP 核验通过：

- 最终全部路径与冻结 native 一致；
- 接受/回滚、尝试冲突对数、尝试车辆数一致；
- 逐车成本和低层碰撞数一致。

这里比较的是独立导入相同路径后的单次 PP，不是对原闭环全部内部历史的复现。
对于回滚作业，最终路径一致本身也不证明每条未提交中间路径逐格相同；
当前诊断同时比较逐车成本及碰撞计数，但没有将其夸大为任意状态下的形式化等价证明。

20 组普通尝试在三种方法中，路径、成本、节点数和碰撞数全部相同。
14 份成功结果分别通过 Python 冲突重建和冻结 native 路径导入校验。
这 14 份有重复基线和相关顺序，不是 14 个独立 native PP 成功案例。

## 最重要的适用边界

| 状态 | 定向新增恢复的顺序 | 首车/后车成本 | 不在历史选中邻域中的车辆 | 整个状态零冲突 |
|---|---|---|---|---|
| `case-b4c844537f19` | 46 → 254 | 91 / 63 | 46 | 是 |
| 同上 | 254 → 46 | 62 / 97 | 46 | 是 |
| `case-7972d3318d2d` | 288 → 4 | 81 / 72 | 288、4 | 否 |
| 同上 | 193 → 4 | 75 / 72 | 193、4 | 否 |

**四个新增恢复条件全部涉及原历史邻域外的车辆。**
逐条对比输入路径后，确认这些外部车辆的路径也实际发生了变化，不只是形式上被列入两车集合。
因此本轮没有证明“对 V2 原本选中的完整邻域，仅改变内部路径就能带来这些收益”。
这也不证明必须改动外车，只说明当前找到的成功见证改动了它们；
能否固定外车、仅调整内部路径，仍需单独验证。
不得把修复全局高冲突对与修复模型选中的 agent 集合混为一谈；
偷偷替换或扩大原邻域会同时改变候选机制，破坏归因。

在 254 → 46 条件下，自动生成的顶点约束仍定位到 `t=2, cell=1078`，
复现了首车 62 步不变而两车兼容的机会。约束来自当前路径冲突，不是硬编码成功见证。
无定向方法也能恢复一个条件，说明反馈的增量必须继续与便宜随机重试比较。

## 没有解决的问题

1. 13/20 个顺序条件在定向方法下仍未找到解；不是 13 个联合无解证明。
2. 35/201 终点相关案例仍未解决。不能仅凭停车边界就断言必须加入外车。
3. `case-3723c8bd272e` 的 19/364 两个顺序曾在 Python 参考搜索中被恢复，
   本轮原生诊断没有恢复。不同基础路径和平局规则会改变反馈约束。
4. 该案例反馈的四个约束集中于同一格子的连续时刻 `t=1..4`；
   若反馈预算被同一资源占满，约束多样性可能不足。此为后续假设，未追加试验或改门槛。
5. 单步机制成功不等于更高端到端成功率、更短长尾或更优执行路径。

## 下一步的准入边界

可以继续原生机制研究，**不能直接替换 V2 默认修复器**。

下一轮首先固定模型实际选择的完整邻域及其规划顺序，从该次 PP 的内部阻塞中提取反馈。
若阻挡车属于选中集合，可以验证有界路径重选、预算和完整回滚；
若阻挡车在外部，应明确记为“当前固定邻域不可直接利用的机会”，不自动扩邻域。

只有完整邻域内部重选出现低开销收益，才进入独立原生修复器的事务与失败回滚验收。
定向补充外车必须作为另一项消融，不能把本轮四个恢复条件直接算入前者。
Official 和 V2 都使用 PP；后续仍需四路对照区分通用修复收益与 V2 特有收益。
不恢复静态上下文迁移主张，不训练 RL。
