# 最近 47 状态模型重建与同来源预测结果

## 本轮结论

上一轮最近模型缺少可加载权重的问题已经补齐：按原训练流程重建的 8 折 GBDT，
376 行原预测、1,504 个候选分数和选择均精确复现。保存权重后重新加载仍完全一致。
这不是从磁盘找回原权重字节，而是固定旧流程的确定性重建。

对完整 16 个同来源候选对评估后，最近模型的 H32 分支完成率为 **57.03125%**，
低于 pair 均匀选择的 **59.765625%**，与历史 16 状态模型的均值相同。
本轮不设置晋级门槛，所以不能把这一结果归因于“门槛要求全面更好”。
相对均匀选择的区间跨零，结论是没有显示优势，不是证明模型在总体上必然更差。

所有数值均为固定首次动作后、冻结 continuation 最多 32 步内获得无冲突解的比例。
它不是完整任务成功率、机器人执行时间或 TTF。

### 均值相同不是误用了旧模型

最近模型与历史模型在 5/16 个状态上选择不同，其中三个状态的经验结果相同。
另外两个状态一正一负，幅度相同，刚好抵消：

| 状态 | 历史模型所选完成数 | 最近模型所选完成数 |
|---|---:|---:|
| `2ee66d719bb40c104bfbf6a0-d0004` | 7/8 | 6/8 |
| `09c1b4f9a91ded098e046111-d0004` | 7/8 | 8/8 |

已独立从 trial 标签与所选 candidate ID 重新计算差值和区间，结果一致。

### 最稳定的局部机会仍被错过

状态 `af41defd15b848f64ffaf816-d0016` 的同来源 size16 候选：

- `neighborhood-0877faa3a97f991a`：8/8 完成。
- `neighborhood-32eb04938822bdcf`：3/8 完成。
- 最近模型、历史模型和原 pool 分数都选择后者；最近模型在 pair+anchor 并集中也选后者。

最近模型在 pair 内的 A 减 B 分数差为 `-0.04501179510095383`，不是平局规则导致。
分数不是校准概率，不能因为幅度比历史模型小，就解释为“更准确的不确定度”。

## 与历史连接，而不是重复试模型

[此前的来源匹配审计](SA_SOURCE_MATCHED_PREPARATION_RESULT_ZH.md)已经发现：
旧 47 状态的已标注候选里，同来源签名且同为实际 size16 的候选对为 0，
但原完整池里有 137 对。这说明训练直接观察到的对比与本次要求的组内区分存在覆盖缺口。

本次结果进一步说明，沿用原标签重建更近版本，没有自动补上这种能力。
不过，训练覆盖不足、127 维汇总表示不足、样本有限及 H32 结果波动仍可能共同影响结果；
不能从本次单独认定唯一原因，更不能推断所有新模型都不可行。

本批仅 6/16 对的经验完成率不同，只有一个差异较强、在上一轮全部 split-half 中方向一致的案例。
这不支持立即把它包装成充分的新模型训练集，或反复换网络直到出现正结果。

下一项若继续训练研究，应改变待验证的数据条件，而不是再重复容量、历史窗口或单步收益试验：

1. 针对“同来源、同大小、不同成员”预先定义配对学习任务，先核算留图后各训练折的有效差异覆盖。
2. 旧标签与新标签使用不同随机流；不能把它们拼成一个假定共享 trial key 的大候选组。
   应保留各自配对组与 randomization key，按状态统一权重，避免同一根被重复加权。
3. 只有训练覆盖支持这一问题，才做一次固定表示、固定容量的有界验证；不使用强案例来筛选训练或验证状态。
4. 若差异覆盖仍不足，先记录证据不足，不再仅用这 16 对轮换模型；扩大采集需要单独范围和预算。

本轮没有执行上述新训练任务。原 Dual16+SA 继续保持冻结，没有进入正式计时或部署。
即使将来离线识别改善，仍必须验证连续控制，不能跳过历史上单次干预有益而闭环退化的记录。
