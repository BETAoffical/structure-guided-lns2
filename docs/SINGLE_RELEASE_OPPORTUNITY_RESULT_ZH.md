# 单外车软占用机会审计：完整负面结果

日期：2026-09-10。结论：**NO_GO；冻结控制器不变，没有新的TTF或成功率提升。**

## 本轮验证了什么

前两轮频率排序无法准确定位软占用反馈对象。为区分“没有选对外车”和“这种动作本身没有机会”，本轮不再设计排序器，而是穷举一个明确的有限动作空间。

从7个已查看失败长尾状态中，按固定哈希为每张地图选择一个，共3个状态。固定原模型选中的集合、PP顺序、两个PP seed和所有外部真实路径；依次只让搜索的软CAT不参考一辆外车。真实碰撞账本从第一步起仍包含它，接受/回滚规则完全不变。

三张地图均属于已查看的 station_centric 开发数据，不是三种布局族或独立泛化确认。两个seed也不是两张新地图。

## 为什么失败

事后描述性分析不改变主门槛：

| 状态后缀 | 尝试路径/停止位置改变 | 与普通尝试完全相同 | 全部回滚 | 回滚时新增冲突涉及被忽略外车 |
|---|---:|---:|---:|---:|
| 0000 | 832 | 0 | 832 | 439 |
| 0002 | 933 | 1 | 934 | 264 |
| 0006 | 824 | 118 | 942 | 349 |
| 合计 | **2589 (95.61%)** | **119** | **2708** | **1052 (38.85%)** |

这里比较的是逐车尝试路径序列和停止位置，不只是回滚后相同的最终路径。新增冲突以输入路径的原有冲突对为参照；这一列是描述性关联，不能声称1052个分支都由忽略该车单独导致失败。

最直接的解释是：

1. **不是多数动作没有执行效果。** 95.61%的尝试序列确实改变，但改变后的组合仍不能通过真实冲突约束。
2. **软引导与物理占用不同。** 搜索少参考一条软占用路径，并不会让外车消失，也不会改变它的终点停车。允许这类新路径通过验收会改变科学问题，可能只是漏算冲突。
3. **已不只是排序没选对。** 这三处状态的全部单外车选择都试过；即使免费获得这套动作空间的oracle，也没有一步收益。换更复杂排名器不能在相同候选结果中创造收益。
4. **不能据此证明必须扩邻域。** 仍可能存在同集合的其他合法路径或不同顺序；本轮只穷举“固定seed和顺序下，忽略一辆外车软CAT”的动作，不穷举联合路径空间。

## 与历史结果是否矛盾

不矛盾。历史235号车见证来自另一个已查看状态，保持11车集合时平均冲突从37.75降至35，8/8有改善；那是局部机会，不是失败长尾恢复。本轮取其中两个条件作实现控制，逐车路径、成本、节点及最终路径全部复现，均得到35冲突。因此不能把新结果解释为见证功能被代码改坏。

相关证据已重新检查：

- [局部路径兼容性](LOCAL_PATH_COMPATIBILITY_V1_RESULT.md)：case-3723的19/364曾有两车参考路径机会；35/201联合搜索仍为预算未知。不能直接重复加预算，也不能称后者必须扩邻域。
- [原生路径兼容性](NATIVE_PATH_COMPATIBILITY_V1_RESULT.md)：两个失败长尾来源都未恢复；四个新增恢复条件均实际改变了历史邻域外车辆的路径，不能算作原邻域内部重选收益。
- [累计冲突预算归因](CONFLICT_BUDGET_ATTRIBUTION_ZH.md)：case-3723原PP尝试中，即使理想消除已记录内部冲突，剩余外部关联冲突仍超过接受上限。改变选中车辆路径也可能减少这些冲突，不等于证明外车必须移动。
- [搜索前沿观察](SEARCH_FRONTIER_OBSERVER_RESULT_ZH.md)：裁剪后软占用集合仍很宽，频率排名没有定位历史见证。减少日志不等于形成可执行修复。

这些结果共同支持：目前多轮廉价、固定邻域的局部引导没有解决这些困难长尾，但不否定此前局部机会，也不能否定所有路径协调方法。

## 下一步与停止边界

本轮到完整机会审计及失败分类结束，不自动增加trial、状态或搜索预算。

1. **停止单外车软CAT释放的在线接入与频率排序扩展。** 不再为这套已枚举无收益的动作训练模型，也不重复更多频率权重。
2. 若继续研究，先做“最小实际路径协调”的证据准入，而非直接扩大邻域：从已保存的成功路径与失败账本中，明确哪些少量车辆的实际路径变化有合法见证，且适用于原来的失败状态。只有同一失败状态中的见证才有资格支持新干预。
3. 区分已有的固定外部路径不可行证据与预算未知；不重跑已穷尽的相同子问题，不把未知当作扩大车辆/预算的理由。不重复历史全量阻挡闭包、通用重选或大范围回退。
4. 若找不到新的、可验证且与历史失败不同的协调假设，就暂停这条修复扩展，保留负面结论。若找到，再单独预注册有界实际路径调整，继续保持真实冲突验收和完整回滚。

研究目标仍是减少真实长尾并提高成功率。上述后续仍未执行；没有新模型晋级，没有进入RL、正式TTF或静态迁移验证。
