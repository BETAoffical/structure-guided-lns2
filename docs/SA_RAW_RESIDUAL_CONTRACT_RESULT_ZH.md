# 下一版选择器表达合同：验证通过，尚未训练

2026-09-24。**已实现可针对其他候选提高概率的新表达方式，并验证零初始化严格保留父策略。**
本轮没有训练、MAPF修复调用或TTF计时，不增加成功数，不替换Dual16/SA/PP或当前actor-1。

## 1. 具体改了什么

旧原型为固定锚点先验乘以有界残差。在本项目17–20个候选下，任何权重都不能让一个非锚点候选成为最高概率项。
本轮独立原型保留actor-1作为冻结base，使用：

```text
pi_new(a|s) proportional to pi_base(a|s) * exp(delta_theta(s,a))
```

delta是129→32(tanh)→1的小网络，最后输出原始logit，不再施加[-2,2]上界。
第一层复制base，末层为零；归一化、输入列与候选池不变，未增加地图/OD特征或单步结果特征。
零初始化时概率完全等于base，不是再次叠加一次base残差，也不是退回未训练的均匀探索。

新分支包含4,193个可训练参数，另保留4,193个冻结base网络参数。没有增加每个网络的宽度，但总参数及前向计算更多。
当前实现计算base和修正两次前向，**尚未测量其在线开销，不能写成工程加速**。
该原型使用独立schema，旧控制器加载器明确拒绝，不会根据相似文件名意外切换模型。

构造权重是数学/程序见证，不是训练出来的权重，不代表选中了真实MAPF中的正确邻域。
每个候选用不同输入特征区分，没有将candidate ID或成功标签输入模型；相同特征仍不能凭空区分。
这只能排除上一版永久概率上界造成的表达障碍，不证明现有实际特征足以学习有用选择。

## 3. 跨平台与梯度

18组真实输入加20组构造输入，每个平台共626次固定draw选择：

| 实现 | 概率最大误差 | 选择一致 |
|---|---:|---:|
| Windows NumPy 1.26.4 | 0 | 626/626 |
| Windows Torch 2.12.1+cu126 | 2.22e-16 | 626/626 |
| WSL NumPy 1.21.5 | 4.34e-18 | 626/626 |

复用已有环境，没有安装依赖。使用CPU数值校验，Torch版本带CUDA后缀不等于本轮做了GPU训练。
零修正的NumPy路径直接保留原概率，CDF边界左右也保持选择；Torch接口仍经过可微log-softmax，避免把零初始化的梯度切断。
有限差分、非零修正导出、候选置换、公共logit平移、base不可变、输入泄漏拒绝及概率下溢拒绝均有测试。
零末层使首轮第一层梯度为零、末层梯度非零，这是结构性质；不能误称优化器漏更新，也不表示已经充分训练。

Windows现有Torch环境51项相关测试通过；WSL为52通过、10跳过，跳过项为需要Torch的测试，已在Windows执行。
不是全仓库测试、CTest或新的官方parity运行；旧native没有修改。

## 4. 如何约束更新而不永久锁定旧首选

保留已有三个固定上限：平均KL 0.002、平均轨迹KL 0.1、最大状态KL 0.02。
检查参考是直接前一行为策略，不能每轮都将新模型拉回最初base；base权重本身仍固定。
原型只提供检查器，没有优化器或train入口，不会由“通过KL”自动触发参数更新。

测试使用60个人为小改动，逐次满足局部KL限制后，可以累计超过旧首选；若错误地永远与初始base比较，该累计变化会被拒绝。
这60步不是训练轮数、超参数扫描或MAPF实验，只用于排除永久锚定在新检查器中重新出现。
零动作可行任务的权重仍保留；只有零动作输入时检查器不批准更新。轨迹KL保留整段求和，没有偷偷恢复修复次数上限。
在有限旧状态上通过KL不保证新访问状态安全，更不能代替完整任务成功率。

## 5. 本轮没有解决的内容

- 尚未将该schema接入独立的MAPF连续采样/训练入口，不能称为训练就绪或已上线控制器。
- 尚未执行任何优化器更新、终局回报拟合或新模型闭环评价。
- 旧actor-1的实际残差差值离上界很远，表达限制仍不是已证明的失败原因。
- 终局信用稀疏、困难任务无成功见证、方向噪声和真实特征区分能力仍可能限制训练。
- 旧更强均匀探索、课程续训、H32以及温度扫描的负面结论均保留；本轮不是把它们换名重试。

## 6. 下一步的有效范围

表达合同已核验，不再反复做同一数学演示。下一轮应补隔离的采样与终局更新适配：

1. 新初始化策略在原生微型任务和完整无次数上限episode接口中复现base行为；原生PP/SA不改。
2. 单独登记新Train采样、有限更新预算和未训练父策略对照。不得因为初始化等价就自动反复拟合已多次使用的旧批次。
3. 信号仍是完整任务终局成功，资源中断保留未知，不用一步下降、单步便宜或未选动作伪标签。
4. 训练后先看新随机流配对的新增/损失成功及计算量，再决定是否值得新地图或TTF；不要求每张图全胜。

本轮只使后续训练拥有较符合“替代选择器”目标的表达方式，不承诺它能学会、提高成功率或减少长尾。
