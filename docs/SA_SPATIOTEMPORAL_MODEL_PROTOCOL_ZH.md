# 小型时空表示训练探针：冻结协议

2026-09-17。用户要求继续并同步Git。本轮只做离线开发训练，不接入控制器，不调用求解器，不启动TTF或RL。
代码和参数在读取模型比较结果前提交。远端推送受安全审批限制时明确记录，不改用其他上传方式。

## 问题

同样的动作、H32标签和训练地图下，保留路径时序及候选与外部占用关系的小型网络，是否比旧汇总特征更有预测价值？
不宣称复现NNS，也不改变PP、SA、候选池、标签或部署方式。当前47状态、8地图只够一个开发性探针。

## 固定数据

- 复用 `sa-spatiotemporal-input-audit-v1`：旧16和新增31状态，188候选，每候选8个trial，共1504个既有结果。
- 八折leave-one-map-out；同图所有新旧状态、候选和trial一起留出。没有额外Validation或闭环任务输入。
- 同图状态等权、地图等权；trial先聚合为候选H32完成率，标签为同状态候选完成率差。
- H32的后续31步仍由旧Dual16+SA执行。预测该标签不等于预测新模型连续控制的完成率。
- 全成功、全失败、平局状态全部保留。不筛选经验赢家，也不把trial当成独立训练样本。

## 四种对照

1. `gbdt`：现有固定100树7叶配对GBDT，8个留图模型。与旧配方保持127维特征、训练权重和参数一致。
2. `flat`：仅127维旧特征，32隐藏单元的小MLP；排除仅更换学习器的影响。
3. `time_bag`：与时序模型完全相同的网络参数量，但先把每条路径及候选条件的时间轴取均值并广播；是序列聚合消融，不是仅修改一个时间戳。
4. `path_time`：保留时间序列的小网络，输入旧127维特征加时空表示。

每个神经模型固定3个seed：202609171、202609172、202609173。共72次拟合，不从中选择最好seed。
每次固定60epoch，batch4状态，AdamW学习率0.001、weight_decay0.001、梯度截断1.0，无验证集早停或参数搜索。
损失为同状态所有无序候选对的完成率差MSE。最后一个不足4状态的batch仍使用固定分母4，避免额外放大权重。
候选输出经sigmoid得到有界相对效用，不将其称为已经校准的完成概率。平局优先原动作，再按候选ID。

## 时空编码器

完整已有路径按最大路径时域展开，末端持续停留，不做时间抽样。
共享编码候选并集中的车辆路径；所有外部车辆形成占用场。
27个路径通道包括位置、移动/等待、终点状态、物理时间、起终点、障碍邻域、同刻/下一时刻占用和反向交换。
32个候选条件通道区分选中/外部车辆在路径及其一格邻域的占用、下一时刻占用、最终停车和交换。
上述下一时刻仍是当前已知路径，不是修复结果。

共享路径两层Conv1d，隐藏16，kernel3，dilation分别1和4；候选条件拼接后再一层kernel3卷积。
按候选成员和真实时域掩码做mean/max pooling，与标准化旧特征拼接，经过32单元头输出。
旧特征标准化只用训练地图；原始通道使用固定坐标和时间尺度。地图名、agent数值ID及结果字段不作为通道。

这是有界表达能力的原型：外部路径虽全部参与占用场，网络只读取候选旧路径一格附近的场，不覆盖所有可能绕行方案。
卷积局部感受野加池化不是完整联合规划器；不能把失败解释为所有精确时空模型无效。
time_bag与path_time同容量；flat较小，故只对flat的优势不能单独归因于时序，必须报告bag对照。

## 运行与复现

CPU预处理最多20进程；旧GBDT最多8折并行。单张RTX4060上逐个训练神经模型，不开20个GPU进程。
复用已有Windows全局sklearn1.5.0和独立venv-graph的PyTorch；不安装新依赖。
启用确定性算法，记录版本、训练seed、每epoch训练损失、参数量、逐状态预测、训练地图和标准化参数。
每个完成的fold原子落盘，已完成fold只能通过binding/integrity校验后续用。失败保留锁和错误，不自动删锁重跑。
单fit安全上限300秒，总训练上限7200秒。触及上限即中止并报告，不缩短epoch或改参数。
保存完整折预测与协议，不输出缺少部署合同的生产模型或portable bundle。

## 判定与报告

主结果为每个地图先平均状态，再平均3个训练seed，最后8地图等权；seed不是独立地图。
同时报告训练拟合、逐地图/seed表现、完成率regret、经验oracle命中和size分布。
对path_time相对各对照做5000次地图级paired bootstrap，不把同图状态独立重采样。
经验oracle使用同批trial选优，有乐观偏差；不称为可实现上限。

开发信号要求：对GBDT至少+3个百分点、bootstrap下界不低于0、至少5/8地图严格改善、至少2/3seed正改善；
同时优于flat且该差异bootstrap不显示退化，并在点估计上优于time_bag、原动作和随机期望。
未满足则固定记录 `no_stable_incremental_representation_signal`，保留局部正信号，不追加网络或门槛。
通过也仅记 `development_representation_signal`；两种结果均不授权正式控制器替换或TTF。
