# 线性H32选择器：新地图有界闭环协议

## 唯一问题与范围

上一轮线性差值模型在8张留出开发地图上相对冻结Dual16+SA净增2.604个百分点，5胜1负2平；
但低于同数据GBDT。本轮不追加离线门槛，直接给它一次固定预算的连续控制验证。
研究问题是低复杂度、可传递的线性估计器是否能在新任务中保持实际完成收益。
不是重复旧16状态GBDT的闭环，也不复跑已失败的单次介入或anchor门控。

只新增诊断入口，不改正式Dual16、PP/SIPPS、SA、候选生成或历史结果。
本轮不正式计时、不训练RL、不改论文结论；多进程耗时不是TTF。

## 在新数据产生前冻结

训练数据仅使用上一轮登记的47状态、8地图、188候选、1504trial。
所有trial先聚合，按地图等权、图内状态等权；总训练权重保持状态数。
冻结两份完整开发集模型：alpha=1线性岭回归，以及原100树/7叶GBDT固定参数。
不能把新GBDT误称为旧16状态模型，也不能把差异全部归于估计器以外的数据因素。
线性SVM不进入闭环；它留图更弱，不为其额外采集。

正式数据生成前保存输入、特征schema、标准化、模型、代码、native和协议SHA。
GBDT在Windows sklearn/Python portable及WSL native预测逐项一致。
线性运行时采用固定顺序math.fsum，Windows矩阵实现误差不超过1e-12且选择必须完全一致；
Windows/WSL固定求和实现分数与选择必须完全一致。
确认数据永不参与此次拟合或参数选择。

## 固定数据与对照

- master seed：2026091802；8张全新station-centric仓库地图。
- 每图两种既定任务压力：agent density 0.20/0.25，bottleneck crossing ratio 0.4。
- solver seeds：227/229；16任务、32配对任务种子、3臂共96个episode。
- 对照：冻结Dual16+SA、完整47状态GBDT+SA、完整47状态线性模型+SA。
- 初始化、候选池、每步四候选子集规则、PP顺序随机种子和SA接受随机流完全一致。
  各模型访问不同状态后候选当然可以不同；只保证同状态与决策索引下规则一致。
- 冻结策略仍选其原anchor；两个学习模型从包含anchor的同一确定性四候选子集中选。
- 保留零冲突任务。32次reset必须有效，至少16非零、至少6图提供修复状态；不满足只报告证据不足。
- 与所有保留manifest检查map/task seed及几何SHA隔离。已缺失历史文件列明，不能声称查验了不存在的数据。
- 禁止按冲突结果、难度、成功率重抽seed或替换地图。

## 资源、停止与记录

最多20个独立进程。每episode最多512次修复或2500万新增generated nodes，节点预算在完整修复之间检查，
因此记录单次修复造成的overshoot。这是机制诊断预算，不重新引入生产算法100步上限。
沿用单次PP 5秒、episode 300秒保护、外部360秒fuse。后两者是资源保护而不是正式性能预算。
正常耗尽512步/节点预算属于本协议未完成；wall_safety/incomplete_pp属于截尾，外部异常暂停检查。
截尾不伪造失败标签，报告观察成功数及把未知置0/1所得成功率差上下界。
不因某臂结果差而增加预算、重试或改变门槛。

每episode保存初始状态、增量trace、候选、分数、动作、特征越界、节点与冲突轨迹、最终路径质量及原子receipt。
复用进程运行锁，完成批次后可安全停止；已完成且哈希有效的episode在resume中跳过。
不完整episode需审计，不自动覆盖重跑。完整96项输出全部进行路径、特征、模型选择和随机流复核。

## 报告和解释

主结果为固定工作预算内的净成功数；同时报告32/64/128/256/512步完成曲线、地图得失、
修复次数、重复状态、共同成功的节点开销、SOC/makespan和特征越界。
地图级5,000次paired bootstrap描述不确定性，不要求每图胜、不要求提高5个百分点或区间完全为正。
不以共同成功的少数快例替代全组成功率，也不把多进程diagnostic_seconds称作TTF。

- 净成功数为正：保留有界闭环信号，完整列出损失及代价，之后才决定独立单worker TTF。
- 成功数持平但共同成功节点明显减少：作为计算开销方向的探索信号，不冒称成功率提高。
- 仅局部有效：保留描述，不事后筛图作为确认集。
- 有资源截尾：结论不确定，展示差值边界；不自动追加重跑。
- 无正收益：保留负面结果，不追加正则参数或第五个模型，不改冻结生产策略。

本轮最多2个全数据正式拟合、32个reset、96个闭环episode。
可复现测试在微型数据上执行，不额外采集H32训练标签。
按20进程、360秒fuse计5批的理想上界约30分钟，另加准备、生成、reset和逐轨迹审计；不是速度预测。
