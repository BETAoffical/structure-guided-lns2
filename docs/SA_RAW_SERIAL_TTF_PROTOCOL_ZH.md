# 冻结Raw选择器串行TTF与首解路径质量协议

2026-09-25。用户已明确授权进行计时验证。此前节点预算确认不作TTF证据。

## 数据、方法和边界

复用`sa-raw-independent-confirmation-v1`的六张仓库地图、12个任务、solver seeds251/257、两replica。
全部48配对条件都保留，四种方法共192次，不按已有结果筛选或改任务。
比较raw_parent、raw_updated、dual16_sa、official_sa，模型、PP+SIPPS和SA均冻结。
这批地图仍未参与拟合，但已有固定工作量结果被查看；本轮是预登记的计时确认，不宣称全新数据或跨布局泛化。

每次120秒首解即交付。只有全局墙钟预算，没有修复次数或搜索节点预算。
模型特征的256次/2500万节点缩放仍原样保留，超过后相应剩余比例为零，不成为终止条件。
PP调用获得全局剩余秒数，不沿用诊断中的20秒安全截断；因此截止点附近的路径可以不同。
每个子进程fuse为240秒，含启动和收尾，不作为额外求解预算。未知异常暂停整组，不自动重试。
不训练、不调温度、不改候选池、没有第二阶段anytime，不自动晋级默认控制器。

## 时间定义

- 常驻规划器主时钟：紧贴`env.reset()`前启动，包含初始PP、在线特征、候选、推理、SA、PP、在线检查和中间轨迹写入。
- 原始TTF：初始或某次PP返回首次可行状态的同一单调时钟时间。软预算外返回的解保留，但不算预算内成功。
- 有效交付时间：包含最后一次轨迹收尾、最终路径合法性检查、路径写出和文件哈希。它可能大于TTF或软预算，照实保留。
- 模型加载、环境构造分别作为setup报告，不计常驻TTF；worker启动后的冷总时间另记。父进程spawn/调度时间不是常驻TTF。
- 最后结果摘要的原子发布发生在交付时间采样之后，不是额外搜索；路径证据已在交付时写完。
- 理想任务完成时间为交付耗时加makespan乘0.5/1/2秒，主分析1秒，不称真实机器人测量。

Official和Dual16不计算新actor专用的129维特征/历史；Dual16仍使用其原GBDT候选打分。
这不是修改基线动作：计时前逐一核对192条来源的前三次动作、候选、模型特征/概率和路径前缀。
不重新运行已有整条来源轨迹，不为微基准追加不必要实验。

## 顺序、记录和暂停

单worker执行，48配对依次使用四方法的24种排列，每种恰好两次。
同一pair/replica共享初始fingerprint；显式方法使用既有共同PP/选择流，Official保留内部RNG。
各方法使用相同SA接受流。保留来源phase，所以无需引入新随机流解释差异。
记录全部候选、选择、冲突轨迹、节点、PP与空决策、分项耗时、SOC、makespan及等待步数。
准备和最终审计最多20进程，但正式计时时没有其他solver或审计并行运行。
接电、避免游戏和其他重负载；记录平台和线程环境。不能自动证明用户没有外部负载。

```powershell
python scripts/run_sa_raw_ttf.py prepare
python scripts/run_sa_raw_ttf.py preflight
python scripts/run_sa_raw_ttf.py all
python scripts/run_sa_raw_ttf.py stop
python scripts/run_sa_raw_ttf.py resume
python scripts/run_sa_raw_ttf.py audit
python scripts/run_sa_raw_ttf.py report
```

以上执行/审计命令需使用已登记WSL native。`stop`可在Windows运行，完成当前episode后停止。
`resume`只复用完整已校验episode；残留部分文件或失败记录要求先检查，不能静默重跑。
全部输出独立保存在忽略的`build/sa-raw-serial-ttf-v1`，历史数据不覆盖。

## 报告和验收

1. 分母192，48配对，逐条件列成功、预算内成功、按时交付及失败，不把失败填零TTF。
2. 主报成功率及共同成功原始TTF、交付时间；120秒失败惩罚仅作为另列的capped统计。
3. 对父模型、Dual16+SA、Official+SA分别给收益/损失案例、地图分层、配对胜负和5000次地图bootstrap。
4. 报成功TTF中位数/p95/最大值及SOC/makespan/理想完成时间，注明共同成功子集分母。
5. 六图统计不当成48张独立地图；不要求每任务全胜，也不凭一个均值直接晋级。
6. 正式前提交代码、协议、冻结哈希和前缀一致性证据。本轮不推送远端，保留本地Git bundle及证据备份。
7. 全部轨迹事后审计，任何非法路径、身份/特征/动作错配属于实验错误，不并入求解失败。

若成功率/TTF改善但makespan退化，分别报告，不用规划优势代替整批完成时间优势。
若真实TTF没有改善，先定位新增选择/历史计算开销，不因诊断节点下降就宣布更快，不用此批数据继续拟合。
