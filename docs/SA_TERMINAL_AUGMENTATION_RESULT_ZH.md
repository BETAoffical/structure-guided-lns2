# M04 终末集合补充与单次联合参考结果

## 结论

**定向补齐入口相关车辆没有恢复完整任务；一次五车联合参考耗尽节点，结论为未知，不是无解。**

本轮没有训练新模型、修改正式 Dual16/actor/PP/SA、开展 TTF 或扩大预算扫描。两个根来自同一个 M04 500-agent 任务、同一条来源轨迹，不能将分支数当作独立任务数。

- 沿用原候选四个 PP seed，完整重放 249 次历史修复；2/2 原动作控制精确复现。
- 新增 16 个 PP 分支，复用 SHA 固定的 8 个原组 trial。实际每个集合均有四个不同修复顺序。

## 唯一一次五车联合参考

在原生对照全部未清零后，按预留边界独立登记[联合参考协议](SA_TERMINAL_JOINT_REFERENCE_PROTOCOL_ZH.md)，提交 `9946e5f`。
只检查最早根 241 的 `[94,244,249,388,443]`，其余 495 条路径固定；不检查第二根、不追加预算。

参考器复用历史硬约束时空 A*，以 CBS 同时协调全部五车；它不是 native PP，也不是两车松弛。搜索预算 180 秒/1,000,000 次低层展开，进程 fuse 210 秒。

结果：`unknown / node_budget`，恰好消耗 1,000,000 次低层展开，展开 16 个高层节点，尚有 10 个 open 节点，未找到全任务见证。
五个根单车搜索均可行，成本分别为 94:96、244:45、249:92、388:78、443:45 步；每次单车搜索只忽略其余四个选中车，仍避开全部固定外部车。
这说明没有立即暴露“某个选中车单独就无路可走”，但不证明五条路径能同时兼容，也没有证明五车集合足够或不足。
由于无可行见证，没有执行或声称 native 成功路径注入验证。

## 对新模型和下一步的含义

1. 现有候选缺少三车组合是事实，但缺失不等于这个组合就是正确标签。本次不能以补齐组合为理由直接训练或改在线候选。
2. 问题不能仅用“选中冲突双方”解释；选中之后的路径兼容性与固定外部时空占用仍需区分。
3. 也不能反向下结论说评分器没有价值、样本再多也没用：更早选择能否避免这些末态，本轮没有测试；两个相关状态不是模型总体检验。
4. 停止围绕同一根继续加 seed、加车闭包、CBS/PBS 预算或同配方课程更新。历史已有局部改善但不完成任务，本轮再次说明不能以单步下降替代完成信号。
5. 暂不重训、不晋级。后续若继续新模型，应先提出能够提供原任务完整终局信用、且不同于既往 H32/课程/续跑的对照；若要研究协调修复器，则另立课题与 Official 同机制对照，不能悄悄更换 PP。

没有发现要求改正式控制器的证据；本次诊断也没有解决长尾。保留阴性/未知结论，不通过挑选均值或放宽词义制造晋级。
