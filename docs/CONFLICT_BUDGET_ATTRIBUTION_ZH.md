# 累计冲突预算归因审计

## 固定范围

从 `c0bf0de` 创建 `codex/initlns-conflict-budget-attribution`；恢复标签为 `pre-budget-attribution-20260910`。
本轮只读前一轮 24 状态、48 个状态/seed 条件及主方法已经保存的 37 个替代分支。
不调用 MAPF 搜索器，不训练、不改变控制器，不增加约束、候选、车辆或搜索预算，不启动正式计时。
之前 `mechanism_no_go` 结论保持不变。

## 检查内容

1. 从原始状态和每次实际尝试路径重建冲突事件，不直接信任日志的计数。
2. 重建每次插入后累计的唯一冲突车对。重复时刻不重复计费，终点持续占用和交换冲突均计入。
3. 只把涉及选中车辆的冲突计入邻域原有接受上限；外部车辆之间的冲突不混入此上限。
4. 区分此前内部冲突、最后一次插入的内部/外部冲突，以及首次超过上限的步骤。
5. 计算删除此前内部冲突、或理想地调整最多两辆内部车覆盖冲突对的乐观上界。它不考虑新路径能否存在或新冲突，不是可行性证明。
6. 对既有替代分支，只在共同已规划前缀长度上比较消失/新增的内部和外部冲突；不同长度不能直接当成同一完整结果比较。

使用最多 20 个进程，每条件原子写出，支持身份严格匹配的续跑。
遇到事件、路径、计数、文件 SHA 或输出身份不一致立即失败，不修正旧数据或继续输出有效结论。
报告是事后归因，不设置新的推广门槛，也不把乐观覆盖上界升级为恢复收益。
