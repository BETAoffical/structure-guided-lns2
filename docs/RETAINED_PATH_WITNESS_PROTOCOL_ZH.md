# 已保存路径的协调见证审计

## 目的与固定范围

本轮接续单外车软CAT完整负面结果。只用已保存路径检查三个相同失败状态的实际路径协调机会，不调用PP/SIPPS/CBS、不重新训练、不生成新路径、不计时比较，也不更改控制器。

保留原三个状态及失败时的原邻域。历史对照包含这些状态已有局部两车结果的全部成功、失败和unknown，不把其他状态成功当作这三个状态的证据。

进一步固定一个参考库：每个相同任务、相同solver seed、同120秒fixed_budget协议的Official Adaptive **首次可行路径**。不用第二阶段优化后的最终路径，不在多个成功参考中挑最有利者。缺少该指定参考或身份不符立即停止，不替换seed/控制器/预算。

这些路径来自别的算法的已有解。它们可用于事后验证某种路径组合存在，绝不能当作当前在线控制器能获得的输入或新的性能结果。

## 身份与真实性

- 绑定源码、配置、旧审计、源状态、历史结果、参考capture和native SHA。
- 地图障碍、agent ID、起终点、任务、solver seed及配对初始完整fingerprint一致；当前失败状态另验自己的完整fingerprint。
- 参考capture验证旧artifact envelope、binding及state fingerprint，并重新验证几何路径、顶点/交换冲突和终点持续占用。
- 最终参考路径必须全局无冲突。所有生成的混合路径都在当前失败状态的完整路径集合中重新验证，原邻域外的实际改动车辆单独记录。

## 二选一路径依赖，仅为存在性检查

每辆车只允许保留当前路径或采用其指定Official参考路径，不搜索第三条路径。

如果车i采用参考路径会碰撞车j的当前路径，建立有向依赖 `i -> j`。因此，采用i参考路径时必须同时采用j参考路径。参考路径彼此已无冲突，所以依赖闭合的集合不会产生新旧路径之间的新冲突；未替换车辆之间的原冲突可以保留。

对当前每个冲突端点分别计算最小依赖闭合集合，报告实际改动车辆数、其中原邻域外车辆数、消除的冲突对、SOC和makespan。对每个根，这是该固定二选一路径库下的最小闭合集合，不是所有可能MAPF路径中的最少车辆证明，也不是一个新在线候选生成器。

只有一个原冲突对时，枚举两端闭包可给出此固定参考库内消除该冲突的最少实际改动车辆数。多冲突状态不声称求出了全局最少车辆解。

描述性小规模界限固定为实际改动车辆不超过16，不能看到结果后提高。即使有小规模合法见证，也仅允许作为下一项独立机制设计依据，不能自动接入PP、推广或开始TTF。

## 执行与判断

依赖行按agent并行，最多20个进程；节点/边计算复用现有冲突重建器。所有根集合用完整状态重新检查，最小参考见证交给冻结native reset_paths校验。reset_paths只导入/验证，不运行路径搜索。

无全新solver rollout。结果和路径保存在忽略的 `build/initlns-retained-path-witness-v1`；整组锁，原子文件，异常停止，历史数据不覆盖。再次audit只重复离线核查，不涉及重新计时或搜索。

- 找到小规模见证：报告是内部重选、外部路径变更还是单纯不相关冲突消除；先对照已做过的重选/闭包/延续结果，避免重蹈覆辙。
- 只找到大规模参考替换：证明该固定库存在全局可行路径，不证明需要改这么多车；不能把大闭包直接部署。
- 历史只有同冲突数换路或一步下降：明确不是持续恢复。没有新的有区别假设则停止扩展。
- 缺失或身份错误：报告证据不足/无效，禁止借用同地图不同任务的路径。

预计离线检查数分钟，最多20workers。主输出为中文证据与停止/继续边界，不是新性能表。代码、测试、配置及输入SHA在正式混合路径审计前推送。
