# H32匹配标签聚合：成员选择改善，但未形成整体优势

## 结论

本轮真正训练了新模型，不只是检验标签。固定GBDT参数，8折各训练一次，
每折整张地图及其新旧采集组全部留出。没有新采集、调参、求解或正式TTF。

**新增同来源标签改善了旧H32模型在成员选择上的表现，但收益未超过原Dual16分数，
并损失了旧四候选任务上的部分能力。** 这是局部正信号与整体取舍，不是“所有模型失败”，
也不是因为要求每个案例都必须获胜而否决。正式控制器保持原样。

## 数据与模型

- 47个根状态、8张已查看的station-centric开发地图，非独立确认或跨布局测试。
- 旧47个四候选组，加47个同来源同size16二候选组，共94组、2256个已有H32结果。
- 每组8trial先聚合，再构成组内比较；329个无向pair、658个正反训练行仍只有47个状态。
- 每根总权重保持1，新旧组各占一半；再作地图平衡。不存在组间伪配对或同根翻倍计权。
- 新模型仍为100树、7叶的HistGradientBoostingRegressor，输入127维动作前特征。
- 标签仍为最多32步、冻结Dual16+SA续跑条件下的完成率差，不是一步下降、TTF或剩余轮数。
- 本轮未增加history字段，不能称为完整的历史条件化新策略。

旧H32对照使用已经精确重建的47状态留图模型，不是更早的16状态模型。
“原Dual16分数”只在各组的候选范围内选择，不能冒充重新运行完整Dual16闭环。

## 具体进展与失败原因

### 一个以前稳定选错的案例得到纠正

`af41defd15b848f64ffaf816-d0016`的两个同来源邻域，已有结果为8/8和3/8完成。
原Dual16分数、旧H32都选择3/8者；本轮留出该地图训练的新模型选择了8/8者。
不是用该根标签拟合后再回测它，也不是平局规则改动：47个主比较的三种模型均无精确分数平局。

因此“127维特征完全没有成员区分信息”并不符合本轮结果。
但这仍是已查看开发集上的一个改正，不能保证在新地图或真实连续控制中同样奏效。

### 旧任务出现损失，不是自动安全增强

`11e6b02cd8deffc1743aa11d-d0016`的旧四候选任务中，旧H32选择6/8者，
聚合模型选择2/8者。二者都来自Target:16，实际成员数分别为16和15。
另一根`47c8eead2979a7b0b05c1fa4-d0004`，旧H32选7/8者，新模型选4/8者。

这些损失说明不能将原因全部归为“跨规则选择错了”，也不能保证简单拆成两层就能解决。
候选成员、实际大小、与其他候选的相对关系都可能参与；本轮没有逐一隔离其因果贡献。

### 训练内拟合较好，留图收益缩小

八折训练内、先地图等权再折等权，相对组内均匀选择的平均增益：

- 同来源二候选：训练内+3.8802个百分点，留图+0.9115。
- 旧四候选：训练内+6.5848个百分点，留图+0.9896。

训练内折之间重复使用状态，这些数字只描述拟合，不能当更多独立证据。
差距支持当前表示/样本下仍有泛化不足，不支持优先增加容量。
H32终止标签还受到PP顺序、SA随机接受及后续策略共同影响；有限trial的经验优劣并非确定真值。

此外，本轮每根训练份额从全部旧四候选改为新旧组各一半。
**新增覆盖与训练任务权重重分配同时发生**，不能把结果完全归因为“补采更多数据”。
总权重不变只排除了同根重复计权，不意味着两个任务的优化不会互相影响。

## 下一步的边界

保留聚合模型为研究原型，不直接替换Dual16或旧H32，也不自动扩大TTF或RL。
它不是完全没有学到东西，但还没有证明可带来更高完整成功率或更短长尾。

历史[成对一致性审计](SA_PAIRWISE_CONSISTENCY_RESULT_ZH.md)已试过直接anchor比较和矛盾否决，
[低复杂度排序器](SA_LOW_COMPLEXITY_RANKER_RESULT_ZH.md)已试线性效用与分组SVM，
[策略预算对齐更新](SA_POLICY_ALIGNED_UPDATE_RESULT_ZH.md)也已试过新策略访问状态与两种续跑标签。
不能把这些方案换个名字再跑，更不能把本次损失直接归因为成对循环或一步标签。

若继续，优先设计一个范围更窄的问题：如何保留旧全局排序能力，同时利用新增的同来源成员信号。
要先说明与历史anchor门控的区别，以及模型在动作前凭什么决定使用成员修正。
固定旧模型加独立成员修正是候选设计，不是本轮已经验证的方案；
不能事后按哪个模型在该根更好来混合，也不扫描本批新旧标签权重直到出现正结果。
没有清楚的新识别信号时，应保留当前局部成果和负面结果，而不是立即再训练一轮。
