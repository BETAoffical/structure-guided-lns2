# 原任务内部终局支持诊断

本轮不训练、不更新模型、无TTF，不改PP、SA、候选或正式控制器。
使用完整原任务的中间状态，而不是删除车辆；试验后也不能把条件续跑成功率称为原任务成功率。

## 历史排重

- 首次梯度拆分、状态基线、探索比例、课程续训已经执行，不重复。
- 旧晚期状态实验使用固定decision32/64/96、四个强制根候选、128次决策上限。
- 本轮由当前actor-1在原任务上自然到达的状态出发，全候选策略持续运行至终局或原25M节点预算耗尽。
- 保留原绝对decision、历史、温度及已消耗节点，不重热、不清空历史、不补发25M预算，不强制选根动作。
- 这不是首次研究中间状态，也不是成功教师轨迹已经存在的证明。

## 选择与边界

只用已审计第二批actor-1的六张Train图、原bottleneck_d25、solver233/239、replica0..3，共48条。
遍历每条轨迹，取首次出现1--10冲突且仍有原节点预算的修复前状态，不取事后最低点。
每图按(pair_id, replica, episode_id)排序，选第一个存在该状态的来源，最多一个根；所有未选来源及缺失地图登记。
不按该来源最后成功与否选择，不读M06/M07、Validation、Test、OOD或课程模型新评价来选根。

已在设计检查中看过这48条轨迹及阈值覆盖，因此这是公开的开发性、事后机制诊断，不冒充盲预注册确认。
六根并不是六个独立新地图；同一根四次重复不算四个独立状态。

## 执行

1. 冻结代码/配置/原轨迹/模型/native SHA，建立独立build输出，保留备份。
2. 每根重放完整原动作prefix、完整历史和节点；在根重新生成候选，逐项核对特征/概率。
3. 六个control执行原根动作，下一状态、路径、节点fingerprint必须复现。任何错误停止，不发布续跑标签。
4. 每根4条新随机流，从完整原状态开始，策略始终是同一actor-1；最多24条。
5. 无决策上限；继承原25M修复节点预算，原子PP允许最后一次调用越过节点边界。
6. 最多20个独立进程，单步20秒保护、后缀900秒保护、含重放的进程fuse1860秒。保护触发记未知，不记无解。
7. 完成当前批次可安全停止；缺失/异常不自动重试。逐作业原子结果、增量进度和完整trace。

根状态重放和原下一步验证消耗额外诊断算力，这不计入科学轨迹的节点两次，也不作为部署TTF。
低冲突不意味着容易；特别报告到根时已花费的节点与剩余预算，不能把预算不足解释为模型无能。

## 解释

- 全原任务失败条件出现后缀成功：得到完整车辆/OD下的条件成功见证，但非新控制器成功率增益。
- 同根成败混合：可能提供状态条件终局信息，仍需独立训练合同；不能给未选动作编标签或把后缀回报倒填旧prefix梯度。
- 所有重复成功/失败：保留轨迹，但没有该根内的对照信用；不自动扩大trial、预算或更换阈值。
- 审计错误/保护截断：未知，先查实现，不算科学失败。

无自动训练或晋级。先报告根级完成、最低/终局冲突、原剩余预算、路径质量及历史排重结论。
