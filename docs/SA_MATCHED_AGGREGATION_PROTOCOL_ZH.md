# 同来源补采后的固定模型聚合验证

## 问题与边界

上轮496个新H32结果补齐了31根，但47根合并的标签分半选择增益只有0.309个百分点，
区间跨0。本轮只回答：动作前特征能否通过跨状态学习利用这些弱信号。
不是重做标签稳定性测试，不增加trials、网络容量或一步下降目标。
全部地图已查看，属于开发验证；不进行新采集、正式TTF、RL或控制器替换。

## 冻结模型与数据

- 47根、8张地图；原47个四候选组加47个同来源二候选组，共94组。
- 旧1504个结果加752个匹配pair结果，共2256个H32结果；额外anchor诊断不入训练。
- 仅在组内构成282+47=329个无向比较，正反方向共658行，不是658个独立状态。
- 保留全部平局；标签为8个配对trial的平均H32完成率差，未知结果不能当失败。
- 旧、新组各有自己的随机流，相同trial编号不跨组配对。
- 根预算为1，均分到两个组，再均分到组内候选对及正反方向；训练地图等权，保持总权重等于训练根数。
- 整张地图的所有根和所有组一起留出。8折各只训练一次，无参数搜索或按结果再训练。

固定HistGradientBoostingRegressor：100棵树、7叶、min leaf10、learning rate0.05、L2为0.1、
seed20260916，不早停。输入沿用127维动态邻域、旧pool分数、decision和温度，
pair向量为差值加均值，共254维。不增加history或显式静态上下文，不能称为新历史条件化模型。

## 特征与冻结对照

复用已验证的native动作前提取器，47根的188个原候选向量必须逐值复现；
新增候选从同一输入pool提取，禁止使用修复后路径、trial结果、runtime或generated nodes。
新增输入向量同时检查agent成员、candidate ID、特征名及有限数值。

固定比较：

1. 当前组内均匀选择的精确期望。
2. 冻结Dual16原pool分数，限制在同一候选组内选择。
3. 已重建并逐分数复现的47状态旧H32模型，对应同一留地图折，不重新拟合。
4. 本次加入匹配标签后的固定H32聚合模型。
5. 同组标签事后最优者，只作为有抽样乐观偏差的经验上界。

二候选分数取正反预测差的一半；四候选延用原pairwise总分。
平局优先真实anchor（若它属于组），随后candidate ID。缺失anchor不伪造标签。
保存所有分数；不能把分数差称为校准后的成功概率。

## 指标与解释

主分析是47个匹配二候选组，次分析是47个原四候选组，两种候选空间不混算。
报告地图等权H32完成率、相对均匀/旧pool/旧H32的差值、逐图和逐根结果、选择改变与经验oracle差距。
5,000次地图级paired bootstrap，seed202609183；同根多个组或trial不当独立样本。
训练内结果单独描述，不能与留图结果合并。

不新设“所有地图必须更好”的门槛，也不将正的点估计直接判为正式晋级。
根据均值、幅度、区间和逐图损益解释；不按结果换参数、去掉负面地图或挑选子组模型。
只有有意义的动作前预测信号才讨论另立闭环验证；本轮任何结果都不自动部署或恢复TTF主张。
若无稳定增量，保留完整负面结果，分析是训练拟合/泛化差异还是匹配任务上的方向错误，
不自动继续容量搜索或扩采。
