# Bootstrap 概率选择的有界闭环结果

2026-09-18。完成 64 个 episode、7,414 次修复及逐步审计。未修改正式控制器，未运行正式 TTF。

## 结论

按[冻结协议](SA_BOOTSTRAP_CLOSED_LOOP_PROTOCOL_ZH.md)，概率选择没有改善原 Dual16+SA 的净完成收益，也没有超过均匀随机的完成数。本轮不是因为没有每图必胜或差一点达到 5% 而否决：相对冻结策略，概率选择少完成 4 个实例，没有独自救回任何实例，共同成功案例的工作量也更高。

这只否定当前训练数据、模型和预算下的这个原型，不证明所有概率策略或所有新模型无效。保留相对新单 GBDT 的小改善，但不替换强对照。

## 做了什么

- 原训练数据仍为 47 状态、8 地图、188 候选、1504 个 H32 trial，没有新增监督标签。
- 单 GBDT 直接复用已有完整训练模型。新增 20 个地图 bootstrap GBDT 回归器，参数不变；目标仍是候选间 H32 完成率差值，127 维候选特征形成 254 维成对输入。
- 概率选择每步均匀抽一个成员，再选择该成员的首选候选；这是成员投票分布抽样，不是校准后的贝叶斯成功概率，不是 ensemble 平均分。
- 四臂使用相同候选定义、PP/SIPPS、SA 温度和 PP/接受随机流。选择随机流独立，路径分化后允许候选池自然分化。候选子集最多 4 个，始终包含当前冻结 Dual16 anchor。
- 复用此前已查看的 8 张 station-centric 仓库开发地图，固定哈希每图选 1 个任务，solver seeds 227/229。未按结果替换任务；与训练地图隔离，但不是新的独立确认数据。
- 8 个任务中两项为 density 0.20，六项为 0.25；agent 数量 325–539，初始冲突对数 70–518，均值 232.25。
- 每臂 16 个实例，最多 128 次修复或 2500 万 generated nodes。PP/episode/process 时间保护为 20/300/360 秒，最多 20 个独立进程。
- 本轮没有时间截尾，也没有触发节点上限；所有未完成实例都正常停在 128 次修复。这不是证明无解，不代表延长预算后的最终成功率。

## 不只是末期卡住

以下是事后描述，不用于修改模型或预算。对已成功实例按后续冲突为零补齐，其余实例均实际运行至 128 步；从保存的冲突序列直接求均值：

| 方法 | 初始 | 第32次修复后 | 第64次后 | 第128次后 |
|---|---:|---:|---:|---:|
| 冻结 | 232.25 | 67.25 | 33.00 | 11.25 |
| 单 GBDT | 232.25 | 89.31 | 56.75 | 37.44 |
| 概率选择 | 232.25 | 94.44 | 57.00 | 29.19 |
| 随机 | 232.25 | 108.56 | 56.06 | 32.94 |

概率选择未完成的 14 例最终仍剩 7–58 对冲突，不是普遍只卡在最后 1–2 对。与冻结逐例比较，最终冲突数 0 例更低、2 例相同、14 例更高。差距在前中期已经出现，所以不能只把本轮退化解释为终点停车或最后两车的路径兼容性。

概率选择偏离当前 Dual16 anchor 的比例为 77.72%，单 GBDT 为 86.02%，随机为 74.09%。这是各自访问状态上的描述，不能直接做因果归因。

概率选择有 6 次完全相同路径状态再访问，占 1930 次决策的 0.31%；冻结为 4/1528，0.26%。这不支持把坏表现全部解释为大量完全相同状态的死循环，但不排除近似循环、相同冲突结构或无效路径变化。重复邻域率未单独统计，不能用路径重复率替代它。

概率选择决策加权的特征越界比例约 1.45%。这是逐列超出旧训练最小/最大值的比例，不是联合分布覆盖率；不能据此否定状态分布偏移。

## 工作量和路径质量

概率选择与冻结共同成功的 2 例：

- generated nodes：8,207,791 对 6,095,465，增加 34.65%。
- 修复次数：138 对 81，增加 70.37%。
- SOC 总和：67,224 对 67,442，减少约 0.32%。
- makespan 总和：276 对 272，增加约 1.47%。

这里只是两个共同成功实例的条件比较，不外推全部任务的路径质量。没有串行 TTF，不能计算真实交付时间或整批机器人完成时间。全组节点总量较低也不能表示更快完成，因为有更多任务到预算结束仍未完成。

JSON 中通用 `completion_curve` 包含 256/512 的已观察完成计数；这些不是运行到该预算的结果。本轮只解释 32/64/128 范围，不把更高分箱当延长实验。

## 与历史相结合

1. [离线一致性审计](SA_UNCERTAINTY_AUDIT_RESULT_ZH.md)显示概率选择的 H32 根动作期望优于随机，但劣于单 GBDT；本轮补上此前没有做的连续概率选择验证，没有再次优化一步冲突下降。
2. [线性闭环](SA_LINEAR_CLOSED_LOOP_RESULT_ZH.md)已显示简单模型虽优于新 GBDT，仍不如原策略。此次概率化重现了“优于较差的新模型，不等于优于强对照”的问题。
3. [策略对齐更新](SA_POLICY_ALIGNED_UPDATE_RESULT_ZH.md)和[干预频率](SA_INTERVENTION_FREQUENCY_RESULT_ZH.md)已有负面证据，不能接着把“再加同类访问状态”或“减少使用次数”换名重做。

当前可确认：随机化没有补回足够的连续修复进展，差距不是因为部署没有抽到不同成员或模型推理不一致。仍只是待验证的解释：H32 标签评价根动作后交给冻结参考策略，连续控制却每步再次换动作；训练目标对应的策略与实际部署策略不同，47 状态也不足以保证后续状态的可靠价值估计。本轮没有把这一解释单独做因果识别，不能断言它是唯一原因。

## 下一步边界

停止扩大这套 bootstrap 选择器，不追加成员数、树参数、温度或挑选更有利种子；不以降低门槛恢复正结论。保留原 Dual16+SA 和本轮所有负面记录。

若继续新模型研究，必须先给出与已失败的单次干预、频率调整、策略访问状态补样不同的决策信号，并使训练标签真正对应预定的连续控制方式；“再训练一次相同 H32 排序器”不是这个信号。当前结果不足以直接启动 RL 或正式 TTF。它也不证明所有新模型不可行。
