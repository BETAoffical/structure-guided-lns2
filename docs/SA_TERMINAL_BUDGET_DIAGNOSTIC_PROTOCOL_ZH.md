# M04 原随机流有界工作预算诊断

## 问题与历史边界

原任务内部支持诊断中，M04 的500辆车、原bottleneck_d25任务在累计
24,058,245节点时首次到达10对冲突，原25M预算只剩941,755节点。
四条已审计后缀在预算结束时分别剩1、7、10、16对冲突，均未完成。
本轮检验这个已知根是否存在额外少量工作即可到达的终局，不证明模型改进。

旧120→300秒实验已经说明：延长时间不能普遍消除SA长尾，旧Official恢复比
Dual16+SA更多。本轮不是重复该速度比较，而是当前actor-1的同一Train根、
同四条随机流、固定节点预算干预。它仍是事后选择困难根的开发诊断。
不得声称首次研究延长预算，也不得把四条后缀当成四张独立地图。

## 固定协议

- 只续跑上一轮M04的全部trial 0/1/2/3；不读取M06/M07、Validation、Test或OOD。
- 总修复generated上限30M，即比原25M增加20%；最后原子PP允许越界。
- 不设决策次数上限，不在失败后自动增加预算或trials。
- 模型、PP、候选生成、历史、绝对decision、SA温度和随机流完全冻结。
- 模型输入仍以原25M和256为缩放常量，二者均不是新停止条件。
  超过25M后remaining_node_fraction由原公式自然截为0，不重置、重缩放或重新训练。
  这些新状态超出原收集工作范围，完整保留特征越界率，不声称训练分布内。
- 先重放227步原prefix及每条原后缀，检查候选、特征、概率、动作、SA随机数、
  路径增量、节点、状态fingerprint和历史完全一致，再允许新一步。
- 新结果只能写入独立build目录；原25M结论保持0/4。
- 四作业四独立进程。后缀900秒安全保护、含重放1860秒fuse；截断属于未知。
  不测TTF、不训练、不生成自动晋级判断、不修改正式控制器。
- 支持完整作业resume和完成当前批次后停止；异常或部分输出必须先检查。

## 验收与解释

四条前缀必须逐项一致。新轨迹离线重建历史、特征、概率和随机选择，校验
每步SA转移与最终路径；计算原25M和新30M口径，不能将额外工作算成原预算成功。
成功时记录新增节点、决策、SOC、makespan和等待；失败只说明该有限预算未找到，
不说明不可行。源SHA和完整性校验通过后才出结论。

- 出现成功：获得原任务的条件终局见证，说明至少这些随机流受到原剩余工作量限制；
  不能推断所有长尾是预算问题，也不直接将新轨迹加入旧终局训练合同。
- 全部未成功：单纯补20%工作未恢复本根，停止预算扫描，保留未知/失败分类。
- 保护截断或重放错误：先报告未知或实现错误，不计作科学失败，不自动重跑。

预计确切作业数4；原prefix与旧后缀共950次重放，不是新增决策样本。
新增节点许可总和小于20M，重放也需计算资源，不能以此预测端到端TTF。
