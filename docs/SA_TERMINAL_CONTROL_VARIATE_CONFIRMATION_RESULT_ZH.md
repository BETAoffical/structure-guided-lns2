# 冻结终局基线独立随机流确认结果

## 结论

**冻结加权基线的降噪信号未重现，保留A，不更新模型。**

上一轮在已有64条轨迹上做交叉拟合，显示相对LORO二阶矩下降18.60%，仅属于描述性信号。本轮先从那些轨迹拟合并冻结两个标量基线，再对64条新独立随机流进行确认；加权基线相对同样冻结的普通均值基线，四条件等权二阶矩反而增加**12.8076%**。

比较口径不同，不能把两轮百分比当作同一个量的直接复测。关键区别是：本轮不允许评估数据参与基线拟合，检查真正的新随机流泛化。

这不是TTF、成功率或模型能力的改善/退化实验。两种基线读取同一批A轨迹，A、Dual16候选池、PP+SIPPS、SA和native均未改动。本轮也没有更新参数。

## 数据与完整性

- 四个已查看Train条件：M01-d20、M00-d25、M02-d25、M04-d20；每条件16条。
- 完整64/64：45条成功，19条正常耗尽2500万generated节点边界；0错误、0安全超时未知。节点边界在原子修复之后检查，可以略微跨界。
- 无决策次数上限；每条独立重置，输入任务、初始fingerprint与冻结A身份保持一致。
- 64/64完整native审计通过，包括动作、概率、随机流、特征、状态增量、路径与终止语义。
- 完整终局score维度4193；两个基线均仅从上一轮对应16条轨迹拟合，未使用新标签重拟合。
- 20-worker采集四批累计约1095.84秒，native审计约657.17秒；这两项是并行工作时长，不是单worker TTF。

## 为什么M00反转

以下是对冻结score文件的事后解释，不用于重新拟合基线、重新判门槛或更新A。每条能量定义为完整轨迹`||S||²`，不是runtime或路径长度。

| M00能量 | 拟合批 | 新批 |
|---|---:|---:|
| 成功轨迹score能量总和 | 1217.9842 | 10083.0787 |
| 失败轨迹score能量总和 | 39360.1611 | 12069.0850 |
| 成功能量占比 | 约3.00% | 约45.52% |

旧批失败轨迹支配能量，给出了接近0的加权基线。新批出现若干高score能量成功轨迹，成功总能量约为旧批的8.28倍；旧基线对这些成功轨迹几乎保留完整贡献，而普通均值基线对其贡献有更多削减。

新批M00最大单条贡献约占均值基线二阶矩总和34.29%，加权基线下约36.43%；M02最大单条贡献占66.71%。说明估计仍受少量轨迹影响，而不是换一个小标量就能消除所有不稳定性。

两个批次的条件、模型和程序身份一致。这是有限独立随机轨迹中观察到的成败与score能量关系变化，不能仅凭16条/批就断言真实分布已经改变，也不能把它归因于地图修改或程序中断。

## 数值边界说明

M01拟合时的加权b保存为`0.9999999999999998`，而不是数学上的1。新批全成功，使普通均值基线二阶矩为0，加权值留下约`2.27e-30`。

预注册的严格零分母检查将该条件保护标为false。这是浮点舍入造成的数值标记，不是真实科学退化，也不应作为否决方法的实质理由。本轮保留正式JSON和门槛，不事后改写判定；即便将该残差视为0，**总体+12.8%与M00+34.1%仍然不通过**。后续新协议应在标签产生前明确常数回报与数值零的处理，不用这种残差卡住晋级。

## 下一步边界

保留A与原有正式TTF结论。停止把这套每条件16条拟合的加权标量基线当作新训练更新的依据，不继续追加同四条件的随机轨迹直到出现好结果。

若继续研究，先用已有更广Train轨迹做只读的影响度与跨条件稳定性检查，确认是否能以共享或收缩基线减少单条轨迹支配；历史状态Ridge基线已有负面结果，不能简单再训练同样的状态回归器。新的基线、更新、模型或端到端实验需要另立协议，不用本批结果反复选系数后宣称独立确认。
