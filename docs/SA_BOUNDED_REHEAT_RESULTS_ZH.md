# 有限回温机制探针结果

## 结论

单次16步、按此前冲突增量定标的回温窗口，产生了局部持续收益，但没有新增零冲突完成。预注册结论为 `no_completion_benefit`，不是所有指标都无效，也不是已证明回温永远无效。

本轮不替换正式 Dual16+SA，不启动TTF，不追加温度、窗口或trial。模型、候选生成、官方兼容PP+SIPPS和原120/300秒结果保持不变。

- 9个已查看状态，每个4个配对trial、原退火/有限回温两臂，共72个分支；另有2个两步smoke。
- 3个主要状态均来自同一张地图0004；trial及不同solver seed不能当成独立地图。
- 原退火 `T=1000*0.99^decision`；回温仅在16步内设置基于此前32次尝试的温度下限，之后恢复原绝对轮次冷却。没有强制接受。
- 每分支最多128步、5000万generated节点、180秒资源安全窗口。并发诊断耗时不是TTF。
- trial0复用原后续随机流；trial1--3只改变入口后的PP/接受随机流，两臂配对。入口及候选池严格相同。

## 局部收益与代价

仅统计12个主要配对分支，不与未干预成功对照混合：

| 指标 | 原退火 | 回温 | 变化 |
|---|---:|---:|---:|
| 平均最终冲突 | 6.75 | 5.75 | 降低14.815% |
| 平均固定128步冲突AUC | 1361.958333 | 1239.041667 | 降低9.025% |
| generated总节点 | 189930817 | 183383819 | 降低3.447% |
| 完成分支 | 1/12 | 1/12 | 不变 |

AUC按相邻冲突数梯形面积求和，提前可行补零。最终冲突2对改善、10对相同；AUC为3对改善、3对退化、6对相同。小幅AUC退化也保留，不能称全面更好。

两项最终冲突改善分别为 `23 -> 18` 和 `11 -> 4`，但都没有可行。另一个分支最终均剩1对冲突，AUC `672.5 -> 503.5`，generated却从16077845增至18866474，增加17.345%。因此冲突进展和计算代价并不总是一致。

唯一完成的主要trial，两臂均用122步完成，不能将其算作回温恢复。

## 原因分析

1. **提高温度不等于改变轨迹。** 12对主要分支中，6对路径及冲突关系始终一致。窗口对典型增量给出有限接受概率，不保证放行某次大幅恶化，例如首个主要状态入口的 `+5` 从0.304%提升到3.125%，仍未被接受。这是预定的有界策略，不是实现没有生效。
2. **改变轨迹也不等于持续离开停滞区域。** 另外6对实际分叉，其中3对后来重新汇合到相同路径及冲突关系；它们均来自第一个主要状态，分别在入口后第13、34、6步汇合并保持一致至末尾。
3. **剩下3对保持分叉，只有2对最终冲突更少，没有新增完成。** 当前数据支持局部探索机会，尚不支持消除最后残余冲突或改善成功率。
4. **有一类停滞不受接受温度控制。** 负对照的4个回温分支共512步全部维持6对冲突，0次变差尝试；两臂路径状态完全相同。温度无法放行一个修复器没有产生的候选路径。
5. **不能把所有失败归咎于选择器。** 这里冻结了候选、排序器和PP，未分离三者对后续停滞的贡献。轨迹汇合不是对“一步最优必然错误”的证明，也不证明某个剩余状态不可修复。

物理状态采用现有 `audit_sa_cooling_traces.PhysicalIdentity`，包含地图、带ID路径和冲突边，排除计数与时间，仅作分析。主要组最终9/12对物理状态相同；包含低层计数的正式fingerprint相同为8/12，二者不能混称。正式重放/RNG的fingerprint从未替换。

- [单次拒绝反事实](SA_REJECTION_BRANCH_RESULTS_ZH.md)已经出现收益和损失，不能用本次局部信号恢复“强制接受所有恶化”的路线。
- [稳定候选后续轨迹](STABLE_CANDIDATE_CONTINUATION_RESULT_ZH.md)已经表明一次下降可能只是降低停滞平台。本次部分改善持续到128步但仍未完成，不能再次用一步下降替代成功证据。
- [冷却审计](SA_COOLING_TRACE_RESULTS_ZH.md)区分了早期高接受率失败与后期低温拒绝；本次只否定这一个有限回温变体足以提高所测状态完成率，不否定原SA已验证的历史恢复收益。
- 不自动加温、加长窗口、增加trial或延长TTF。保留原Dual16+SA及本轮负面/局部结果。若继续设计新机制，必须同时解释如何产生可用的新路径、为何不立即回到旧的选择区域，并先与已有候选回退和路径重选负面记录比较，不能仅换一个温度重复本轮。
