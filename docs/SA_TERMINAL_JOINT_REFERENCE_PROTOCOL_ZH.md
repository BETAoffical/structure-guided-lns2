# 补充集合失败后的单次联合参考检查

触发条件是上一阶段定向、随机、原组均未清零，已满足。该阶段是预留的一个参考作业，不追加 native trial。

固定选择最早根 decision 241 的定向集合 `[94,244,249,388,443]`，不是根据哪个 PP seed 最好选择；其余 495 辆车的完整路径固定。联合协调全部五辆，不把两车松弛当作五车可行。

参考器复用现有通过独立动态网格校验的硬约束时空 A* 和冲突提取，将历史两车 CBS 的约束树展开到最多五车。顶点及交换冲突分别对双方分支，终点永久占用保留，单车静态尾完整搜索，没有人为路径时限。只运行一个节点预算 1,000,000、搜索保护 180 秒、进程 fuse 210 秒的作业，不重复、不扩大、不扫算法参数。搜不到且预算耗尽是 unknown；只有单车完整搜索不可行或 CBS 队列完整耗尽才记 scoped infeasible。

这是参考搜索，不是官方 PP 的修复逻辑；不更改正式 native、模型、SA、候选或训练。

- feasible：保存五辆车全部路径，回注原完整任务独立核验；随后还须冻结 native `reset_paths` 校验，不能说 native PP 成功。
- infeasible：仅证明固定这 495 条外部路径时该五车集合不够，不证明原任务不可解，也不识别最小必须移动的外部集合。
- unknown：不能区分集合与路径协调，停止本轮，不再自动增预算或从另一个根开始。

本检查是事后开发证据、不是 TTF，也不是集合生成器或新模型。所有旧原生分支、登记及 SHA 保留。单作业不虚设20进程；新增参考代码只服务本次边界判别。
