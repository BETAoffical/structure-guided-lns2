# SA 残余状态的必要配对兼容性

本轮不修改正式 PP、PBS、Dual16、退火或模型，不训练、不跑 TTF。恢复点为 `pre-sa-pair-compatibility-20260914`。

## 新问题及历史边界

旧 PBS 固定整个16车集合，在三个状态预算内没有下降。旧两车 CBS 固定其余所有车，旧补车和软 CAT 消融也没有证明当前16车集合缺车。
本轮检查必要条件：当前每条冲突边的两车，在忽略其余选中车辆、但仍固定集合外所有真实路径时，能否协调。
这种放松问题若完整穷尽仍不可行，才证明原16车集合不足以清零。找到解只代表两车放松问题可行，不能当作16车见证。
三个状态来自同一已查看地图，不是独立样本。当前原路径已经逐车避开外部路径，故不重复单车可达性检查。

## 迭代与停止

1. 三个冻结状态的13条冲突边，分别固定其他所有车、或忽略同集合其余车辆，共26个参考CBS作业。复用历史 BFS 单车搜索，不改变旧源码。
2. 每作业45秒、250000低层展开，20个独立进程，90秒硬fuse；预算未知不是无解。并发时间不解释为TTF。
3. 只有BFS预算未知的相同作业，才用新的确定性空间启发式A*单车搜索复核一次，其他外部路径、CBS分支及预算相同。A*先与BFS和独立时间展开小图验证最短成本/可行性；不得以路径变化误判旧实现错误。
4. 硬约束参考见证先独立校验，再放回完整原状态计算新增冲突。不能删除忽略车辆来伪造成功，也不能把硬参考修复当成官方软冲突PP。
5. 若放松问题完整不可行，下一轮只诊断该证书涉及的外部条件；若找到可完整注入的改进，下一轮才对同一机制做有界原生路径验收。其余未知不加预算、不继续PBS参数扫描。
6. 没有稳定且可部署的候选改进标签，不直接重训。历史HistoryRank、Feedback Exploration、回温和宽泛补车不重开。

所有输入及实现SHA在作业前登记，逐作业原子结果、独立日志、显式resume。原始错误保留并先查因。源码分阶段本地提交，结果留在build并做完整备份。
