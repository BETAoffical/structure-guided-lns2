# 三轮SA与选择层诊断：保留效率优势，识别探索覆盖缺口

## 结论

完成历史/论文回查、已有60条轨迹的条件审计，以及两组新初始化的100条五路对照。
模型+SA重复表现出较少修复和较低搜索量；均匀选择覆盖更全，但共同成功案例的累计工作更多。
没有发现本轮接受公式、最高分选择、动作成员或原生路径校验错误。
发现的是设计局限：确定性最高分选择可能持续重复零下降动作，SA不能自行生成另一种邻域；
同时，在当前尺度下T=1000几乎允许所有更差尝试，并非细粒度的风险判断器。

本轮不是正式TTF，不是Official与新算法对照，不是新地图泛化。
所有挑战臂均保留同一个Dual16候选生成器；只有选择方式与接受方式不同。
不改默认Dual16、不训练、不启用RL、不用本轮结果改写历史门槛。

## 2. 第一轮：条件检查

复核已有60条的最高模型分数、请求成员、接受概率、接受决定和来源SHA：全部一致。

- 默认1405次修复中1275次零下降；完整贪心1558次中1428次零下降。
- SA共585次修复，327次零下降；73次更差尝试接受72次。
- 更差尝试的接受概率最低0.988268、平均0.997481。
- 这并非接受公式实现错误，而是当前温度相对冲突变化很高。
- 完整fingerprint包含低层计数；仅改变generated即可改变fingerprint，后者进入proposal随机流。
  用完整计数验证重放有合理用途，不能据此删除；其与候选随机流的耦合可能影响对照，尚未隔离因果。

默认允许等冲突路径更新；`replan_success`表示接受成功，不等于严格冲突下降。
如果未来把该布尔值直接当作进展或脱困证据，会发生语义错误；本轮指标使用实际冲突数，不做这种替代。

## 3. 第二、三轮设计与结果

五张已有station_centric仓库开发地图、五个已有静态OD任务，各四个新初始化seed。
第二轮7/11，第三轮13/17。239--299辆车，初始冲突7--52对，20/20有效且均有冲突；不筛选或替换。
本项目冻结PP生成初始路径后规范化导入，所有臂共享完整初始状态；不继承作者的初始化内部计数。
不是20张独立地图，也不是封存Validation/Test的评估。

原20个作者路径中的那个SA损失仍保留，不能因这20个新初始化零损失就消除旧证据。

## 4. 预注册判定

- 模型+完整贪心：未过。第二轮新增两个损失，总generated比默认高37.5%。不能把完整PP本身直接作为补丁。
- 模型+SA：两轮均无损失且各恢复一个，但都来自13号任务。未过两个不同任务覆盖条件；保留明显效率信号。
- 均匀贪心、均匀SA：均通过本轮有限开发准入；两轮各有新增成功、无损失，覆盖09/13两任务，节点不超限。
- 该准入不含TTF和AUC优势，不等于正式晋级。均匀SA相对均匀贪心没有新增成功，修复次数与AUC反而更高，
  暂无理由把它作为更复杂的优先探索方法。

不添加事后AUC门槛去否认已通过的准入，也不忽略AUC退化去宣布全面胜出。

## 5. 失败分类：接受层不是全部

09/seed17：默认、模型完整贪心、模型SA均256步后剩同一冲突对 `(4,157)`。
最后251次连续选 `neighborhood-fbb38366e322ff16`，成员 `[1,6,157,208]`。
SA这251次全部接受、全部零冲突变化，没有更差尝试，退火无机会打破该平台。
最终19个候选中12个同时包含冲突双方，但没有被最高分选中。
均匀贪心20步、均匀SA24步完成同一个初始任务。

这证明同一个初始任务并非本预算必然失败，也支持选择覆盖不足；
但均匀臂从第一步就不同，不能据此证明卡住末态立即换一个候选就能清零。
不能仅凭重复ID证明所有完整路径逐位不变，也不能宣称那12个双端点候选一定有效。

本轮模型+SA在大多数累计效率指标上优于均匀选择，因此“预测一步效果的模型完全无用”不符合数据。
更合理的解释是强 exploitation 缺少可靠 exploration；这是待实现/验证的设计方向，不是本轮训练出了新模型。

## 6. 双轨预算检查

不运行新solver，按预注册规则对保存的默认与模型SA轨迹固定逐次交替，不读取未来结果分配下一步。
每任务总预算256次，得到19/20；总调用892次。模型SA单轨19/20、603次。
各轨最多256、总预算512时仍19/20，调用1148次，因为09/seed17是共同盲点。
因此不实施仅靠默认+SA堆两份计算的版本；还未体现互补覆盖价值。
这只是轨迹预算核算，不包含双环境维护、初始化、IPC或墙钟开销，也未验证真实双轨执行的逐位等价。

## 7. 下一步与停止点

三轮到此停止，没有追加温度、stall阈值、候选救援或更多seed。
保留默认Dual16、模型SA实验版以及均匀贪心的开发性覆盖证据，不宣布替换默认。

新的可讨论方向是独立的“模型+SA强化轨迹”和“均匀贪心探索轨迹”，不是在当前轨迹停滞后强行覆盖路径。
它与CPLNS的多样化/强化分工相符，但本轮尚未实现或验证该组合。
下一轮须单独冻结固定预算分配，并与两个单轨在等总repair/节点预算下比较；
不能把两个求解器的并行算力、成功并集或事后最优选择当免费收益。
先用未参与这几轮的任务验证新增覆盖是否值得代价，之后才考虑真实TTF。
若无互补收益，保留模型SA的条件性优势并结束该组合方向，不重开历史22号逐个救援链。
