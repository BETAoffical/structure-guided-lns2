# SA与邻域选择的三轮有界诊断

## 历史及论文准入

恢复点 `pre-sa-factorial-rounds-20260912`，分支 `codex/sa-selector-factorial-rounds`。
正式Dual16、模型、native和历史结果不修改。本轮是非计时诊断，不是正式TTF或新地图泛化。

历史不能忽略：PreTail的25组有利/24组不利、ProductivityGuard的8/11误触发、HistoryRank、
Signature Rescue及反馈探索均未形成安全通用救援。禁止再次拟合停滞阈值、禁忌列表、调排序参数或重启22号救援链。
末期SA曾13/20对默认14/20；初始路径SA为19/20对16/20，但有一项配对损失。
默认已允许等冲突新路径，不能把作者代码`>=`与本项目`>`的差别重新包装为新增特性。

重新读取用户提供CPLNS论文第5--9页及固定作者源码：论文在冲突修复阶段使用SA，而在成本优化阶段不用；
合作多求解器、独立组、重启和加权低层共同组成方法，不能把全部收益归为SA。
其退火参数经验证集选择，不能认为T=1000对任意冲突尺度自动合理。
[CPLNS](https://ieeexplore.ieee.org/document/10553642/)、[作者代码](https://github.com/KaenChan/cplns)。
[LNS2+RL](https://ojs.aaai.org/index.php/AAAI/article/view/34501)支持不同修复阶段可能适合不同策略，
但它改变低层规划器，不证明本项目应套用任意冲突阈值。
[统一评测](https://arxiv.org/abs/2407.09451)要求强基线和统一口径，其主要对象是anytime优化，不直接证明InitLNS增益。

本轮新问题是完整修复下接受层与选择层的交互，不是停滞触发随机救援：
若退火只在均匀选取有效，冻结排序与非单调探索可能不匹配；若两者均有效，收益更可能来自接受层；
若完整贪心已经有效，需要与提前中止拆分；若复核方向相反，只记录不稳定性，不追加参数。
这只是受控算法对比，不把轨迹分歧直接写成唯一因果根源。

## 固定轮次

1. 零solver审计已有60条：来源SHA、最高分选择、请求动作、接受概率、接受决定、正delta拒绝与零下降。
   另检查完整fingerprint对低层计数是否敏感。完整计数用于重放本身合理；与proposal随机种子耦合是设计选择，
   不能仅凭其存在判成bug，本轮不修改它。
2. 五个已有开发任务，各使用全新初始化seed `[7,11]`，共10状态。
3. 同五任务使用预留seed `[13,17]`，另10状态，参数与第二轮完全相同。
   第三轮结果在第二轮完成前不生成。不根据第二轮选择策略或更改第三轮参数。
   这是新初始化的同任务复核，不是新地图、最终Validation或独立泛化证明。

每个新状态先由冻结本项目PP reset生成路径，再reset_paths规范化导入；五臂共享完全相同路径和完整初始状态。
记录原PP计数与导入后计数差别；本轮不比较初始化耗时，也不冒称复现作者初始化内部状态。
零冲突保留，空路径、任务/地图不匹配、非法路径、身份变化立即停止。不依冲突数换任务/seed。

五臂：`standard`默认Dual16提前中止PP；`rank_greedy`模型排序+完整PP贪心；
`rank_sa`模型排序+完整PP退火；`uniform_greedy`同候选池均匀选择+完整贪心；
`uniform_sa`同候选池均匀选择+完整退火。
均匀臂仍计算模型分数用于审计，不能以此耗时评价真正的无模型运行时。
选择、PP、接受使用独立且不含arm的确定性随机流。同状态同行为可核对一致性。
温度、候选池、PP均不调整，沿用T=1000、0.99冷却。

## 预算、安全、解释

20个准入作业；两个来源的五臂加legacy默认两步检查，共12个smoke；100个正式诊断分支。
每条最多256次修复、PP5秒、循环资源120秒、外部180秒。每轮1800秒，最多20个独立进程。
总最大新增诊断修复25,600次，另加24次smoke及20次PP初始化；不是计时任务。
异常立即停止，预算截断标未知，步数上限未清零不代表无解。STOP于当前批完成后停，原子文件与SHA续跑。
每轮结果和源码分别备份，备份不得收录第三方未授权源码，不推送build。

每轮分别报告成功、配对得失、共同成功修复次数、固定H256 AUC、generated、平台候选复用和接受分布。
使用五地图配对bootstrap仅作小样本描述，不能以多条trial充当独立地图。
候选进入下一阶段需两轮相对standard均不损失成功、各至少新增1个成功、合计至少2任务新增成功、
generated合计不超过standard的1.25倍、无资源删失/实验错误。仅表示开发信号，不自动晋级或计时。
四种挑战方法全部报告，不事后挑选一次最优；本轮不训练、不启用RL。

附加零solver预算分析：从已存standard和rank_sa轨迹计算固定交替双轨、总256次修复的结果，
再报告各跑256次的最多512次覆盖上限。后者即使覆盖更多成功，也不能写成同预算改善或真实并行加速。
不实现在线合作、路径交换、重启或自动阈值；不读取未来结果决定轨迹分配。

第二轮科学门槛失败时仍完成已冻结的第三轮复核，用于区分重复性与抽样波动；不修改机制。
若完整性失败，则先定位，可最多一次仅修正诊断基础设施，另建run版本，不能拼接新旧结果。
三轮后必须回查上述历史停止结论，不以新增失败样本为理由继续救援链。
